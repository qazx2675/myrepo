도구명: dirmap (dirmap.sh) — 디렉터리 트리 및 폴더 설명 출력 스크립트

양식 유형: T1 (단일 스크립트형 · 빌드 불필요)

주요 실행 파일: dirmap.sh

동작 환경 및 의존성: Linux / RHEL 계열 (bash 4.0 이상 — declare -A 연관배열 사용, find, sort, realpath, egrep)

한 줄 요약: 자주 사용하는 디렉터리의 하위 폴더 구조를 tree 형태로 출력하면서, 스크립트에 등록한 경로별 한국어 설명(└ : 설명)을 함께 표시하는 단독 Bash 스크립트입니다.

1. 개요: 이게 뭐하는 도구인가요?

dirmap.sh는 운영 서버나 공용 작업 디렉터리(예: /home/saccae)의 하위 폴더 구조를 깊이(MAX_DEPTH)와 제외 패턴(EXCLUDE_PATTERN) 조건에 맞춰 tree 형식으로 한눈에 출력하는 스크립트입니다.

일반적인 tree -d 명령과 달리, 자주 확인하는 주요 폴더의 절대경로와 한국어 설명을 스크립트 내부 연관배열(FOLDER_DESC)에 등록해 두면 트리 출력 바로 아래에 └ : 설명 주석을 붙여 주므로 팀 내 폴더 용도 공유 및 온보딩에 유용합니다.

  • 탐색 대상: 파일은 제외하고 하위 디렉터리(-type d)만 알파벳 순(sort)으로 출력합니다.
  • 단독 동작: 다른 도구 의존성이나 외부 설정 파일 없이 dirmap.sh 파일 1개로 동작합니다.

2. 사전 준비 및 배치 (빌드 불필요)

dirmap.sh는 순수 Bash 스크립트이므로 별도의 빌드 과정이 필요 없습니다(빌드 불필요). 스크립트를 내려받은 뒤 상단 설정 변수와 폴더 설명 배열을 환경에 맞게 수정하고 실행 권한만 부여하면 즉시 사용할 수 있습니다.

  1. 실행 권한 부여 bash
  2. 스크립트 상단 기본 변수 수정 — dirmap.sh의 설정 블록에서 기본 경로·깊이·제외 패턴을 환경에 맞게 편집합니다. bash
  3. 폴더 설명 등록 (FOLDER_DESC) — realpath로 정규화된 절대경로를 키로, 한국어 설명을 값으로 추가합니다. bash

어디서나 실행하려면 PATH에 포함된 디렉터리(예: /usr/local/bin/dirmap)로 심볼릭 링크하거나 복사해 두면 편리합니다. 단, FOLDER_DESC 키는 realpath "$BASE_INPUT"으로 변환된 실제 절대경로와 일치해야 설명이 표시되므로, 심볼릭 링크 경로 대신 실제 물리 경로를 키로 등록하세요.

3. 빠른 시작 및 사용 방법

인자 없이 실행하면 스크립트 상단에 설정한 변수값으로 동작하며, 필요할 때 명령행 인자로 경로·깊이·제외 패턴을 순서대로 덮어쓸 수 있습니다.

4. 설정 변수 및 명령행 인자 상세

4.1 스크립트 내부 설정 변수

변수명 기본값 설명
TARGET_PATH /home/saccae 탐색을 시작할 기본 디렉터리 경로
MAX_DEPTH 2 탐색할 최대 하위 깊이 (1 이상의 정수만 허용)
EXCLUDE_PATTERN \.cache 및 숨김 메타 폴더 정규식 제외할 폴더 이름 정규식 (egrep -E 호환, 예: ^test_, source$). 빈 문자열 ""이면 제외 없음
FOLDER_DESC ["/home/saccae/VMsetup"]="VM 자동 구성 스크립트 모음" declare -A 연관배열. 키는 절대경로, 값은 트리 아래에 출력할 설명 문자열

4.2 명령행 인자 (선택)

위치 인자 덮어쓰는 변수 처리 규칙 및 제약
$1 (<경로>) TARGET_PATH Windows CRLF(\r) 자동 제거 후 디렉터리 존재 여부 확인. 없으면 exit 1
$2 (<깊이>) MAX_DEPTH \r 자동 제거 후 1 이상의 정수(^[0-9]+$) 검증. 위반 시 exit 1
$3 ([제외패턴]) EXCLUDE_PATTERN \r 자동 제거. basename에 대해 egrep -q "$EXCLUDE_PATTERN" 적용

6. 주의사항

  • 읽기 전용 안전: dirmap.sh는 find로 디렉터리 구조만 조회하며 파일이나 디렉터리를 변경하지 않습니다.
  • FOLDER_DESC 경로 일치: realpath로 변환된 실제 경로 기준으로 조회하므로, 심볼릭 링크를 탐색할 경우 원본 실제 경로를 FOLDER_DESC에 등록해야 설명이 출력됩니다.
  • 제외 패턴 매칭 범위: EXCLUDE_PATTERN은 전체 경로가 아닌 폴더명(basename)에 대해 부분 일치(egrep -q)로 동작합니다. 특정 접두사/접미사만 제외하려면 ^test_, source$처럼 앵커를 명시하세요.
  • set -euo pipefail 동작: 스크립트에 set -euo pipefail이 활성화되어 있으므로 읽기 권한이 없는 하위 디렉터리가 포함되면 find 오류로 중간에 중단될 수 있습니다.
