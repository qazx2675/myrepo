# 엑셀 버전비교 툴 사용법

이전 버전과 최신 버전 엑셀 파일을 올리면, **달라진 값**을 찾아 한글 설명과 전후 비교 시트가 담긴 **새 엑셀 파일**을 만들어 주는 Windows 프로그램입니다. 올린 원본 파일은 수정하지 않습니다.

## 1. 내려받기와 실행 (빌드·설치 불필요)

필요한 것: Windows(64비트). 결과를 만드는 데 Excel 과 인터넷은 필요 없습니다. 결과 파일을 열어 볼 때만 Excel 등 xlsx 를 여는 프로그램이 있으면 됩니다.

1. 내려받기 (둘 중 하나)
   - ZIP: <https://github.com/qazx2675/myrepo> 에서 브랜치를 `엑셀버전비교툴` 로 바꾼 뒤 **Code → Download ZIP**, 받은 ZIP 의 압축을 풉니다.
   - git: `git clone -b 엑셀버전비교툴 --single-branch https://github.com/qazx2675/myrepo.git`
2. `엑셀 버전비교 툴` 폴더의 **`엑셀버전비교.exe`** 를 두 번 클릭합니다. (ZIP 안에서 바로 실행하지 말고 압축을 먼저 푸세요.)
3. Edge 앱 창이 열립니다. Edge 가 없으면 Chrome, 둘 다 없으면 기본 브라우저가 열립니다. 화면은 내 PC 안(127.0.0.1)에서만 동작합니다.

끝낼 때는 창을 닫으면 됩니다. 잠시(약 10초) 뒤 프로그램도 종료됩니다. 비교가 진행 중이면 끝날 때까지 종료하지 않습니다.

## 2. 화면 사용 순서

| 순서 | 할 일 |
|---|---|
| ① 이전 버전 파일 | 기준이 되는 예전 파일을 선택합니다 (`.xlsx`, `.xlsm`) |
| ② 최신 버전 파일 | 바뀐 파일을 선택합니다 |
| 시트 짝 | 두 파일을 다 읽으면 표가 나타납니다. 필요하면 조정합니다 |
| 비교 | **[비교]** 를 누르면 진행률·단계·경과 시간이 표시됩니다 |
| 결과 | **[결과 열기]** 또는 **[폴더 열기]** |

- 결과 화면에는 변경내역 건수, 시트·행·열·셀별 건수, 소요 시간, 결과 파일 경로, 경고(처음 200건, 전체는 결과 파일의 요약 시트)가 나옵니다.
- 다른 파일을 다시 선택하면 이전 비교 결과는 화면에서 사라집니다. 이미 만든 결과 파일은 남습니다. 비교 중에는 파일을 바꿀 수 없습니다.

### 시트 짝

- 같은 이름의 시트끼리 자동으로 짝지어집니다(대소문자만 다른 이름 포함).
- 시트 이름이 바뀌었다면 **'이전 시트'** 칸에서 직접 고르세요.
- 짝이 없는 시트는 `(없음: 추가된 시트)`, `(없음: 삭제된 시트)` 로 표시됩니다.
- 체크를 끄면 비교에서 제외합니다. 제외한 시트는 결과에 "비교에서 제외"로 적힙니다.

### 키 열 (보통은 '자동')

키 열은 **행을 구분하는 값**(예: ID, 서버 이름)이 있는 열입니다. 프로그램이 행의 내용을 보고 알아서 짝짓기 때문에 보통은 지정하지 않아도 됩니다. 다음 경우에는 지정하세요.

- 값이 많이 바뀌었고 **행 삽입·삭제도 함께** 있는 경우
- **같은(거의 같은) 행이 많이 반복**되는 시트
- 결과에서 서로 다른 행이 "수정"으로 묶여 보이거나, 같은 행이 "삭제 + 추가"로 나뉘어 보이는 경우

지정 방법: **이전 키 열**과 **최신 키 열**을 둘 다 고릅니다. 한쪽을 고르면 다른 쪽은 같은 머리글(없으면 같은 열)로 자동으로 맞춰집니다.

- 키 값이 양쪽에서 하나씩만 있는 행은 키로 짝짓습니다. 키 값 자체가 바뀐 행은 삭제 + 추가로 표시됩니다.
- 키가 비었거나, 값 확인 불가이거나, 중복인 행은 자동 정렬로 비교하고 경고에 행 번호(처음 10개)를 알려줍니다.
- 반복 행뿐이고 고유한 값이 있는 열이 없으면 키 열로 해결되지 않습니다.

## 3. 결과 파일 읽기

결과 파일은 exe 옆 `results` 폴더에 `비교결과_날짜_시각.xlsx` 로 저장됩니다. 그 폴더에 쓸 수 없으면 **내 문서** 폴더에 저장합니다. 기존 파일은 덮어쓰지 않습니다.

### 시트 구성

| 시트 | 내용 |
|---|---|
| 요약 | 파일명, 시트별 건수, 시트·열 변화, 제외한 시트, 경고, 색 범례, 비교 범위, 나눠 담거나 줄인 내용 |
| 변경내역 | 번호 · 시트 · 구분 · 위치(이전) · 위치(최신) · 이전값 · 최신값 · 한글 설명 · 바로가기 |
| 시트명_비교 | 짝지은 행을 왼쪽(Before)·오른쪽(After)에 나란히 배치. 상대가 없는 행은 반대쪽이 빈칸 |
| 시트명_Before / 시트명_After | 원본의 행·열 위치 그대로, 바뀐 곳에 색 표시 |

`변경내역` 의 **바로가기**를 누르면 `_비교` 시트의 해당 위치로 이동합니다.

### 색

| 색 | 뜻 |
|---|---|
| 노랑 | 수정 |
| 초록 | 추가 |
| 빨강 | 삭제 |
| 파랑 | 이동 (이동한 행에서 값이 바뀐 셀은 노랑 등 변경 색) |
| 주황 | 값 확인 불가 |
| 회색 기울임 | 원본에서 숨김인 행·열 (결과에서는 숨기지 않음) |

### 설명 읽는 법

아래 문장은 작은 예제(서버 목록)를 이 도구로 비교해 나온 그대로입니다.

| 구분 | 한글 설명 | 뜻 |
|---|---|---|
| 이동 | `12행 → 3행 이동 (web11)` | 이전 12행이 최신 3행으로 옮겨짐 |
| 수정 | `이전 C3~C5 → 최신 C4~C6 (3개 셀): '대기' → '완료'` | 같은 열의 같은 변화가 연속되어 한 줄로 묶음. 위의 행 이동 때문에 위치가 한 칸 밀림 |
| 수정 | `7행 → 8행 (web06): B열(IP) '10.0.0.06' → '10.0.1.6', D열(담당자) '박' → '정'` | 한 행에서 여러 칸이 바뀜. 괄호 안은 행을 알아보기 위한 값과 열 머리글 |
| 수정 | `9행 → 10행 (web08): D열(담당자) '김' → '김␣' [공백만 다름]` | 보이지 않는 차이는 기호(`␣` 공백, `↵` 줄바꿈)와 `[ ]` 안의 설명으로 표시 |
| 수정 | `2행 (web01): E열(점수) '1.00'(실제값 1.001) → '1.00'(실제값 1.002)` | 화면에는 같게 보여도 저장된 값이 다르면 변경 |
| 삭제 | `10행 삭제 (web09)` | 삭제된 행의 값은 `이전값` 칸에 있음 |
| 추가 | `13행 추가 (web20)` | 추가된 행의 값은 `최신값` 칸에 있음 |
| 확인 불가 | `2행 (합계): B열(값) '10' → 값 확인 불가` | 4장의 "값 확인 불가" 참고 |

숨김 행·열·시트의 변경은 설명에 `(숨김)` 이 붙습니다. 셀 글자 수나 링크 수 같은 Excel 한계를 넘으면 여러 행·시트로 나누거나 줄이고, 요약 시트에 알립니다.

## 4. 비교 범위

### 비교하는 것

- 셀에 보이는 **계산된 값**. 숫자 `1000` 과 글자 `"1000"` 은 같고, 천 단위 쉼표 같은 표시 방식만 바뀌면 같습니다. 유효숫자 15자리 밖의 오차는 무시합니다.
- 날짜는 내부 값으로 비교합니다(날짜 표시형식만 바뀌면 같음).
- 앞뒤 공백, 대소문자, 줄바꿈 차이는 변경입니다.
- 병합 셀은 값이 있는 첫 셀만 비교합니다.
- 숨김 행·열·시트(필터로 가려진 행 포함)도 비교합니다.

### 비교하지 않는 것

- 수식 내용(수식이 바뀌어도 결과 값이 같으면 같음)
- 색·글꼴·테두리·병합 모양, 메모, 그림·차트, 차트 시트
- 결과 파일에는 값과 열 너비만 옮기며 원본 서식은 복제하지 않습니다.

### "값 확인 불가"

파일에 수식의 **계산 결과가 저장되어 있지 않으면**(주로 Excel 이 아닌 프로그램이 만든 파일) 프로그램이 직접 계산해 봅니다. 계산할 수 없으면 "값 확인 불가"로 표시합니다. 예: `INDIRECT`·`OFFSET` 이나 지원하지 않는 함수, 다른 통합 문서 참조, 순환 참조, 그런 셀을 참조하는 수식.

- 어느 한쪽이라도 확인 불가인 셀은 실제로 바뀌었는지 알 수 없으므로 목록에 나옵니다. 직접 확인하세요.
- 해결: 해당 파일을 Excel 에서 열어 다시 저장한 뒤 비교합니다.
- 직접 계산에 성공한 수식이 있으면 "자체 계산한 수식 N개(Excel 과 다를 수 있음)" 경고가 나옵니다.

## 5. 알려진 한계

- **같은 자리에서 행을 지우고 다른 행을 넣으면 "수정"으로 보일 수 있습니다.** 예제: 5줄짜리 표에서 `web02` 행을 `db01` 행으로 바꾸면 `3행 (db01): A열(서버) 'web02' → 'db01', B열(담당) '이' → '정'` 으로 나옵니다. 식별 열(ID 등)이 있고 행이 충분히 많으면 자동으로 구분하지만, 확실히 하려면 키 열을 지정하세요.
- **같은 행이 많이 반복되는 시트**에서 키 열 없이 비교하면, 일부만 수정된 행이 "삭제 + 추가"로 표시될 수 있습니다(대용량 시험의 반복 행 시나리오에서 확인).
- **맨 끝 열의 값을 모두 지우면** 셀 수정이 아니라 `C열(비고) 열 삭제 (4개 값)` 처럼 열 삭제로 표시됩니다. 가운데 열의 값을 모두 지우면 셀별 변경으로 표시됩니다.
- **표시형식이 '일반(General)'인 긴 소수**는 Excel 화면보다 길게 보일 수 있습니다(예: `0.333333333333333`). Excel 은 열 너비에 맞춰 줄여 보여줍니다.
- 1904 날짜 체계 파일을 1900 날짜 체계 파일과 비교하면 날짜가 변경으로 표시됩니다(경고가 나옵니다).
- 지원 형식은 `.xlsx`, `.xlsm` 입니다. `.xls`, `.csv`, 암호가 걸린 파일은 안내 문구와 함께 중단합니다.
- **큰 파일은 메모리를 많이 씁니다.** 시험한 PC 에서 40열 × 30,000행의 모든 셀이 바뀐 경우 약 19초, 최대 약 1.3GB 였습니다. 30열 × 30,000행에 일부만 바뀐 경우는 약 10초, 약 0.5GB 였습니다. PC 와 파일 내용에 따라 다릅니다.

## 6. 문제 해결

| 증상 | 할 일 |
|---|---|
| 실행할 때 "Windows의 PC 보호"(SmartScreen) 경고 | 서명되지 않은 프로그램이라 나올 수 있습니다. 받은 곳이 맞는지 확인한 뒤 **추가 정보 → 실행**. 회사 보안 정책으로 막히면 담당자에게 문의하세요 |
| "프로그램과 연결이 끊어졌습니다" | 창을 닫고 다시 실행합니다. 반복되면 로그를 확인하세요 |
| "허용되지 않은 요청입니다" | 프로그램을 다시 실행합니다(이전에 열어 둔 창·주소는 쓸 수 없음) |
| 파일을 읽지 못함 | 형식(`.xlsx`, `.xlsm`)·암호 여부를 확인하고, Excel 에서 `.xlsx` 로 다시 저장해 봅니다 |
| 결과 파일을 찾을 수 없음 | exe 옆 `results` 폴더, 없으면 내 문서 폴더. 결과 화면의 "결과 파일" 경로를 확인하세요 |
| 그 밖의 오류 | exe 옆의 **`excel-diff.log`** 를 확인합니다(그 위치에 쓸 수 없으면 Windows 임시 폴더 `%TEMP%`) |

## 7. 개발자용: 빌드

사용하는 사람은 필요 없습니다. 코드를 고친 경우에만 Go 가 설치된 PC 에서 실행합니다.

```bat
cd "엑셀 버전비교 툴"
build.bat
go test ./...
```

`build.bat` 은 `CGO_ENABLED=0`, windows/amd64 로 `엑셀버전비교.exe` 를 만듭니다. 처음 빌드할 때는 Go 모듈을 내려받기 위한 인터넷 연결이 필요할 수 있습니다.
