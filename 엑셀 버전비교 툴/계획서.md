# 엑셀 버전비교 툴 — 계획서 (2026-11-26)

## 1. 목표
이전 버전과 최신 버전 엑셀 파일을 업로드하면, 달라진 **보이는 값**을 누락 없이 찾아 한글 설명과 전후 비교 시트가 담긴 **새 엑셀 파일**을 만드는 Windows 실행 파일.

## 2. 확정 사항 (인터뷰)
| 항목 | 결정 |
|---|---|
| 입력 | DRM 없는 일반 xlsx. 원본은 읽기만 함 |
| 비교 대상 | 셀의 계산된 값. 수식 내용 변화는 무시 |
| 표시형식 | 1000 ↔ 1,000 은 동일, 1.001 → 1.002 는 변경(화면에 같게 보여도) |
| 행 매칭 | 자동 정렬 + 필요 시 키 열 지정 |
| 시트 | 같은 이름 자동 짝짓기, 화면에서 제외·직접 짝짓기 |
| 결과 | 요약, 변경내역, 시트별 비교(좌우)·Before·After |
| 설명 묶음 | 행 중심 + 같은 열의 같은 변화가 연속되면 `A3~A10` |
| 이동 | `5행 → 12행 이동`으로 표시, 열 삽입·삭제 감지 |
| 숨김 | 숨김 행·열·시트(필터 포함)도 비교, 설명에 `(숨김)` |
| 성능 | 시간 제한보다 **누락 없이 완료**가 우선. 진행률 표시줄 제공 |
| 실행 | SOP 툴과 동일: exe → Edge 앱 창 → 업로드 → [비교] → [결과 열기] |

## 3. 가정 (다르면 알려주세요)
- 지원 형식은 `.xlsx`, `.xlsm`. `.xls`, `.csv`, 암호 걸린 파일은 한글 안내 후 중단.
- 숫자 `1000`과 텍스트 `"1000"`은 동일. 부동소수점 오차(유효숫자 15자리 밖)는 무시.
- 날짜는 내부 값으로 비교(날짜 표시형식만 바뀌면 동일), 설명에는 화면 표시값을 사용.
- 앞뒤 공백, 대소문자, 줄바꿈 차이는 변경이며 설명에 그 종류를 명시.
- 병합 셀은 값이 있는 첫 셀만 비교.
- **비교하지 않음**: 수식 내용, 색·글꼴·테두리·병합 모양, 메모, 그림·차트. 요약 시트에 이 범위를 적음.
- 저장된 계산값이 없는 수식(다른 프로그램이 만든 파일)은 자체 계산을 시도하고, 실패하면 "값 확인 불가"로 목록에 표시(조용히 넘기지 않음).

## 4. 설계
- Go 단일 exe (`CGO_ENABLED=0`, windows/amd64), 라이브러리 excelize. 결과 생성에 Excel 불필요, 인터넷 불필요.
- 구성: `reader`(읽기·값 정규화) → `diff`(열 정렬 → 행 정렬 → 이동 감지 → 셀 비교) → `describe`(한글 설명·범위 묶음) → `report`(결과 xlsx, 스트리밍 쓰기) → `web`(업로드·진행률 화면).
- 행 정렬: 완전 일치 행을 기준점으로 잡고, 남은 구간은 유사도로 짝지음. 짝 없는 삭제/추가 행 중 같거나 매우 비슷한 것은 이동. 키 열 지정 시 키 우선, 중복·빈 키는 자동 정렬로 처리하고 경고.
- 열 정렬: 머리글과 열 내용 유사도로 삽입·삭제·이동 판정.
- **누락 방지 자체 검증**: 모든 비어 있지 않은 셀이 동일·수정·추가·삭제·이동 중 정확히 하나에 속하는지 실행 때마다 확인. 어긋나면 성공으로 표시하지 않음.
- 결과 파일: 실행 파일 옆 `results\비교결과_날짜_시각.xlsx` (쓰기 불가 시 문서 폴더). 기존 파일 덮어쓰지 않음.

## 5. 결과 시트
1. **요약** — 파일명, 시트별 추가/삭제/수정/이동 건수, 시트·열 추가/삭제, 경고, 비교 범위.
2. **변경내역** — 번호 | 시트 | 구분 | 위치(이전) | 위치(최신) | 이전값 | 최신값 | 한글 설명 | 바로가기. 예:
   - `A3~A10 (8개 셀): '대기' → '완료'`
   - `15행 → 16행 (web01): B열(IP) '10.0.0.1' → '10.0.0.2', E열(담당자) '김' → '이'`
3. **시트명_비교** — 짝지은 행을 좌(Before)·우(After)로 배치, 추가·삭제는 반대쪽 빈칸.
4. **시트명_Before / 시트명_After** — 원래 행·열 위치 그대로.
- 색: 수정 노랑, 추가 초록, 삭제 빨강, 이동 파랑. 틀 고정·자동 필터 적용.
- 값과 열 너비만 옮기고 원본 서식은 복제하지 않음.
- Excel 한계(시트명 31자, 시트당 행 1,048,576, 링크 65,530개, 셀 32,767자)는 분할·축약하고 요약에 알림. 변경내역 항목은 잘라내지 않음.

## 6. 작업 단계와 검증
| # | 작업 | 확인 방법 |
|---|---|---|
| 1 | 고아 브랜치 `엑셀버전비교툴` 생성(다른 파일 없음), Go 골격 | 브랜치 파일 목록에 이 작업만 존재 |

| 4 | 한글 설명·범위 묶음 | 예시 문장 기대값 테스트 |
| 5 | 결과 xlsx 생성 | 실제 Excel에서 복구 경고 없이 열리는지, 링크·색 확인 |
| 6 | 웹 화면·진행률 | 업로드부터 결과 열기까지 실제 조작 |
| 7 | 대용량 시험 | 아래 완료 조건 |
| 8 | `/code-review` 후 수정·재시험 | 지적 사항 처리 결과 보고(한글) |
