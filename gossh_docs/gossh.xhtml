2.2 -w 는 어떤 형식으로 쓰나?

다음 형식은 모두 같습니다: -w hosts.txt, -w=hosts.txt, -whosts.txt, -w^hosts.txt. 명령은 반드시 따옴표로 묶으십시오.

2.3 인증은 어떻게 하나?

  1. gossh 는 SSH 키를 먼저 시도합니다. -i 가 없으면 ~/.ssh/id_ed25519 → id_ecdsa → id_rsa 순서로 찾습니다.
  2. 키 인증이 실패한 서버에만 -p 비밀번호를 씁니다.
  3. 기본 계정은 root 입니다. 다른 계정은 -u <계정> 으로 지정합니다.

3. 기본 명령 실행은 어떻게 하나?

bash result.txt 2> error.log # 오류 출력(stderr)으로 나오는 명령은 2>&1 을 붙인다 gossh -w hosts.txt "java -version 2>&1" > java_ver.txt]]>
  • gossh 는 표준출력(stdout)과 오류(stderr)를 분리합니다.
  • gossh 는 원격 출력의 색 제어 문자(ANSI)를 지웁니다.
  • 처음에 접속하지 못한 서버는 낮은 동시성(최대 50)으로 한 번 더 확인합니다.

4. 같은 결과 묶기(-b)는 어떻게 쓰나?

-b 는 출력이 같은 서버를 한 그룹으로 묶습니다. 접속하지 못한 서버는 따로 묶습니다. 결과가 다른 서버만 눈에 띄므로 이상 서버를 빨리 찾을 수 있습니다.

bash

-script 와 같이 쓰면 -b 는 동작하지 않습니다.

5. 여러 명령의 조사 표(-sv)는 어떻게 만드나?

  1. gossh -sv -w hosts.txt 를 실행합니다. 명령 인자는 쓰지 않습니다.
  2. 조사할 명령을 한 줄에 하나씩 입력합니다.
  3. 미리보기 단계에서 서버 1대로 시험합니다. 아래 키를 씁니다.
  4. next 를 입력합니다. 모든 서버에서 실행합니다.
  5. 결과 표를 확인합니다. 표는 화면과 파일 <hostfile>_survey.tsv(엑셀용 탭 구분), <hostfile>_survey.txt(| 구분)에 저장합니다.
미리보기 입력동작
Enter첫 서버로 시험합니다.
<호스트명>그 서버로 시험합니다.
Ni (예: 2i)N번 명령을 수정합니다.
a명령을 추가합니다.
Nd (예: 3d)N번 명령을 지웁니다.
next모든 서버에서 실행합니다.

명령은 원격 bash -s 로 전달합니다. 그래서 기본 셸이 csh/tcsh 인 서버에서도 동작합니다. 결과가 2줄 이상이면 명령을 다시 입력하거나 줄을 / 로 합칠 수 있습니다.

5-1. 접속 user 조회(-lu)는 어떻게 하나?

-lu 는 서버의 /var/log/secure* 에서 지정한 시간 범위 안에 SSH 로 로그인에 성공한 계정과 마지막 로그인 시각을 서버별로 모읍니다. 서버를 변경하지 않습니다.

  1. gossh -lu -w hosts.txt 를 실행합니다. 명령 인자는 쓰지 않습니다. -u, -p, -i, -P, -c, -t 는 그대로 적용합니다.
  2. 시작 시간을 입력합니다. 형식은 YYYYMMDDHH 입니다(예: 2026111900).
  3. 끝 시간을 입력합니다. 형식은 시작 시간과 같습니다(예: 2026111923).
  4. 결과 표를 확인합니다. 표는 화면과 파일 <hostfile>_loginuser.txt 에 저장합니다.
  • 시간 입력 규칙: 숫자 10자리이고 월·일·시가 실제로 있어야 합니다. 틀리면 같은 질문을 다시 합니다. 끝 시간은 시작 시간보다 빠를 수 없습니다. 같은 시간은 됩니다. 범위는 시작 시의 00분부터 끝 시의 59분 59초까지입니다.
  • 연도는 비교하지 않습니다: 로그 줄에는 연도가 없습니다. 월·일·시만 비교합니다. 시작과 끝의 연도가 다르면(예: 2025123100 ~ 2026010100) 연말을 넘는 범위로 봅니다.
  • 읽는 파일: /var/log/secure 와 백업 /var/log/secure-YYYYMMDD(약 한 달치)를 읽습니다. .gz 파일은 zcat 으로 읽습니다. 읽을 수 없는 파일은 건너뜁니다.
  • 세는 로그인: sshd 의 Accepted password/publickey/keyboard-interactive for 계정 줄만 셉니다. 로그인 실패, Invalid user, su, sudo, 세션 줄과 root 계정은 세지 않습니다.
  • 접속 방식: 서버마다 SSH 접속을 한 번 합니다. 조회 스크립트는 원격 bash -s 로 전달합니다. 그래서 기본 셸이 csh/tcsh 인 서버에서도 동작합니다. 동시 접속과 접속 불가 서버 재확인은 -sv 와 같습니다.
  • 입력이 끝나면: 파이프 입력이 모자라면 아무것도 실행하지 않고 중단합니다.

결과 표는 계정마다 한 줄이고 머리줄이 없습니다. 형식은 호스트|접속성공시간|계정 입니다. 호스트는 호스트 파일 순서이고, 한 호스트의 계정은 이름순입니다. 접속성공시간은 그 계정이 범위 안에서 마지막으로 로그인한 시각이며 형식은 MMDD_HHMM 입니다.

text
표의 줄뜻
호스트|1118_0921|kimkim 이 범위 안에서 마지막으로 11월 18일 09시 21분에 로그인했습니다.
호스트||접속은 됐습니다. 범위 안에 로그인한 계정(root 제외)이 없습니다.
호스트|-|-접속하지 못했습니다(재확인 후에도). 또는 실행에 실패했습니다.
호스트|!|!접속은 됐습니다. /var/log/secure* 를 하나도 읽을 수 없습니다(권한 없음 또는 파일 없음). 경고에 서버 목록이 나옵니다.

gossh -h -lu 를 실행하면 예시 화면을 볼 수 있습니다. 시험할 때는 환경변수 GOSSH_LU_LOGDIR 에 폴더를 주면 /var/log 대신 그 폴더의 secure* 를 읽습니다.

6. 기준 서버와 비교·설정 복사(-rpm, -tmp, -limit, -tl)는 어떻게 하나?

이 네 옵션은 명령 인자 없이 씁니다. 실행하면 화면 질문에 답합니다(예: 기준 서버 이름).

옵션하는 일안전 장치
-rpm기준 서버와 대상 서버의 설치 RPM 을 이름.아키텍처 기준으로 비교합니다. gpg-pubkey 는 제외합니다.읽기 전용입니다.
-tmp/etc/tmpfiles.d/custom-tmp.conf 의 /tmp 정리 시간(h)을 바꾸거나 설정을 지웁니다(d).즉시 정리는 하지 않습니다.
-limit기준 서버의 /etc/security/limits.conf 를 대상 서버에 복사합니다..bak 백업을 만듭니다. sha256 으로 검증합니다. 빈 파일 또는 60000 바이트 초과 파일이면 멈춥니다.
-tl-tmp 와 -limit 의 질문을 한 번에 받고 둘 다 실행합니다.위와 같습니다.

8. 실행 중에 어떻게 제어하나? (-m, Ctrl+C)

8.1 오래 걸리는 서버 보기 (-m)

-m 을 쓰면 60초 이상 실행 중인 서버와 끝난 서버 목록을 봅니다. 실행 중에 Enter 를 누르면 목록 표시를 켜고 끕니다. 파이프나 터미널이 아닌 환경에서는 -m 을 무시합니다.

8.2 Ctrl+C 동작 (1초 안에 누른 횟수)

누른 횟수동작
1회지금 실행 중인 서버 목록을 출력합니다. 작업은 계속합니다.
2회지금 실행 중인 서버만 취소합니다(<hostfile>_res_cancel 에 기록). 남은 서버는 계속합니다.
3회전체 작업을 멈춥니다. 지금까지의 요약을 출력하고 결과 파일을 저장합니다.
4회즉시 종료합니다(종료 코드 130).

9. OS 설치 중 서버 거르기(-pm)와 autofs 보호는 무엇인가?

  • -pm: 본 명령 전에 ~/.profile 에서 anaconda 를 찾습니다. 찾으면 그 서버를 "OS 설치 중"으로 분류하고 명령을 실행하지 않습니다(_os_install 파일). 특정 autofs 계정이 마운트되지 않은 서버도 분류합니다(_nosvrauto 파일). 점검 시간 제한은 10초입니다.
  • autofs 보호: 명령에 /user/ 가 있으면 동시 접속 수를 자동으로 450 으로 줄입니다. 마운트 폭주를 막기 위해서입니다. 꼭 필요할 때만 -cf <N> 으로 이 제한을 바꾸십시오.

10. 위험 명령은 어떻게 차단되나? (강제 실행 절차)

위험 명령은 기본으로 차단합니다. 차단하면 종료 코드 1 로 멈춥니다.

  • 문자열 포함으로 차단: reboot, poweroff, shutdown, halt, init 0, init 6, ddc
  • 명령 단어로 차단: kexec, systemctl kexec/rescue/emergency, isolate rescue/emergency.target, init 1/telinit 1, sysrq-trigger, ipmitool ... power off/reset/cycle, mkfs*, dd ... of=/dev/, wipefs, fdisk(fdisk -l 포함), parted(parted -l 포함), sgdisk, shred, rm -rf /, lvremove/vgremove/pvremove, ifdown, nmcli ... down, ip link set ... down, systemctl stop sshd/network/NetworkManager

강제 실행 절차 (꼭 필요할 때만):

  1. 명령에 -dnlgjawkrdjqghkrdls 플래그를 추가합니다.
  2. 화면에 나온 대상 서버 목록과 똑같이 서버 목록을 다시 입력합니다. 빈 줄에서 Enter 를 누르면 입력이 끝납니다.
  3. 목록이 완전히 같으면 확인 질문이 나옵니다. y 를 입력합니다.

-m꺼짐60초 이상 실행 중인 서버 목록 보기 (Enter 로 켜고 끔)
-script꺼짐 (pdsh 이름이면 켜짐)진행률·요약·색을 끄고 호스트: 출력줄 만 출력
-t <초>15접속(TCP·핸드셰이크·인증) 제한 시간. 명령 실행 시간에는 적용하지 않습니다.
-pm꺼짐OS 설치 중·autofs 미마운트 서버 사전 점검
-dnlgjawkrdjqghkrdls꺼짐위험 명령 강제 실행 승인 (10절 절차 필요)
-tmp / -limit / -tl꺼짐6절 참고. 명령 인자 없이 씁니다.
-rpm꺼짐6절 참고. 명령 인자 없이 씁니다.
-sv꺼짐5절 참고. 명령 인자 없이 씁니다.
-lu꺼짐5-1절 참고. 명령 인자 없이 씁니다. 시작·끝 시간(YYYYMMDDHH)을 묻습니다.
-h [옵션...]—옵션 설명. 옵션 이름을 주면 상세 설명과 출력 예시를 보여 줍니다. 모르는 옵션이면 종료 코드 1

11.2 결과 파일

결과 파일 이름은 -w 로 준 파일 이름으로 시작합니다. 파일에는 한 줄에 서버 하나를 적습니다. 그래서 결과 파일을 다시 -w 로 넘겨 재실행할 수 있습니다. 같은 위치에서 다시 실행하면 _res_off, _res_refsed, _os_install, _nosvrauto, _res_cancel 파일을 먼저 지웁니다.

파일내용
<hostfile>_res_off접속 시간 초과, DNS 조회 실패, 네트워크 불가 서버
<hostfile>_res_refsed접속 거부(Connection Refused, 포트 닫힘) 서버
<hostfile>_os_install-pm 에서 OS 설치 중으로 분류한 서버
<hostfile>_nosvrauto-pm 에서 autofs 계정이 마운트되지 않은 서버
<hostfile>_res_cancelCtrl+C 2회로 취소한 서버
<hostfile>_rpm_report.txt-rpm 사람용 보고서
<hostfile>_rpm_tab.txt-rpm 탭 구분 표 (UTF-8 BOM, 엑셀용)
<hostfile>_rpm_diff-rpm 에서 차이가 있는 서버. 차이가 없으면 만들지 않습니다.
<hostfile>_survey.tsv / _survey.txt-sv 결과 표 (탭 구분 / | 구분)
<hostfile>_loginuser.txt-lu 결과 표 (호스트|접속성공시간|계정, | 구분)

12. 문제가 생기면?

  • 접속이 안 되는 서버가 있다: <hostfile>_res_off 와 <hostfile>_res_refsed 를 확인합니다. 서버 전원·네트워크·SSH 서비스를 확인한 뒤 gossh -w <hostfile>_res_off "명령" 으로 다시 실행합니다.
  • RHEL 6 같은 오래된 서버에 접속이 안 된다: gossh 는 최신 암호를 먼저 쓰고, 실패하면 오래된 암호(aes128-cbc, 3des-cbc, arcfour*)와 키 교환(diffie-hellman-group*)으로 다시 접속합니다. 옵션은 필요 없습니다. 서버가 blowfish-cbc 만 지원하면 접속할 수 없습니다.
  • "차단된 명령" 오류가 나온다: 10절의 위험 명령 목록에 들어 있는 명령입니다. fdisk -l·parted -l 도 차단합니다. 정말 필요하면 10절 절차를 따르십시오.
  • 명령이 너무 오래 걸린다: -m 으로 멈춘 서버를 봅니다. Ctrl+C 를 2번 눌러 그 서버만 취소합니다.
  • 출력에 pdsh 진행률이 안 나온다: 실행 파일 이름이 pdsh 이면 -script 가 기본으로 켜집니다. 정상입니다.

13. 자주 묻는 질문 (FAQ)

Q. gossh 는 무엇을 하는 도구인가요?
A. 여러 서버에 같은 명령을 동시에 SSH 로 실행하고 결과를 모아 보여 주는 도구입니다. 기본 형태는 gossh -w hosts.txt "명령" 입니다.

Q. 서버 100대의 디스크 용량을 한 번에 보려면?
A. gossh -w hosts.txt -b "df -h" 를 실행합니다. -b 가 같은 결과를 묶으므로 다른 서버만 눈에 띕니다.

Q. gossh 로 파일을 복사할 수 있나요?
A. 아니요. gossh 에는 파일 전송 기능이 없습니다. scp 또는 rsync 를 쓰십시오. 예외로 -limit 는 기준 서버의 limits.conf 하나만 복사합니다.

Q. gossh 로 재부팅할 수 있나요?
A. 기본으로는 할 수 없습니다. reboot 등은 차단합니다. 꼭 필요하면 -dnlgjawkrdjqghkrdls 플래그를 추가하고 서버 목록 재입력과 y 확인을 거쳐야 합니다.

Q. 여러 명령의 결과를 엑셀에 붙여 넣고 싶어요.
A. gossh -sv -w hosts.txt 를 실행합니다. 결과는 <hostfile>_survey.tsv 에 탭 구분으로 저장합니다.

Q. 어떤 계정이 서버에 SSH 로 로그인했는지 알고 싶어요.
A. gossh -lu -w hosts.txt 를 실행하고 시작·끝 시간(YYYYMMDDHH)을 입력합니다. 결과는 <hostfile>_loginuser.txt 에 호스트|접속성공시간|계정 형태로 저장합니다.

Q. 서버마다 설치된 패키지가 다른지 비교하려면?
A. gossh -w hosts.txt -rpm 을 실행하고 기준 서버를 입력합니다. 차이는 _rpm_report.txt 와 _rpm_diff 에 저장합니다.

Q. 비밀번호를 줘도 키로 먼저 접속하나요?
A. 예. 항상 키를 먼저 시도합니다. 키가 실패한 서버에만 비밀번호를 씁니다.

Q. 동시 접속 수를 바꿔도 되나요?
A. 기본값(1000)을 쓰십시오. 명령에 /user/ 가 있으면 autofs 보호를 위해 자동으로 450 이 됩니다.

Q. 접속이 안 된 서버만 다시 실행하려면?
A. gossh -w <hostfile>_res_off "명령" 을 실행합니다. 결과 파일은 한 줄에 서버 하나라서 그대로 -w 에 씁니다.
