도구명: gossh (gossh_os8 / pdsh 호환 병렬 SSH 실행 도구 v2)

양식 유형: T1 (단일 CLI 도구형)

주요 실행 파일: gossh_os8 (RHEL/Rocky 8+ 사전 빌드 정적 바이너리), update.sh

연계 도구: survey(조사), setup_check, stress-test, auto_setup, pm_monitor, config_check, OS 환경설정 체크, ip_change, ldap_setting, ldap_check, esxi-log-check 등 다수 운영·자동화 도구의 실행 엔진

한 줄 요약: pdsh·clush 스타일로 수천 대 서버에 병렬 SSH 명령 실행, 설정 변경(-tmp/-limit), 패키지 비교(-rpm), 다중 조사 표 생성(-sv), 대화형 접속(-i)까지 제공하는 고속 병렬 SSH CLI입니다.

위험 명령 가드 및 실서버 교차검증 필수: 본 도구는 보조 도구로 사용하시기 바랍니다. 재부팅·디스크 파괴·네트워크 단절 등 위험 명령은 기본 차단되며 강제 실행 시 -dnlgjawkrdjqghkrdls 플래그와 대상 호스트 재입력 대조가 필요합니다. 또한 -tmp·-limit·-tl이나 원격 설정 변경 명령 실행 후에는 출력 요약만 믿지 말고 무작위로 서버 몇 대에 직접 접속해 반영 여부를 확인하십시오.

1. 개요: 이게 뭐하는 도구인가요?

gossh는 다수의 Linux 서버에 동시에 SSH 명령을 실행하고 결과를 호스트명: 출력줄 형태로 출력하는 병렬 SSH CLI 도구입니다. 여러 HPC·VM 자동화 도구(조사, setup_check, stress-test, auto_setup, pm_monitor, config_check, ip_change, ldap_setting 등)가 내부 서브프로세스로 호출하는 공통 기반 도구입니다.

  • pdsh/clush 문법 호환: -w hosts.txt, -whosts.txt, -w^hosts.txt 및 NodeSet 범위 표기(esxi[0001-0020], qwer[2660,2671,2826-2829], 다차원 hostname[0001-0002]ev[01-03])를 지원하며 pdsh 이름으로 심볼릭 링크해 사용할 수 있습니다.
  • 안정성 기능 내장: SSH 키 우선 인증 후 비밀번호 폴백, 내장 DNS 리졸버 선행 조회, 1차 접속불가 호스트 저동시성(최대 50) 재검증, /user/ autofs 마운트 스톰 보호(동시성 450 제한), stdout/stderr 완전 분리, 원격 ANSI 제어코드 제거를 기본 제공합니다.

2. 사전 준비 및 바이너리 배치 / 배포

2.1 사전 빌드 바이너리(gossh_os8) 확인 및 권한 부여

별도의 빌드 과정 없이 함께 제공되는 정적 바이너리 gossh_os8에 실행 권한만 부여해 그대로 사용합니다.

3.2 인증 정책 (SSH 키 최우선) 및 autofs 보호

  • 키 우선 폴백: -p로 비밀번호를 지정해도 항상 SSH 키 인증을 먼저 시도하며(-i 미지정 시 ~/.ssh/id_ed25519 → id_ecdsa → id_rsa 순 자동 탐색), 키 접속에 실패한 호스트만 비밀번호로 폴백합니다.
  • /user/ autofs 가드: 명령 문자열에 /user/가 포함되면 마운트 스톰 방지를 위해 동시 접속 수(-c)가 자동으로 450으로 제한됩니다. 우회가 필요할 때만 -cf <N>을 사용하세요.

3.5 실행 중 Ctrl+C 제어 (pdsh 방식)

연속 입력 횟수 (1초 이내) 동작
1회 현재 접속/명령 실행 중인 호스트 목록을 stderr에 표시하고 계속 진행
2회 현재 걸려 있는 호스트들만 취소(<hostfile>_res_cancel 기록)하고 대기열 호스트를 계속 진행
3회 전체 작업 중단 후 지금까지의 결과 요약 출력 및 결과 파일 저장 후 종료 (4회 입력 시 즉시 종료 exit 130)

3.6 구형 SSH 서버 접속 지원 (RHEL 6 등)

옵션 없이 항상 최신 암호/키 교환을 먼저 제안하고 실패 시 구형 알고리즘(암호: aes128-cbc, 3des-cbc, arcfour256, arcfour128, arcfour / 키 교환: diffie-hellman-group16-sha512, group-exchange-sha256/sha1, group1-sha1)으로 접속합니다. 단, 내장 SSH 라이브러리에 blowfish-cbc가 구현되어 있지 않아 blowfish-cbc만 제공하는 서버는 접속할 수 없습니다.

4. CLI 옵션 전체 표

플래그 기본값 설명
-w <hostfile> (필수) 호스트 목록 파일 (# 주석, 공백/쉼표 구분, esxi[0001-0020] 등 NodeSet 범위 확장, 중복 제거). -w^파일·-w파일 지원
-u <계정> root SSH 접속 계정
-p <비밀번호> (없음) SSH 비밀번호 (키 인증 우선 시도 후 실패 시에만 폴백)
-i <경로 또는 호스트> 자동 탐색 -w와 함께 쓰면 SSH 개인키 경로. -w·명령 없이 단독 사용 시 해당 호스트 대화형 SSH 접속(호스트:포트 허용, 종료코드 원격 셸 준수 / 실패 시 255)
-P <포트> 22 SSH 포트 번호
-c <N> 1000 동시 접속 수 (명령어에 /user/ 감지 시 자동으로 450 제한)
-cf <N> 0 /user/ autofs 제한을 우회하여 강제 지정할 동시 접속 수
-b false 동일 출력 호스트 묶음 출력 (-script 시 비활성화)
-m false 60초 이상 실행 중/완료 호스트 행리스트 보기 (Enter 토글, 파이프/비터미널 시 무시)
-script false* 진행률/요약/ANSI 색상을 끄고 호스트: 출력줄만 출력 (*실행 파일명이 pdsh이면 기본 true)
-t <초> 15 SSH 접속(TCP+핸드셰이크+인증) 제한시간. 로그인 성공 후 명령 실행 시간에는 미적용 (재검증 로그인 제한은 최대 8초)
-pm false 본 명령 전 ~/.profile 내 anaconda 감지("OS 설치중" 제외) 및 특정 autofs 계정 접근 점검 (점검 10초 제한)
-dnlgjawkrdjqghkrdls false 위험 명령 강제 실행 승인 플래그 (대상 호스트 재입력 완전일치 대조 + y/N 확인 필요)
-tmp / -limit / -tl false /etc/tmpfiles.d/custom-tmp.conf 수정 / /etc/security/limits.conf 복사 / 두 작업 동시 실행 (명령 인자 없이 사용)
-rpm false 비교서버와 RPM 패키지(이름.아키텍처) 차이 비교 및 보고서/TSV 저장 (명령 인자 없이 사용)
-sv false 다중 조사 명령을 입력받아 표(표준출력 및 _survey.tsv/_survey.txt)로 수집 (명령 인자 없이 사용)
-h [옵션...] — 옵션 요약·상세 출력. 옵션명을 함께 주면(예: gossh -h -b) 해당 옵션 설명 및 모의 출력 예시 표시 (모르는 옵션은 exit 1)

5. 출력 형식 및 결과 파일 안내

실행이 끝나면 특이사항이 있는 호스트만 -w로 넘긴 파일명을 접두사로 사용해 압축 없이 한 줄에 호스트 하나씩 저장됩니다. 그대로 -w 인자로 넘겨 재실행할 수 있으며, 같은 위치에서 다시 실행할 때는 이번 실행이 생성할 수 있는 아래 5개 파일명만 시작 시 먼저 삭제합니다.

6. 위험 명령 가드 및 주의사항

위험 명령 차단 규칙 및 강제 실행 절차:

  • 부분일치 차단: reboot, poweroff, shutdown, halt, init 0, init 6, ddc
  • 독립 명령 단어 차단: kexec, systemctl kexec/rescue/emergency, isolate rescue/emergency.target, init 1/telinit 1, sysrq-trigger, ipmitool ... power off/reset/cycle, mkfs*, dd ... of=/dev/, wipefs, fdisk(fdisk -l 포함), parted(parted -l 포함), sgdisk, shred, rm -rf /, lvremove/vgremove/pvremove, ifdown, nmcli ... down, ip link set ... down, systemctl stop sshd/network/NetworkManager
  • 차단 시 종료코드 1로 즉시 중단됩니다. 강제 실행이 필요하면 -dnlgjawkrdjqghkrdls 플래그를 추가한 뒤, 화면에 출력된 대상 호스트와 동일하게 호스트 목록을 재입력(빈 줄 Enter로 종료)해 완전 일치를 통과하고 y를 입력해야 실행됩니다.
