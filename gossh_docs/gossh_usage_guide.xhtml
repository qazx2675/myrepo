이 문서는 gossh 를 처음 쓰는 사람을 위한 사용 가이드입니다. 옵션 전체, 결과 파일 전체, 위험 명령 목록은 같은 폴더의 gossh 상세 문서(gossh)를 보십시오.

1. gossh 는 무엇인가?

gossh 는 여러 서버(수백 대 이상)에 같은 명령을 한 번에 실행하는 도구입니다. gossh 는 결과를 모아서 보여 주고, 결과가 다른 서버를 골라 줍니다.

  • 일괄 점검: 서버 200대를 1대씩 확인하면 몇 시간이 걸립니다. gossh 는 한 번에 확인합니다. -b 를 쓰면 같은 결과를 묶으므로 문제가 있는 서버만 바로 보입니다.
  • 기준 비교: 기준 서버와 다른 서버의 설치 패키지(-rpm)와 설정(-tmp, -limit)을 비교하고 차이만 보고합니다.
  • 사고 방지: 재부팅(reboot) 같은 위험 명령은 기본으로 차단합니다.

2. gossh 는 어떻게 실행하나?

정기 자동 실행(크론탭) 안내

  • 매월 01일 00시에 자동 실행되도록 크론탭(crontab)에 등록되어 있습니다. 그전에 필터된 파일만 등록하십시오.
  • 업데이트 일시를 놓쳤다면 아래 수동 실행 방법으로 직접 실행하십시오.

gossh 는 서버에 이미 설치되어 있습니다. 아래 형태로 실행합니다. 명령은 반드시 따옴표로 묶으십시오.

bash [옵션] "<실행할_명령어>"]]>
  • 대상 서버 지정(-w, 필수): 파일(-w hosts.txt) 또는 범위 표기(-w esxi[0001-0020], -w web[01-20])를 씁니다. 같은 서버가 두 번 나오면 한 번만 실행합니다.

옵션언제 쓰나참고

-P <포트>SSH 포트를 바꿀 때기본값 22
-b같은 결과의 서버를 묶어서 이상 서버만 찾을 때—
-sv여러 명령의 결과를 호스트|결과 표로 저장할 때명령 인자 없이 실행
-lu시간 범위 안에 SSH 로 로그인한 계정을 서버별로 볼 때명령 인자 없이 실행
-rpm기준 서버와 설치 패키지(RPM)를 비교할 때명령 인자 없이 실행

-m60초 이상 끝나지 않는 서버를 실시간으로 볼 때Linux 터미널 전용
-script스크립트에서 결과만 받을 때색과 요약을 숨깁니다.
-c <개수>동시 접속 수를 바꿀 때기본 1000. 명령에 /user/ 가 있으면 450
-t <초>접속 대기 시간을 바꿀 때기본 15초
-dnlgjawkrdjqghkrdls차단된 위험 명령을 꼭 실행해야 할 때만서버 목록 재입력과 y 확인 필요

3. 상황별로 어떻게 쓰나? (Q&A)

Q1. 여러 서버의 상태(디스크, 메모리, 서비스)를 한 번에 확인하려면?

bash

-b 는 같은 결과의 서버를 하나로 묶습니다. 결과가 다른 서버만 따로 출력합니다.

Q2. 장애 때 여러 서버의 오류 로그를 한 번에 보려면?

bash

접속하지 못한 서버는 _res_off(접속 불가) 파일에 저장합니다. 접속을 거부한 서버는 _res_refsed(접속 거부) 파일에 저장합니다.

Q3. 여러 명령을 실행해서 보고서용 표를 만들려면?

bash

화면 안내에 따라 명령을 여러 개 입력합니다. 서버 1대로 미리 시험한 뒤 next 를 입력하면 모든 서버에서 실행합니다. 결과는 <hostfile>_survey.tsv(엑셀용)와 <hostfile>_survey.txt 에 저장합니다.

Q3-1. 어떤 계정이 서버에 SSH 로 로그인했는지 확인하려면?

bash

화면 안내에 따라 시작 시간과 끝 시간을 YYYYMMDDHH 형식으로 입력합니다(예: 2026111900, 2026111923). 서버의 /var/log/secure* 에서 범위 안에 SSH 로그인에 성공한 계정(root 제외)과 마지막 로그인 시각을 모읍니다. 결과는 화면과 <hostfile>_loginuser.txt 에 호스트|접속성공시간|계정 형태로 저장합니다. 접속하지 못한 서버는 호스트|-|-, 로그를 읽지 못한 서버는 호스트|!|! 입니다.

Q4. 기준 서버와 패키지나 설정이 같은지 비교·적용하려면?

  • 패키지 비교: gossh -w hosts.txt -rpm (차이는 _rpm_report.txt, _rpm_diff 에 저장)
  • 표준 설정 적용: gossh -w hosts.txt -tmp, -limit, 또는 -tl

Q5. 일부 서버가 끝나지 않고 멈춰 있으면?

  • -m 을 같이 써서 60초 이상 끝나지 않는 서버를 봅니다.
  • Ctrl+C 를 2번 누르면 멈춘 서버만 취소합니다. 취소한 서버는 _res_cancel 파일에 저장합니다.
  • Ctrl+C 를 3번 누르면 전체 작업을 멈추고 결과를 저장합니다.

4. 꼭 알아야 할 주의사항은?

  1. 파일 전송(SCP/SFTP) 기능은 없습니다. 파일 복사는 scp 또는 rsync 를 쓰십시오.
  2. 재부팅·종료 같은 위험 명령은 기본으로 차단합니다. 예: reboot, poweroff, shutdown, halt, init 0, init 6, ddc. 전체 목록은 gossh 상세 문서를 보십시오.
  3. 동시 접속 수(-c)는 기본값을 쓰십시오. 명령에 /user/ 가 있으면 시스템 부하를 막기 위해 동시 접속 수를 자동으로 450 으로 줄입니다.
  4. 설정을 바꾼 뒤에는 직접 확인하십시오. 서버 몇 대를 무작위로 골라 직접 접속하고 반영 여부를 확인하십시오.
