Confluence Intelligence 사용 권장

이 문서는 Confluence Intelligence에게 질문하여 원하는 작업을 빠르게 찾을 수 있도록 작성되었습니다. 직접 문서를 처음부터 읽지 않아도, 우측 상단 또는 하단의 Confluence Intelligence에게 아래처럼 질문해 보세요:

  • "서버 100대 디스크 용량을 한 번에 확인하려면 어떻게 해?"
  • "특정 서버만 패키지가 다르게 설치된 것 같은데 비교하는 방법 알려줘."
  • "gossh로 서버 재부팅 명령어를 실행할 수 있어?"

1. gossh란 무엇인가요?

gossh는 수백 대의 서버에 한 번에 같은 명령을 내리고, 그 결과를 한눈에 모아서 정상/이상을 자동으로 분류해 주는 일괄 작업 도구입니다.

  • 일괄 점검: 서버 200대의 디스크 용량이나 서비스 상태를 1대씩 접속해 확인하면 몇 시간이 걸리지만, gossh를 쓰면 한 번에 조회하고 정상 서버는 하나로 묶어(-b) 문제가 있는 2~3대만 즉시 골라낼 수 있습니다.
  • 기준 비교: 기준 서버와 다른 서버들의 설치 패키지(-rpm)나 시스템 설정(-tmp, -limit)이 다른지 자동으로 대조해 차이점만 리포트로 뽑아냅니다.
  • 사고 방지 안전장치: 실수로 전체 서버를 재부팅(reboot 등)하는 대형 사고를 막기 위해 위험 명령어는 기본적으로 차단되어 있습니다.

2. 기본 사용법 (바로 실행하기)

이미 서버에 설치되어 있는 gossh 명령어를 바로 실행합니다.

bash [옵션] "<실행할_명령어>"]]>
  • 대상 서버 지정 (-w, 필수)
    • 파일로 지정: -w hosts.txt
    • 범위 패턴으로 지정: -w esxi[0001-0020] 또는 -w web[01-20] (중복 호스트는 자동 제거)

자주 쓰는 옵션 한눈에 보기

옵션 무엇을 할 때 쓰나요? 비고
-w <대상> 명령을 실행할 서버 목록이나 패턴 지정 필수
-u <계정> 접속할 사용자 계정 지정 기본값: root
-p <비밀번호> 비밀번호로 접속할 때 지정 키 인증 우선 시도 후 사용
-i <키경로> 특정 SSH 개인키 파일 지정 미지정 시 기본 키 자동 탐색
-P <포트> SSH 접속 포트 지정 기본값: 22
-b 결과가 같은 서버들을 하나로 묶어서 출력 이상 서버만 빠르게 찾을 때 유용
-sv 여러 명령어를 대화형으로 입력받아 호스트|결과 표로 저장 gossh-standalone 버전 전용
-rpm 기준 서버와 대상 서버의 설치 패키지(RPM) 차이 비교 명령어 없이 실행
-tmp, -limit, -tl /tmp 정리 및 limits.conf 표준 설정 일괄 적용 명령어 없이 실행
-pm 작업 전 OS 설치 중이거나 마운트 이상이 있는 서버 사전 확인 _os_install, _nosvrauto 생성
-m 60초 이상 응답 없는(멈춘) 서버 실시간 확인 Linux 전용
-script 자동화 스크립트에서 결과만 깔끔하게 파싱할 때 사용 색상 및 요약 숨김
-c <개수> 동시에 접속할 서버 수 조절 기본 1000 (/user/ 경로 시 450 제한)
-t <초> 로그인 대기 시간 제한 기본값: 15초
-dnlgjawkrdjqghkrdls 차단된 위험 명령어(reboot 등)를 정말 실행할 때만 추가 오타/실수 방지용 안전장치

3. 상황별 실무 활용 예시 (Q&A)

Q1. 수십~수백 대 서버의 상태(디스크, 메모리, 서비스)를 한 번에 확인하고 싶어요.

bash
  • -b 옵션을 붙이면 정상적으로 같은 결과를 낸 서버들은 하나로 묶어 보여주고, 다른 결과를 낸 이상 서버만 따로 돋보이게 출력해 줍니다.

Q2. 장애가 났을 때 여러 서버의 에러 로그를 한 번에 보고 싶어요.

bash
  • 접속이 안 되거나 거부된 서버는 자동으로 _res_off(접속 불가), _res_refsed(접속 거부) 파일로 따로 저장되므로, 미응답 서버 목록을 즉시 파악할 수 있습니다.

Q3. 여러 명령어를 순서대로 실행해서 보고서용 표(호스트|결과)로 뽑고 싶어요.

bash
  • (gossh-standalone 버전 지원) 실행 후 안내에 따라 명령어를 여러 개 입력하면 모든 서버에서 실행한 뒤 결과를 표 형태로 저장해 줍니다.

Q4. 기준 서버와 다른 서버의 설치 패키지나 시스템 설정이 같은지 비교·적용하고 싶어요.

  • 패키지 비교: gossh -w hosts.txt -rpm (차이점을 _rpm_report.txt, _rpm_diff로 저장)
  • 표준 설정 적용: gossh -w hosts.txt -tmp 또는 -limit, -tl

Q5. 작업 중에 일부 서버가 응답 없이 멈춰 있을 때는 어떻게 하나요?

  • Linux 환경에서는 -m 옵션을 함께 써서 60초 이상 응답 없는 서버를 확인할 수 있습니다.
  • Ctrl+C를 눌러 작업을 중단하면 미완료된 서버 목록이 _res_cancel 파일에 저장됩니다.

4. 꼭 알아둘 주의사항

  1. 파일 전송(SCP/SFTP) 기능은 없습니다.

    gossh는 명령어 일괄 실행 도구입니다. 일반 파일이나 프로그램을 서버로 복사할 때는 scp나 rsync 등 다른 도구를 사용하세요.

  2. 재부팅/종료 같은 위험한 명령어는 기본 차단됩니다.

    reboot, poweroff, shutdown, halt, init 0, init 6, ddc 명령은 실수 방지를 위해 실행이 막혀 있습니다.

  3. 동시 접속 수(-c)는 가급적 기본값을 유지하세요.

    경로에 /user/가 포함된 경우 시스템 부하를 막기 위해 자동으로 동시 접속 수를 450으로 제한합니다.
