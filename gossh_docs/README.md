# gossh 문서 안내

- **도구 이름**: gossh (병렬 SSH 실행 도구 v2). 같은 실행 파일을 pdsh 이름으로도 씁니다.
- **하는 일**: 여러 서버(수천 대)에 같은 명령을 동시에 SSH 로 실행합니다. 결과를 호스트: 출력줄 형태로 모아서 출력합니다.
- **본문 파일**: [`gossh.xhtml`](./gossh.xhtml), [`gossh_usage_guide.xhtml`](./gossh_usage_guide.xhtml)
- **작성 방식**: ASD-STE100 규칙(짧은 문장, 한 단계에 한 동작, 도구 이름 반복)의 질문-답변 형식. Confluence Intelligence 가 각 절만 읽어도 답할 수 있도록 작성했습니다.

## Confluence 에 붙여 넣는 방법

1. `.xhtml` 파일 전체 내용을 복사합니다. `<root>` 래퍼가 없는 Storage Format 본문 조각입니다.
2. Confluence 페이지를 편집 모드로 열고 **Source Editor (`<>`)** 를 엽니다.
3. 복사한 내용을 붙여 넣고 **Apply** 를 누릅니다.
4. `info`·`warning`·`note`·`code`·`toc` 매크로와 표가 정상인지 확인하고 저장합니다.
   - `gossh_usage_guide.xhtml` 은 첨부 이미지 `workflow.svg` 를 페이지에 첨부해야 그림이 보입니다.

## 본문 구성

`gossh.xhtml`:

- 0. 도구 요약 (핵심 사실)
- 1. 어떤 일을 하려면 어떤 명령을 실행하나? (명령 찾기)
- 2. 처음 사용하기 전에 무엇을 준비하나?
- 3. 기본 명령 실행은 어떻게 하나?
- 4. 같은 결과 묶기(-b)는 어떻게 쓰나?
- 5. 여러 명령의 조사 표(-sv)는 어떻게 만드나?
- 5-1. 접속 user 조회(-lu)는 어떻게 하나?
- 6. 기준 서버와 비교·설정 복사(-rpm, -tmp, -limit, -tl)는 어떻게 하나?
- 7. 한 서버에 대화형으로 접속(-i <호스트>)하려면?
- 8. 실행 중에 어떻게 제어하나? (-m, Ctrl+C)
- 9. OS 설치 중 서버 거르기(-pm)와 autofs 보호는 무엇인가?
- 10. 위험 명령은 어떻게 차단되나? (강제 실행 절차)
- 11. 옵션·결과 파일 참고표
- 12. 문제가 생기면?
- 13. 자주 묻는 질문 (FAQ)

`gossh_usage_guide.xhtml`:

- 1. gossh 는 무엇인가?
- 2. gossh 는 어떻게 실행하나?
- 3. 상황별로 어떻게 쓰나? (Q&A)
- 4. 꼭 알아야 할 주의사항은?
