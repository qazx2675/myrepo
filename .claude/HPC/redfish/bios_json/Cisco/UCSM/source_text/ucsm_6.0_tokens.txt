Server BIOS Tokens in Release 6.0(2b)
          This document provides new and changed server BIOS token information in Cisco UCS Manager release,
          6.0(2b). The servers supported in this release 6.0(2b) continue utilizing the BIOS tokens from the previous
          release.
          For detailed information on server-specific tokens introduced in earlier versions, refer Cisco UCS Server
          BIOS Tokens, Release 4.3 and Cisco UCS Server BIOS Tokens, Release 4.2
          Cisco UCS Manager supports the following servers in 6.0(2b):
             • Cisco UCS 410c M8 Compute Node



          Note   This platform is supported from 6.0(2b) onwards.

             • Cisco UCS X210c M8 Compute Node
             • Cisco UCS X215c M8 Compute Node
             • Cisco UCS C240 M8 Server
             • Cisco UCS C220 M8 Server
             • Cisco UCS C245 M8 Server
             • Cisco UCS C225 M8 Server
             • Cisco UCS X410c M7 Compute Node
             • Cisco UCS X210c M7 Compute Node
             • Cisco UCS X210c M6 Compute Node
             • Cisco UCS C240 M7 Server
             • Cisco UCS C220 M7 Server

Server BIOS Tokens in Release 6.0(1b)
                        This document provides new and changed server BIOS token information in Cisco UCS Manager release,
                        6.0(1b). The servers supported in this release 6.0(1b) continue utilizing the BIOS tokens from the previous
                        release and no new servers are added in this release.
                        For detailed information on server-specific tokens introduced in earlier versions, refer Cisco UCS Server
                        BIOS Tokens, Release 4.3 and Cisco UCS Server BIOS Tokens, Release 4.2
