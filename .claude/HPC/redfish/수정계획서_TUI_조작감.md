# 수정 계획서 — TUI 조작감 개선

대상: `biostool bios` 대화형 화면 (`cmd/biostool/tui_view.go`, `tui_flow.go`, `tui_render.go`).
범위: 키·진행 순서·안내 문구만. 점검·비교·설정 로직과 결과 파일은 바꾸지 않는다.

## 1. 찾은 문제 (사용 순서대로)

| # | 어디서 | 지금 동작 | 왜 끊기는가 |
|---|---|---|---|
| A | 모든 화면 | 뒤로·취소 키가 화면마다 다름. 메뉴: Esc/q/Ctrl+X, 한 줄 입력: Esc/Ctrl+X, 여러 줄 입력: Ctrl+X 만(Esc 는 안내만), y/n: Esc/Ctrl+X, 결과 화면: q/Esc(Ctrl+X 는 안내만) | 화면이 바뀔 때마다 "여기선 뭘 눌러야 나가지"를 다시 읽어야 함 |
| B | 대상·비교서버·BIOS 값 붙여넣기 | 완료가 Ctrl+D 뿐 | 다른 입력은 Enter 로 끝나는데 여기만 다름. Cisco 대상이 없을 때도 Ctrl+D |
| C | 대상 입력 | 3칸 줄 오류·대상 없음·파일 못 찾음·Cisco 단계 취소·프로파일에서 뒤로 → 첫 메뉴로 돌아가고 넣은 내용이 사라짐 | 한 글자 고치려고 메뉴 선택 + 붙여넣기를 처음부터 다시 |
| D | 결과 화면 | 위 줄(벤더)이 하나뿐이어도(전부 태그면 "태그" 하나) ←→ 가 아무 일도 안 함. Enter 를 눌러야 태그 이동 | 태그를 쓰면 매번 Enter 를 먼저 눌러야 함. 재비교·재점검 뒤에는 위치·필터도 처음으로 돌아감 |
| E | 수정 미리보기·설정 결과 등 글 화면 | q/Esc 만 닫힘, Enter 는 반응 없음. "q 돌아가기"를 누르면 재점검이 시작됨 | 다음으로 가려고 "돌아가기"를 눌러야 함 |
| F | 전체 설정 비교 직후 | 모델이 다른 대상이 있으면 y/n 질문이 끼어듦 (태그마다 한 번씩) | 결과를 보기도 전에 질문에 답해야 함 |
| G | 첫 메뉴(대상 입력) | q/Esc 한 번에 프로그램 종료 | 결과 화면은 q 두 번인데 여기는 한 번 — 실수로 끝남 |
| H | 한 줄 입력(대상 파일) | 기본값이 채워져 있고 지우려면 Backspace 연타 | 전체 지우기 키 없음 |
| I | Pending 질문 | y 포함 / n 제외하고 진행 / Ctrl+X 취소 | 다른 질문의 n 은 "하지 않음"인데 여기만 "제외하고 진행" |
| J | 진행 줄 | `[2/4 접속·조회]`, `[3/4 CSV 저장]` 뒤로는 번호 없음 | 1/4·4/4 가 없어 단계 수가 맞지 않음 |

## 2. 개선안

- **A 키 규칙 통일**: Esc = 어디서나 한 단계 뒤로, Ctrl+X = 진행 중 작업 취소·입력 버리기, q = 결과 화면에서만 뒤로/종료.
  여러 줄 입력의 Esc 는 내용이 없으면 바로 뒤로, 있으면 "한 번 더 Esc 면 버림".
- **B 빈 줄 Enter 로 완료** (Ctrl+D 도 유지). 붙여넣기 중간의 빈 줄은 완료로 보지 않는다 (같이 들어온 키가 뒤에 더 있으면 무시).
- **C 입력 유지**: 오류가 나면 같은 입력 칸에 머물고 넣었던 줄을 그대로 다시 보여 준다. 프로파일에서 뒤로 와도 앞의 대상이 남는다.
- **D 위 줄이 하나면 바로 아래 줄 이동**: ←→ 가 곧바로 태그/관리망을 움직인다. 재비교·재점검 뒤에도 같은 이름의 벤더·태그·필터를 유지한다.
- **E 글 화면은 Enter 로도 닫힘**, 안내는 "Enter 계속".
- **F 모델 다른 비교**: 질문 대신 안내 줄 + 키로 원할 때 실행 (인터뷰에서 결정).
- **G 첫 메뉴 종료 확인**, **H Ctrl+U 전체 지우기**, **I Pending 질문을 3개 메뉴로**, **J 단계 번호 정리** (인터뷰에서 선택).

## 3. 인터뷰 결정 (2026-11-11)

| 항목 | 결정 |
|---|---|
| A 키 통일 · C 입력 유지 · E 글 화면 Enter 닫기 | 넣음 |
| B 여러 줄 입력 완료 | 빈 줄 Enter 로 완료 (Ctrl+D 유지, 붙여넣기 중 빈 줄은 완료 아님) |
| D 위 줄이 하나일 때 | Enter 없이 ←→ 로 바로 태그/관리망 이동, 재비교·재점검 뒤 위치·필터 유지 |
| F 모델 다른 비교 | 질문 없음. 안내 줄 + `x` 키를 누를 때만 참고용 CSV |
| G·H·I·J | 넣지 않음 |
| 가독성 (추가) | 키 안내 줄 정리(키 강조·설명 회색·묶음) / 입력 칸 제목 짧게 + 형식·예시 줄 / 맨 위 지금 단계 표시 / 구분선과 [질문]·[안내] 표시 |

## 4. 작업 단계

1. 입력 상자 (`tui_view.go`, `tui_keys.go`): A·B, 처음 내용이 있는 여러 줄 입력, 제목 아래 형식·예시 줄 + 테스트
2. 흐름 (`tui_flow.go`): C·E·F(x 키), 입력 칸 제목 짧게, 지금 단계 표시 호출 + 테스트
3. 결과 화면 (`tui_view.go`, `tui_render.go`): D, 키 안내 줄·단계 줄·구분선·[질문]/[안내] + 도움말 + 테스트
4. 랩 `go vet`·`go test`, os8 바이너리 재빌드, README·사용법.txt·CHANGELOG, bios-collect push

## 5. 바꾸지 않는 것

- Tab = 화면 전환, ←→ = 벤더, Enter = 아래 줄로 (벤더가 2개 이상일 때는 지금과 같음)
- 설정 적용 확인은 y 를 직접 눌러야 함 (Enter 로 적용되지 않음)
- 명령행 옵션, 결과 파일 이름·내용
