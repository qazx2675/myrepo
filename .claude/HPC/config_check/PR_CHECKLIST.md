# PR 체크리스트 (config_check)

이 스크립트는 bash 단일 파일이라 빌드 대신 문법 검사와 시나리오 검증을 합니다.

- [ ] `bash -n config_check.sh` 통과
- [ ] `shellcheck`가 있으면 실행하고 새 경고가 없음
- [ ] 폐쇄망에서 폴더 그대로 실행 가능 (외부 의존 없음, gossh v2만 필요)
- [ ] 실제 gossh v2로 최소 1개 시나리오 검증 (정상 호스트 + 없는 호스트(pingX) 혼합)
- [ ] 아래 시나리오 중 변경과 관련된 것을 확인
  - [ ] 공백/줄바꿈 혼용 목록, 중복 호스트
  - [ ] 30행 단위 열 출력, prefix 집계
  - [ ] LDAP 1종 / 2종 이상 / 미확인 / 없음
  - [ ] FAIL 출력, `NO FAIL`
  - [ ] `n` / `y` / `set` (스크립트 2개 / 3개가 각 호스트에서 1번씩 실행되는지)
  - [ ] 벤더별 코멘트(D·L·J·T·W), 전체 정상 공통 코멘트
  - [ ] DHCP(원격 파일이 남지 않는지), usb0, VWP, AI 서버
  - [ ] pingO_sshx / nosvrauto / os_install 분류와 기타 상태 요약
  - [ ] Ctrl+C(gossh 실행 중 / 프롬프트 대기 중), 종료 후 `/tmp/config_check.*` 없음
- [ ] 설정 변경이 포함되면 실제 서버 몇 대에서 반영 여부를 직접 확인
- [ ] `CHANGELOG.md` 갱신
- [ ] `README.md` 표(변수, 출력 항목)와 `ARCHITECTURE.md` 표가 코드와 일치
- [ ] 설정 블록의 값(호스트명, 경로, 서버 주소)이 비어 있거나 예시 값임 (실제 값을 커밋하지 않음)
