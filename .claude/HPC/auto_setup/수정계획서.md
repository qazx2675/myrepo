# auto_setup v0.8.0 · awx_script 수정계획서

인터뷰(2026-10-12) 결과를 정리한 문서입니다. **승인 후** 결함 수정과 신규 기능을 함께 구현합니다.
가정 항목은 9장에 확정 내용을 반영했습니다. 10장(메뉴 구조)만 새로 확인이 필요합니다.

## 0. 공통 원칙

- 기존 빈 변수·`auto_setup.conf` 값은 건드리지 않습니다. 새 변수는 **빈 값으로 추가만** 하고, 비어 있으면 기존과 똑같이 동작합니다.
- 새 변수는 `conf/update_v0.8.0.sh` 로 현장 conf 에 추가합니다. 앵커 방식이고 `--dry`·`--undo` 를 지원합니다.
- 노드 서비스·데몬 재시작은 하지 않습니다. bindpw 는 어디에도 출력하지 않습니다.
- 바이너리 재빌드 대상
  - `auto_setup_os6` 는 .60(Go 1.20)에서 다시 빌드해 커밋합니다.
  - 엔진 두 개는 소스 변경이 없으면 그대로 둡니다.
- 버전과 태그
  - 버전: auto_setup **0.8.0**, awx_script 는 CHANGELOG `[Unreleased]` 에 추가합니다. 다른 세션의 미배포 항목이 이미 있어 버전 번호는 붙이지 않습니다.
  - 태그: `auto_setup-v0.8.0` 을 만들고, 태그 메시지에 CHANGELOG 항목을 연결합니다.

## 1. 결함 수정 (v0.7.3 점검 결과 ①②③)

### ① 시간 제한
- 준비확인과 `g` 의 gossh 호출(os8)·`ssh os6_mgmt` 호출(os6)에 전체 시간 제한 **60초** 를 겁니다. 시간이 지나면 프로세스 그룹을 종료합니다.
  - 시간 초과된 호스트는 무응답으로 처리하고, 사유는 `시간 초과(60초)` 로 표시합니다.
- ssh 옵션은 다른 경로와 같게 `-o BatchMode=yes -o ConnectTimeout=10` 으로 맞춥니다.
- 60초는 상수입니다 (확정). ldapbk 의 90초/45초와 같은 방식이고, conf 변수는 만들지 않습니다.

### ② csh 영향 제거
- os6_mgmt 로 보내는 원격 명령을 모두 공통 함수 하나로 감쌉니다.
  - 감싸는 형태: `bash -c '<명령>'`
  - 명령 안의 `'` 는 `'\''` 로 바꿉니다.
- 적용 경로 6곳: 준비확인, os_check run, 2차 체크, LDAP 백업·복원, 클라이언트 중계, 변경 엔진.
- 그래서 os6_mgmt 의 로그인 셸이 csh/tcsh 라도 `$(...)`·`${f}` 가 bash 에서 해석됩니다.
- awx_script 01/02 의 os6 경로는 이미 `bash <파일>` 방식이라 영향이 없습니다. 점검만 하고 고치지 않습니다.

### ③ gossh 출력 해석 통일 + 따옴표
- gossh 출력 해석을 함수 하나로 합칩니다. 지금은 준비확인 `parseCheck` 와 LDAP `splitGossh` 가 따로 해석합니다.
  - ANSI 색을 제거합니다.
  - `호스트: 내용` 형식을 분리합니다.
  - `ERROR: 종료코드 N` 줄과 `SSH 접속 실패: …` 줄을 사유로 인식합니다.
- 호스트명 일치 규칙
  - 정확히 같은 이름이 없으면 **짧은 이름**(첫 `.` 앞)으로 다시 맞춥니다. FQDN 과 짧은 이름이 섞여도 응답을 놓치지 않게 하려는 것입니다.
  - 짧은 이름이 둘 이상과 겹치면 맞추지 않습니다.
- 인식 실패 기록
  - 출력은 있는데 호스트를 하나도 인식하지 못하면, 원본 앞 5줄을 `auto_setup.log` 에 `[!] gossh 출력 해석 실패` 로 남깁니다.
  - g 결과 상세 열에도 `출력 형식 불일치` 로 표시합니다.
- 따옴표
  - `os6_gossh` 경로와 원격 명령 인자는 모두 셸 인용 함수(`shq`)를 거칩니다.
  - 경로에 공백이나 `'` 가 있어도 깨지지 않습니다.

## 2. 신규 설치 양식 생성 (TUI `w` 메뉴 2번 / CLI `auto_setup newhost`)

nodeinfo 를 쓸 수 없는 신규 설치 서버에 씁니다. 엔지니어에게 받은 **hostname ip mac** 만으로 01 의 12필드 양식(`${user}.txt`)을 만들고, nodeinfo 는 자동으로 **N** 입니다.

### 2-1. 템플릿
- 양식 그대로 보여 줍니다. hostname ip mac 자리는 고정 표시입니다.
  ```
  1 [A]   tmp tmp sec <hostname> <ip> <mac> bond sda sda5       500 8.10 uefi   (sec-bond-sda-500-8.10-uefi)
  2 [mec] tmp tmp mec <hostname> <ip> <mac> eth0 sda sda5       500 9.6  uefi   (mec-eth0-sda-500-9.6-uefi)
  3       tmp tmp mec <hostname> <ip> <mac> eth0 nvme nvme0n1p8 400 9.6  uefi   (mec-eth0-nvme-400-9.6-uefi)
  ```
- 이름은 값으로 자동 생성합니다(`sec-bond-sda-500-8.10-uefi`). 원하면 짧은 별칭(`A`, `mec` 등)을 붙일 수 있습니다.
- root 파티션은 디스크로 고정해서 표시합니다: sda → `sda5`, nvme → `nvme0n1p8`.
- 저장 위치
  - **conf 공용**: 새 빈 변수 `newhost_template_1` ~ `newhost_template_9`. 형식 `별칭|infra nic disk 용량 os boot` (예 `A|sec bond sda 500 8.10 uefi`).
  - **user 별**: 화면에서 `+` 로 만든 템플릿은 `<AUTO_SETUP_DIR>/newhost/<user>/templates` 에 자동 저장되고, 다음에도 그대로 보입니다.
- 값 검사
  - disk 는 `sda`/`nvme` 만, 용량은 숫자만 받습니다.
  - boot 는 `uefi`/`legacy`/`레거시` 만 받습니다 (01 이 `레거시` 를 legacy 로 바꾸므로 둘 다 허용).
  - infra·nic·os 는 형식만 봅니다 (공백 불가).

### 2-2. 흐름
1. **user**
   - `-user` 로 실행했으면 그 user 를 씁니다.
   - 아니면 세션 user 를 씁니다(§5). 없으면 처음 한 번 고르게 합니다.
2. **붙여넣기**: `hostname ip mac` 을 한 줄에 한 대씩 넣습니다. 빈 줄이나 `.` 으로 끝냅니다.
   - 구분자는 공백·탭·쉼표 무엇이든 됩니다. 순서가 달라도 IP·MAC 패턴으로 자동 구분합니다.
   - MAC 은 `-` 를 `:` 로 바꾸고, 구분자 없는 12자리는 `:` 를 넣습니다. 대소문자는 **소문자로 변환**합니다 (확정).
   - 형식 오류, 목록 안의 hostname·IP·MAC 중복은 빨갛게 표시하고, 고치기 전에는 다음으로 넘어가지 않습니다.
3. **템플릿 지정**: 표 아래에 한 줄로 적습니다.
   ```
   svr001-020=1  svr021-023=mec  svr024-043=3
   ```
   - 범위(`svr001-020`), 패턴(`spice*`), 행 번호(`1-20`), 전체(`*`) 를 쓸 수 있습니다.
   - 오른쪽 값은 번호·별칭·자동이름 중 무엇이든 됩니다. 나중 지정이 앞 지정을 덮어씁니다.
   - **개별 수정**: `svr005 os=9.6`, `svr001-005 nic=eth0` 처럼 열 하나만 바꿀 수 있습니다.
   - **지정이 없는 행**: 이력 추천값을 노란색 `추천` 으로 채웁니다.
     - 이력은 이 기능으로 만든 과거 양식 + awx_dir 의 `${user}.txt` 백업(모든 user)입니다.
     - hostname 에서 숫자를 뺀 접두어가 가장 길게 일치하는 가장 최근 기록을 고릅니다.
   - 그래도 값이 없는 행은 빈 칸(빨강)이고, 저장할 수 없습니다.
4. **DNS 점검**: §3 규칙대로 합니다. 불일치가 있으면 표를 보여 주고 `a` 모두 DNS 로 / `n` 그대로 / `s` 하나씩 / `q` 중단 중에서 고릅니다.
5. **미리보기**: 12필드 줄을 템플릿별로 묶어 보여 줍니다. `추천` 행과 DNS 로 바꾼 행은 색으로 표시합니다.
   - `y` 를 누르면 `awx_dir/${user}.txt` 에 저장합니다.
   - 기존 파일은 `<AUTO_SETUP_DIR>/newhost/<user>/backup/<시각>.txt` 로 백업하고, 같은 내용을 이력에도 남깁니다.
6. **저장 후 다시 확인**: 저장된 내용을 다시 보여 주고 `AWX 실행할까요? [y/n]` 을 묻습니다.
   - `y` 면 기존 `w` 흐름으로 이어집니다. 프로파일을 고를 수 있습니다.
   - 이때 **nodeinfo 는 프로파일과 상관없이 N 으로 강제**하고, 대상 서버 목록은 방금 만든 hostname 들로 자동 입력합니다.

## 3. DNS 점검 (awx_script 01 + 양식 생성, 같은 규칙)

- **기준값**: `/etc/resolv.conf` 의 각 DNS 서버(최대 3)에 **직접** A 레코드를 묻고, 그 답을 기준으로 합니다. `/etc/hosts`·getent 는 쓰지 않습니다.
- 판정
  - **DNS 사용 가능**: 목록 중 1대라도 어느 DNS 서버에서든 답을 받으면 점검합니다. 전부 실패하면 `DNS 조회 불가 — 점검 생략` 한 줄만 출력하고 기존대로 진행합니다.
  - **일치**: 응답한 서버들의 답이 같고 IP 가 1개이며 등록 IP 와 같으면 정상입니다.
  - **불일치**: 기준 IP ≠ 등록 IP 이면 표에 나오고 교체를 고를 수 있습니다.
  - **판단 불가**: 서버끼리 답이 다르거나 A 레코드가 여러 개면 경고만 하고 자동 교체 대상에서 뺍니다.
  - **미등록**: NXDOMAIN 이면 `미등록` 표시만 하고 점검에서 뺍니다.
- **중복 경고**: 불일치 호스트의 잘못 등록된 IP 에 대해 아래 두 가지를 확인합니다.
  1. 목록 안에서 다른 hostname 이 같은 IP 를 쓰는지
  2. 그 IP 의 DNS 역조회(PTR)나 목록 안 다른 호스트의 DNS 기준 IP 가 다른 hostname 을 가리키는지
  - 해당하면 `⚠ 1.1.1.2 는 svr0002 의 IP` 처럼 추가 경고를 냅니다.
- 출력 예
  ```
  hostname  등록IP   DNS IP   비고
  svr0001   1.1.1.1  1.1.1.2  ⚠ 등록IP 1.1.1.1 은 svr0005 의 IP (DNS)
  a 모두 DNS 로 / n 그대로 / s 하나씩 / q 중단 :
  ```
- **속도**
  - 동시 32개로 조회하고 질의당 2초, 재시도 1회입니다. PTR 은 불일치 IP 만 묻습니다.
  - 1000대 기준 10초 안쪽을 목표로 합니다.
- 구현
  - **01 (bash)**: `dig +short +time=2 +tries=1 @서버` 를 우선 쓰고, 없으면 `nslookup`, 둘 다 없으면 `DNS 도구 없음 — 점검 생략` 입니다. `xargs -P 32` 로 병렬 실행합니다.
    - 위치는 `[4] fix_mac` 다음, `[5] 대상 출력`(작업진행 Y/N) 전입니다.
    - 교체는 `${user}.txt` 5번째 필드를 바꾸고 LOG 에 `[DNS] svr0001 1.1.1.1 -> 1.1.1.2` 로 남깁니다.
  - **auto_setup (Go)**: 순수 Go DNS 질의를 씁니다(외부 명령 없음, 같은 규칙).
  - **auto 모드(AWX_AUTO=1)** (확정): stdin 이 `/dev/null` 이므로 질문은 **`/dev/tty`** 로 받습니다.
    - 불일치가 나오면 경고 표를 출력하고 `등록값 그대로 계속 진행할까요? [y/N]` 을 묻습니다. `y` 면 진행하고, 그 외에는 중단합니다.
    - 터미널이 없어(`/dev/tty` 를 열 수 없음) 물을 수 없으면 중단합니다.
    - auto_setup 양식 생성에서 이미 점검·결정한 경우에는 `AWX_DNS_CHECKED=1` 을 넘기고, 01 은 표만 출력하고 묻지 않고 진행합니다.

## 4. gossh 작업 기록 (TUI `s` / CLI `auto_setup s`)

"zz, bb, fc 로 만든 파일에 뭘 했는지" 를 잊지 않게 합니다. **user 별** 로 남습니다.

### 4-1. 화면
```
[user: alice] gossh 작업                              n 새 작업  / 호스트 검색  Enter 선택  q 닫기
 qkz : svr001 등 20대                                  (메모: LDAP 재적용 대상)
   ├ 10/12 14:02 os8      cat /proc/uptime             성공 18 실패 0 접속불가 2(os6 재실행 → 성공 2)
   └ 10/12 14:10 os8      systemctl is-active sssd     성공 20
 fbw : spice101 등 1,200대
   └ 10/12 15:30 os6 전량 rpm -q kernel                성공 1,198 접속불가 2
```
- **새 작업 `n`**
  - 호스트를 붙여넣습니다. 이미 같은 목록이 있으면 `qkz 와 같은 목록(20대) — 재사용? [y/n]` 을 묻습니다.
  - 새 목록이면 `/tmp/<소문자 3자리 임의>` 파일을 만듭니다. 이미 있는 이름은 피합니다.
  - 명령을 입력하면 TUI 를 잠시 떠나 터미널에서 gossh 를 그대로 실행합니다. 출력·색·위험어 확인도 그대로입니다. 끝나면 목록으로 돌아옵니다.
- **항목 선택**: 같은 파일로 새 명령 / 재실행 / 실패·접속불가 호스트만 재실행 / 결과 다시 보기(`less -R`) / 메모 / 호스트 목록 보기.
- **`/` 검색**: `svr015` → 그 호스트가 들어 있던 작업과 명령을 시간순으로 보여 줍니다.
- **세션 이동**: 터미널을 옮겨도 같은 user 로 열면 같은 목록이 보입니다. 각 실행 줄에 터미널(pts)·서버·작업 위치를 함께 기록합니다.

### 4-2. 실행 위치
- 기준 대수는 새 빈 변수 `work_os6_over` 입니다. 비어 있으면 1000 입니다.
  - **1000대 이하**: os8 gossh 로 실행하고, 접속불가 호스트는 os6_mgmt 경유로 자동 재실행합니다.
  - **1000대 초과**: 전량 os6_mgmt 경유로 실행합니다.
- (확정) os6_mgmt 에서 auto_setup 을 연 경우에는 대수와 상관없이 os6 gossh 로 바로 실행합니다. 기록은 os8_mgmt 로 중계합니다.
- os6 경유 실행은 호스트 목록을 base64 로 넘기고 `ssh -t` 로 실행합니다. 출력과 위험어 확인이 그대로 보이고, ②의 `bash -c` 감싸기가 적용됩니다.

### 4-3. 기록 보관
- 위치: `<AUTO_SETUP_DIR>/work/<user>/` (디렉터리 0700, 파일 0600). 호스트 목록 사본도 함께 둬서 `/tmp` 파일이 지워져도 재실행할 수 있습니다.
- **요약**은 영구 보관합니다: 시각, 터미널, 서버, 경로, 명령, 성공/실패/접속불가 호스트.
- **전체 출력**은 압축해서 보관하고 **7일 지나면 폐기**합니다. 데몬이 하루 한 번 정리하고, (확정) user 당 200MB 를 넘으면 오래된 것부터 지웁니다. `/tmp/<3자리>` 파일도 7일 지나면 함께 정리합니다.
- 출력 수집은 `script -q -f -c` 로 tty 를 유지한 채 저장합니다(색 유지). 성공/실패는 gossh 의 `ERROR: 종료코드`·`SSH 접속 실패` 줄과 결과 파일(`<f>_res_off` 등)로 판정합니다.

## 5. 세션 user

- `auto_setup -user <이름>` 으로 실행하면 그 user 를 씁니다 (v0.7.3 그대로).
- 옵션 없이 실행했으면 **gossh 작업(`s`)·신규 설치 양식(`w`→2)을 처음 열 때** `이 세션에서 사용할 user` 를 한 번 고르게 하고(info_mn.sh 목록), TUI 를 닫을 때까지 기억합니다.
  - CLI `auto_setup s`/`newhost` 는 시작할 때 묻습니다.
- 헤더에는 `[user: alice]` 를 표시합니다.
- 체크스크립트 단독 실행·AWX 실행·변경 작업은 요청하신 대로 기존처럼 매번 묻습니다. 단 신규 설치 양식 → AWX 실행으로 이어질 때는 같은 user 로 자동 진행합니다.

## 5-1. 키 정리: 항목별 메뉴 (`m` 같은 인라인 메뉴를 분야별로)

기능이 늘어 안내 줄이 길어졌으므로, `m` 과 같은 **인라인 메뉴**를 분야별로 둡니다.
- 메뉴 안의 선택 글자는 **기존 단축키와 같은 글자**를 씁니다. 예를 들어 예전 `c` 는 이제 `h` → `c` 입니다.
- 기존 단축키(c t g v d x)는 **그대로 동작**합니다. 안내 줄에서만 빠지고 메뉴와 `?` 도움말에 표시합니다. 손에 익은 키는 그대로 쓰면 됩니다.

| 키 | 메뉴 이름 | 항목 (번호 또는 글자로 선택, `Esc`·같은 키로 닫기) |
|---|---|---|
| `h` | 호스트 작업 (화면 2) | `c` 체크+수정 · `t` 체크만 · `g` 재확인 · `d` 수동 완료 · `v` 결과 보기 |
| `w` | AWX | `1`/`w` AWX 실행(기존 w) · `2` 신규 설치 양식 · (예정) `3` 킥스타트 파티션 변경 |
| `m` | 변경 작업 | 기존 그대로 (IP·LDAP·IP+LDAP·원복·auto.appl 원복) |
| `s` | gossh 작업 | 메뉴 없이 작업 목록 화면이 바로 열림 (§4) |
| `x` | 체크스크립트 단독 실행 | 기존 그대로 |

- `w` 는 이제 바로 실행하지 않고 메뉴가 열립니다. `w` 를 한 번 더 누르거나 `Enter`/`1` 을 누르면 예전처럼 AWX 를 실행합니다.
- 안내 줄 예시
  - 화면 2: ` ↑↓ 이동  ← 목록  f 정체·실패만  a 전체 그룹  r 새로고침  ? 도움말  q 복귀` / ` h 호스트 작업  w AWX·신규설치  m 변경  s gossh 작업  x 단독 체크`
  - 화면 1: 화면 1 에서는 `h` 를 표시하지 않습니다 (호스트 표가 없음).
- 메뉴 줄 표시 예: ` 호스트 작업 ▶ c 체크+수정  t 체크만  g 재확인  d 수동 완료  v 결과   (Esc 닫기)`
- 60칸 이상 화면에서의 줄바꿈 규칙(v0.7.0)을 메뉴 줄에도 그대로 적용합니다.

## 8. 검증 계획 (랩 .58, 변경 부분만)

- Go 단위 테스트
  - 출력 해석 통일(FQDN·ANSI·형식 불일치), 시간 제한(가짜 hang), `bash -c` 인용(`'` 포함 경로)
  - 붙여넣기 인식, 범위·패턴 지정, 이력 추천, DNS 판정 표(가짜 DNS 서버)
  - 작업 기록 저장·검색·7일 정리
- csh 검증: 랩에서 os6_mgmt 역할 계정의 로그인 셸을 tcsh 로 바꾸고 os6 경로 E2E 를 돌립니다.
- 01 DNS: 가짜 DNS(랩 dnsmasq 또는 스텁 dig)로 일치/불일치/중복/미등록/판단불가/DNS 없음/auto 모드 케이스를 확인합니다. awx `run_tests.sh` 에 추가합니다.
- 기존 E2E(`run_e2e.sh`)는 os6 원격 문자열이 바뀌는 부분만 기대값을 갱신합니다.

## 9. 확정 사항 (2026-10-12 회신)

1. 준비확인 시간 제한은 **60초** (상수).
2. MAC 은 **소문자로 변환**.
3. auto 모드에서 DNS 불일치가 나오면 **경고 + 계속 여부 질문**(`/dev/tty`). 물을 수 없으면 중단.
4. os6_mgmt 에서 연 `s` 는 대수와 상관없이 os6 gossh 로 실행.
5. 작업 출력은 user 당 200MB 상한.
6. 새 키는 `s`(gossh 작업). 신규 설치 양식은 별도 키 `i` 대신 `w` 메뉴 2번으로 넣음 (§5-1).

## 10. 새로 확인할 것 (§5-1 메뉴 구조)

1. `h`(호스트 작업) 메뉴 이름과 글자.
2. `w` 를 메뉴로 바꾸는 것 (`ww` 또는 `w Enter` 로 예전 동작).
3. 기존 단축키(c t g v d x)를 숨은 단축키로 남기는 것.
