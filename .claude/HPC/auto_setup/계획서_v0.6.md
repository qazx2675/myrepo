## 1. 공통 결정사항

| 항목 | 결정 |
|---|---|
| 새 키 | `x` = 체크스크립트 단독 실행, `w` = AWX 실행 (화면1 목록·화면2 호스트표 어디서나) |
| 모드 선택 | 단독 실행에서도 `t` = 설정체크만, `c` = 설정체크 + 설정수정(“설정수정” 빨강, 기존 규칙과 동일) |
| 취소 키 | `Ctrl+X`. 체크스크립트 단독 실행은 `Ctrl+X → 취소할까요? [y/n]` 후 프로세스 그룹 종료. AWX 는 Ctrl+X **즉시** 취소(터미널 intr 키를 ^X 로 바꿔 01/02 가 SIGINT 를 받음) |
| Ctrl+C / Ctrl+Z | TUI 전체에서 무시 (종료는 q). 안내 문구 `종료는 q 를 누르세요` |
| q / Esc | 체크스크립트 실행 시작부터 결과가 나올 때까지 무시. 결과 화면에서는 q/Esc 로 닫기 |
| 원격(os6) 갱신 주기 | 5초 → 10초 (`refreshAway`) |
| 단독 실행 기록 | 일회성. auto_setup.log·codes·runs 에 남기지 않음. 임시 디렉터리에서 실행 후 결과 창을 닫으면 삭제 |

## 2. 단계

### S1. conf: AWX 프로파일 변수 + 원격 10초 + Ctrl+C/Z 무시 (auto_setup)
- `awx_profile_1` … `awx_profile_9` 를 conf 로 읽는다 (main.go 빈 변수 9개 + `confVars()`). 형식 `y|2025|설명` = `nodeinfo(y/n)|OS값|설명`.

### S2. 체크스크립트 단독 실행 `x` (auto_setup, 새 파일 `oneoff.go` + 화면 상태)
흐름(전부 TUI 안, 전체 화면):
1. **user 선택**: `awx_dir/01.AWX_nodeinfo_V2.sh` 에서 `user_route="..."` 값을 읽어(함수 안 들여쓴 줄, 첫 번째 것) `bash <user_route>/info_mn.sh` 출력(메뉴)을 보여 주고 번호 입력 → `bash <user_route>/info.sh <번호>` 의 출력(공백 제거)을 user 로 사용. user 는 `^[A-Za-z0-9._-]+$` 만 허용. user_route 를 못 찾거나 비면 "user 메뉴를 찾을 수 없습니다(awx_dir/01 의 user_route 확인)" 안내 후 **user 이름 직접 입력**으로 대체. 이 단계에서 Esc / (빈 입력에서) q = 취소.
2. **호스트 입력**: 여러 줄 입력창. 안내 문구 필수: `호스트를 입력하거나 붙여넣은 뒤 Ctrl+D 를 누르세요 (공백·쉼표·탭·| 는 줄바꿈으로 바뀝니다, Esc 취소)`. 입력 중 `q` 는 호스트명 글자일 수 있으므로 **입력창이 비어 있을 때만** 취소. Ctrl+D 로 완료 → 구분자 정규화·빈 줄 제거·중복 제거(순서 유지), 0대면 다시 입력.
3. **모드 선택**: `t` 설정체크만 / `c` 설정체크 + 설정수정(“설정수정 (환경설정 수정함)” 빨강) / Esc 취소. 대상 대수·user 를 보여 주고 선택 즉시 실행.
4. **실행**: `os.MkdirTemp` 디렉터리에 `targets.txt` 작성, dhcp.sh 링크(runner.go 의 dhcpCandidates 재사용), `bash <os_check_sh> -auto-check|-auto <user> targets.txt` 를 **새 프로세스 그룹**(Setpgid)으로, stdin=/dev/null, 출력은 임시 디렉터리 파일. 실행 중 화면: 경과 시간 + 로그 마지막 N줄(1초마다 갱신). **q/Esc 무시**, `Ctrl+X` → `실행을 취소할까요? [y/n]` → y 면 프로세스 그룹 SIGTERM(3초 후 SIGKILL). 로그·codes·auto_setup.log 에 기록하지 않음.
5. **결과**: runner.go 의 `buildCodeTextMode` 로 본문 생성(설정체크만이면 check.res_<user>, 수정 포함이면 check.res_<user>_postapply) → 기존 결과 창(view.go)과 같은 스크롤 화면(↑↓, Space/b, q/Esc 닫기). 취소했으면 "취소됨" + 그때까지의 로그 꼬리. 창을 닫으면 임시 디렉터리 삭제.
- os_check_sh 가 비었으면 `x` 는 안내만. 원격 클라이언트(os8_mgmt 설정)에서도 로컬 os_check_sh 로 실행.
- 모든 단계 키 처리는 테스트 가능하게(가짜 실행기 주입: `oneoffExec` 변수), tui_test 스타일 키 시퀀스 테스트 + 정규화 함수 단위 테스트.

### S3. AWX 실행 `w` (auto_setup)
1. `awx_dir` 비었거나 `01.AWX_nodeinfo_V2.sh` 없으면 안내만.
2. 유효 프로파일이 1개 이상이면 화면에 `AWX auto 실행? [y/n]` + 노란 안내 `yml 마다 OS 버전이 다르면 N 을 입력하세요` → y 면 프로파일 목록(번호) `1) nodeinfo=y  OS=2025  설명` 에서 번호 선택(Esc 취소). 프로파일 0개면 묻지 않고 일반 실행. 무효 프로파일은 목록 아래 회색으로 사유.
3. 실행: 대체 화면 나가기 + termios 복원 → **cooked 모드에서 intr=^X, susp=비활성(_POSIX_VDISABLE)** 로 바꾼 뒤 `bash 01.AWX_nodeinfo_V2.sh` 를 `Dir=awx_dir`, stdin/stdout/stderr = 터미널로 실행. auto 면 환경변수 `AWX_AUTO=1 AWX_AUTO_NODEINFO=y|n AWX_AUTO_OS=<값>` 추가. 실행 동안 TUI 는 SIGINT 무시. 시작 전 한 줄 안내: `[auto_setup] AWX 실행 — 취소: Ctrl+X (즉시), 끝나면 auto_setup 화면으로 돌아갑니다`.
4. 종료 후 termios 원복(intr/susp 포함) → 대체 화면·raw 복귀 → 메시지 `AWX 종료 (rc=N)` / `AWX 취소됨 (Ctrl+X)`.
- termios 조작은 tty_linux.go 에 함수 추가(tty_other.go 는 no-op). 실행기는 테스트용 주입 가능하게.

### S4. awx_script 수정 (bash, 01/02)
- (a) **다른 경로에서 실행 가능**: 01 맨 앞(변수 블록 뒤, `start_pwd=$(pwd)` 전)에 스크립트 자신의 디렉터리로 `cd` (`cd "$(dirname "$(readlink -f "${BASH_SOURCE[0]}")")" || exit 1`). 스크립트 디렉터리에서 실행하면 동작 동일. 02 는 이미 `awxdir` 를 자기 경로 기준으로 잡지만 02 안의 다른 상대경로도 점검해 같은 방식으로 맞춘다(01 이 `bash 02...` 를 같은 디렉터리에서 부르므로 영향 확인).
- (b) **auto 모드** (환경변수가 없으면 기존과 100% 동일):
  - `AWX_AUTO=1` 일 때만: 01 `awx nodeinfo 사용여부` = `$AWX_AUTO_NODEINFO`, 01 `작업진행여부` = Y, 01 `AWX 인벤토리 소스` 메뉴 = su, 02 `OS 버전 선택` = 모든 yml 에 `$AWX_AUTO_OS` (`default` 면 기존 default_os), 02 `옵션이 맞습니까` = Y. 자동 답변은 원래 프롬프트 줄에 `값 (auto)` 로 에코(-auto 와 같은 스타일). user 메뉴·02 실패 재시도는 사람이 답함.
  - AWX_AUTO_OS 값이 선택지에 없으면 auto 를 끄고 기존 질문으로 진행(노란 경고).
- (c) **패치 스크립트**: awx_script 의 빈 변수(01 최상단 + 02 의 빈 변수 + `user_route`)로 `setup/vars.manifest` 작성 → git-upload-sk 템플릿으로 `setup/setup_guide.sh` 생성, `setup/update_v<신규버전>.sh` 생성(이전=origin/master 의 awx_script). 신규 버전 = CHANGELOG 의 다음 버전(현재 [Unreleased] 아래 0.5.0 → 0.6.0). 01/02 의 현장 값·주석을 보존해야 한다(템플릿 규칙 그대로).
- (d) 테스트: `test/run_tests.sh` 에 auto 모드(환경변수 있음/없음), 다른 디렉터리에서 실행 케이스 추가. .58 에서 전부 통과.
