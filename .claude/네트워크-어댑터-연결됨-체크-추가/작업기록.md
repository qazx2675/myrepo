작업일: 2026-09-15

## 변경 파일

두 사본에 동일하게 적용 (`.claude/VM/vm-network-migration/` 과
`.claude/VM/Network_Change_Integration_Script/projects/vm-network-migration/`).

| 파일 | 변경 내용 |
|---|---|
| `internal/vsphere/nic.go` | `EnsureConnected` 추가, `time` import, `connectAttempts`/`connectPollInterval` 상수 |
| `cmd/connect/main.go` | `SetPortgroup` 후 `EnsureConnected` 호출, 결과 메시지에 `(연결됨 재설정)` 표시 |
| `cmd/rollback/main.go` | 원본 포트그룹 복원 후 `EnsureConnected` 호출 |
| `CHANGELOG.md` / `README.md` / `ARCHITECTURE.md` | 문서 갱신 |

통합 스크립트 최상위 `Network_Change_Integration_Script/CHANGELOG.md` 에도
포트그룹 단계 갱신 항목 추가.

## 핵심 코드

```go
// internal/vsphere/nic.go
const (
	connectAttempts     = 5
	connectPollInterval = 2 * time.Second
)

func (s *Session) EnsureConnected(ctx context.Context, info *VMInfo, index int, key int32) (fixed bool, err error)
```

- 전원 꺼진 VM → 아무것도 하지 않음 (`Connected` 는 항상 false)
- 이미 `Connected` → 아무것도 하지 않음 (멱등)
- 아니면 연결 상태만 담은 Reconfigure → 2초 대기 → 다시 읽어 확인, 최대 5회
- 5회 후에도 안 되면 에러 (게스트에서 NIC 를 내렸거나 포트그룹 포트 부족 안내)

`cmd/connect` 의 재연결 대상 판정을 `rec.OrigConnected` →
`rec.OrigConnected || rec.OrigStartConnected` 로 바꿔 `nm-verify` 의 판정과 맞춤.

## 추가 수정 (같은 날, 사용자 피드백 반영)

사용자 피드백: "여전히 연결됨에 체크가 안된다. 그리고 전원을 켤 때 연결 이
부분도 체크가 되어야한다. 네트워크 어댑터 1 -> vswitch_{user}.txt를 참고하여
포트그룹 선택 -> 연결됨 체크 -> 전원을 켤 때 연결 체크 가 되어야한다."

### 원인 재분석

1차 수정(`EnsureConnected`)은 **백업 당시 연결돼 있던 NIC** 만 재확인하는
조건(`rec.OrigConnected || rec.OrigStartConnected`)이 붙어 있었다. 그런데
실제로는 포트그룹 이관 대상 VM 이 백업 시점에 전원이 꺼져 있는 경우가 많아
`orig_connected`/`orig_start_connected` 가 둘 다 false 로 기록되고, 그러면
재확인 로직 자체가 호출되지 않아 두 체크박스가 계속 꺼진 채로 남았다.

또한 사용자가 원하는 흐름은 "백업 시점 상태를 보존"이 아니라, vSphere 편집
설정에서 관리자가 수동으로 하는 것과 동일하게 **포트그룹 선택 후 두 체크박스를
항상 켜는 것**이었다. 기존 설계(`SetPortgroup` 이 `rec.OrigConnected`,
`rec.OrigStartConnected` 를 그대로 목표값으로 씀)는 "설정 변경이 아니라
순수 이관만 한다"는 안전 장치였지만, 사용자의 명시적 요구와 어긋났다.

### 변경 내용

- `vsphere.EnsureConnected(ctx, info, index, key)` →
  `vsphere.EnsureConnectState(ctx, info, index, key, wantConnected, wantStartConnected)`
  로 일반화. "연결됨" 뿐 아니라 "전원을 켤 때 연결" 도 같이 확인/재반영한다.
  전원이 꺼진 VM 은 "연결됨" 이 항상 false 이므로 그 값은 비교 대상에서 뺀다.
- `cmd/connect/main.go` (Step 3): `SetPortgroup` 에 넘기는 목표 연결 상태를
  `rec.OrigConnected, rec.OrigStartConnected` → **`true, true`** 로 변경.
  뒤이은 확인도 조건 없이 항상 `EnsureConnectState(..., true, true)` 호출.
- `cmd/rollback/main.go`: 이름만 `EnsureConnectState` 로 바뀌었고, 넘기는 값은
  그대로 `rec.OrigConnected, rec.OrigStartConnected` (원복은 원래 값 그대로
  복원해야 하므로 동작 변경 없음).
- 두 사본(`vm-network-migration/`, `Network_Change_Integration_Script/
  projects/vm-network-migration/`)에 Go 소스 동일하게 반영, `diff` 로 일치
  확인.
- 문서(CHANGELOG/README/ARCHITECTURE, 통합 스크립트 최상위 CHANGELOG)에
  추가 항목으로 기록. 통합 스크립트 사본의 문서는 처음에 실수로 원본 문서로
  덮어써서 `build_os6.sh`(OS6 빌드) 관련 고유 이력이 지워질 뻔했으나, 커밋
  전에 `git checkout` 으로 되돌리고 필요한 부분만 다시 편집해 원래 이력을
  보존했다.
