| 파일 | 변경 내용 |

| `cmd/connect/main.go` | `SetPortgroup` 후 `EnsureConnected` 호출, 결과 메시지에 `(연결됨 재설정)` 표시 |

통합 스크립트 최상위 `Network_Change_Integration_Script/CHANGELOG.md` 에도
포트그룹 단계 갱신 항목 추가.

## 핵심 코드

```go
// internal/vsphere/nic.go
const (
	connectAttempts     = 5
	connectPollInterval = 2 * time.Second
)

func (s *Session) EnsureConnected(ctx context.Context, info *VMInfo, index int, key int32) (fixed bool, err error)
```

- 전원 꺼진 VM → 아무것도 하지 않음 (`Connected` 는 항상 false)
- 이미 `Connected` → 아무것도 하지 않음 (멱등)
- 아니면 연결 상태만 담은 Reconfigure → 2초 대기 → 다시 읽어 확인, 최대 5회
- 5회 후에도 안 되면 에러 (게스트에서 NIC 를 내렸거나 포트그룹 포트 부족 안내)

`cmd/connect` 의 재연결 대상 판정을 `rec.OrigConnected` →
`rec.OrigConnected || rec.OrigStartConnected` 로 바꿔 `nm-verify` 의 판정과 맞춤.
