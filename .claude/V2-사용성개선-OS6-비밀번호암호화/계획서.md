### 제약/유지할 것

- 기존 옵션·동작 유지(`-u`, `-i`, `VC_PASSWORD` 환경변수, 이미 있는 VM/포트그룹 건너뛰기, 실패 시 중단)
- 오프라인 빌드 유지, 새 외부 의존성 없음 (암호화는 OS 기본 `openssl`)
- 스크립트는 bash 4.1(OS6) 에서도 동작, openssl 1.0.1(OS6) ~ 1.1.1(OS8) 호환

## 설계

| # | 방법 |
|---|---|
| 1 | `-u` 가 없으면 `$HERE/*.txt`(`*.example` 제외)로 번호 메뉴. `0` = 각 user 파일의 BM 목록 출력 후 다시 메뉴 |
| 2 | vm-param-check `FindSpec` 은 이미 2번째 레코드 숫자를 빼고 비교 → 시험으로 확인. `ask_cae_number` 가 스펙별로 새 번호를 물어 이번 실행의 포트그룹 이름(BM 생성·VM 어댑터)에 반영 |
| 3 | 터미널이면 ANSI 색, `NO_COLOR`/`VMSETUP_COLOR=never` 로 끔, `always` 로 강제 |
| 4 | BM→스펙 표·y/n 제거. 자동 할당 못 한 BM 만 번호 선택. VM 표에 스펙 열 추가 |
| 5 | 실행 계획에 스펙별 affinity 를 파일 내용으로 묶어 출력(같은 내용이면 파일 이름만 나열) |
| 6 | vm-param-check 에 `-specFolder`(모든 대상에 이 스펙 강제) 추가. 생성 후 스펙별로 만든 VM 만 체크, 요약 출력 |
| 7 | 실패용 user/스펙과 장애 주입(govc)으로 케이스별 명령·기대 결과 문서화 + 자동 시험 |
| 8 | `V2/secret/`(key + `vcenter_<id>.enc`, `esxi_<id>.enc`), `openssl enc -aes-256-cbc -md sha256 -salt -a -pass file:key`. `passwd_update.sh` 로 갱신. 우선순위: 환경변수 → 암호 파일 → 입력 |
| 9 | 스펙 `SAC-CAE104-VM99-MAX` (BM hostname0095~0099), VM20 스펙 BM 은 0070~0094 로 조정 |
| 10 | vcenter.txt 는 이미 vm-param-check 폴더 것을 읽음. SPEC_DIR 도 vm-param-check 폴더 것을 먼저 보도록 연동, affinity 가 없는 기존 스펙은 실행 중 affinity 를 골라 스펙에 추가 |
| 11 | nm-* 의 `build_os6.sh` 방식(govmomi vendor 사본을 Go 1.20 호환으로 패치) → `V2/bin_os6/`, `setup.sh` 가 OS6 면 복사 |
