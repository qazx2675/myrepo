### 재현 방법

`검증/` 폴더의 시험 도구(vcsim 실행기 `vcsimenv`, VM 설정 덤프 `vmdump`, 시나리오 `scenarios.sh`, 속도 `timing.sh`).
빌드에는 `.claude/공통/govendor/govmomi-0.55.1-vcsim`을 `vendor`로 링크해야 한다.

```bash
cd 검증 && ln -sfn ../../공통/govendor/govmomi-0.55.1-vcsim vendor
go build -mod=vendor -o bin/vcsimenv ./cmd/vcsimenv && go build -mod=vendor -o bin/vmdump ./cmd/vmdump
# scenarios.sh 는 /root/v2work/{harness,baseline_bin,V2} 경로를 가정한다(록키 작업 디렉터리 기준)
```
