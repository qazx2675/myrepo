## excel_com.go 가 export 하는 것 (다른 파일은 이것만 사용)

```go
type SectionColumns struct {
    StepCol, TaskNameCol, PreTaskDetailCol, TargetObjCol, VerifyMethodCol, WorkerCol, VerifierCol, ResultCol int // 1-based
}
type SectionInfo struct {
    Name         string // "사전작업" | "본작업" | "사후작업"
    StepNumber   string // "1" | "2" | "3"
    TitleRow     int
    HeaderRow    int
    DataStartRow int // HeaderRow+1
    DataEndRow   int
    Cols         SectionColumns
}

// 시트 목록 요약 (POST /api/target/load 응답의 sheets 원소)
type TargetSheetInfo struct {
    Index          int      `json:"index"`           // 1-based 시트 순서
    Name           string   `json:"name"`
    Sections       []string `json:"sections"`        // 찾은 섹션 이름들 (순서: 사전/본/사후)
    HasAllSections bool     `json:"has_all_sections"`
    FontName       string   `json:"font_name"`       // 사전작업 작업내용 데이터 셀 기준
    FontSize       float64  `json:"font_size"`
    ImageCount     int      `json:"image_count"`     // 시트 전체 Shapes.Count
}

type SOPGenerateRequest struct {
    TargetPath     string   `json:"target_path"`      // 상대경로면 GetAppDir() 기준
    SelectedSheets []string `json:"selected_sheets"`  // 체크한 순서
    WorkerName     string   `json:"worker_name"`
    VerifierName   string   `json:"verifier_name"`
    TargetObject   string   `json:"target_object"`
    OutputFileName string   `json:"output_file_name"` // 빈값이면 "SOP_결과본.xlsx", 확장자 없으면 .xlsx 부착, 경로 성분 제거(filepath.Base)
}

type SOPGenerateResult struct {
    Success        bool     `json:"success"`
    DstPath        string   `json:"dst_path"`        // filepath.Join(GetAppDir(), 출력파일명)
    DstFilename    string   `json:"dst_filename"`
    FileSize       int64    `json:"file_size"`
    SelectedSheets []string `json:"selected_sheets"`
    ExecutionTime  string   `json:"execution_time"`
    Message        string   `json:"message"`
}

func FindSections(ws *ole.IDispatch) ([]SectionInfo, error)          // 고정 좌표 없이 탐색
```

## HTTP API (handlers.go / main.go / web/app.js)

- `GET  /api/config` → `{success, config: AppConfig, app_dir}`
- `POST /api/config` body `{worker_name?, verifier_name?, target_object?}` (보낸 필드만 갱신, worker_name 이 보내졌는데 공백이면 400) → `{success, config}`
- `POST /api/target/load` — (a) JSON `{target_path}` 또는 (b) multipart 필드 `target_file`(.xlsx 업로드 → GetAppDir()에 저장). 응답 `{success, target_path, sheets: []TargetSheetInfo, count}`; LastTarget 저장
- `POST /api/generate` body = SOPGenerateRequest. WorkerName 비면 config 값 사용, 비어있으면 400. 시트 0개면 400. 성공 시 verifier/target_object/last_target 저장. → `{success, message, result: SOPGenerateResult, config}`
- 유지: `/api/create-sample-target`, `/api/open-file`, `/api/exit`, `/api/heartbeat`
- 삭제: `/api/config/worker`, `/api/config/category`, `/api/templates/*`, `/api/target/sheets`

(-worker 는 config 에 저장도 함). -template/-major/-minor/-detail/-create-default-template 삭제.
