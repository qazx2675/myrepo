# SOP 자동 생성 프로그램 완성 조건 (Definition of Done v2.0 최종본)

본 문서는 계획서(`sop_v2_0.md`)에 따라 수정·개발될 프로그램이 최종 완성되었음을 판단하는 검증 기준서입니다. 
**모든 항목은 자동화 통합 테스트(E2E Verification)를 시작하여 단 한 번에(One-Shot) 전 항목을 100% 통과해야만 작업이 최종 완료된 것으로 간주합니다.**

---

## 0. 원샷(One-Shot) 통합 테스트 통과 조건 (최우선 필수 조건)
- [ ] **단일 실행 전 항목 일괄 통과:** 테스트 시작 시 빌드부터 샘플 `target` 엑셀(다중 시트, `사전작업`/`본작업`/`사후작업` 3개 섹션, 커스텀 글꼴 크기(예: 14pt), 셀 내 이미지/도형 포함)을 이용한 결과 엑셀 생성 및 정합성 검증까지 **중간 실패나 재시도 없이 한 번에 통과**해야 한다.

## 1. 환경, 빌드 및 파일 생성 조건
- [ ] **Go 기반 단일 실행 파일(`.exe`) 빌드:** 외부 런타임 설치 없이 실행 가능한 단일 `.exe` 파일로 정상 빌드되어야 한다 (`-ldflags="-H windowsgui -s -w"`).
- [ ] **폐쇄망 제약 준수 (새 엑셀 생성 방식):** 원본(`target`) 엑셀을 직접 수정(Overwrite)하지 않고, Excel COM을 통해 새 통합문서를 만들어 시트 구조와 셀 내용을 복사·조합한 뒤 **프로그램(`.exe`)이 있는 위치에 새로운 엑셀 파일(`.xlsx`)**로 생성해야 한다.
- [ ] **생성될 엑셀 파일 이름 지정 가능:** 사용자가 UI(또는 CLI 옵션)에서 생성될 결과 엑셀 파일의 이름을 직접 입력·지정할 수 있어야 하며, 지정한 이름으로 프로그램 폴더에 파일이 생성되어야 한다.
- [ ] **`target` 파일 단독 베이스 사용 및 양식·글꼴 100% 동일 복제:** 별도의 외부 표준 양식 파일 없이 사용자가 선택한 `target` 엑셀 시트 자체의 레이아웃, 병합 구조, 테두리, 열 너비, 행 높이, **글꼴 종류 및 글꼴 크기(예: 11pt면 11pt, 14pt면 14pt)**가 생성되는 결과 파일에 100% 동일하게 복제되어야 한다.

## 2. 불필요 레거시 기능 완전 제거 조건
- [ ] **대분류/중분류/상세내용 완전 삭제:** 기존 v1.2의 `대분류`, `중분류` 드롭다운 및 직접 입력, `상세내용` 텍스트 입력 UI 및 관련 코드(`config.go`, `handlers.go`, `excel_com.go`, `web/*`)가 완전히 삭제되어야 한다.
- [ ] **기존 표준 양식 생성 및 관리 기능 삭제:** 기존 `B8, C8, G8, H8` 기준 기본 양식 생성 버튼 및 플레이스홀더(`대분류`, `중분류` 등) 양식 업로드/목록 관리 기능이 완전히 삭제되어야 한다.

## 3. 작업자, 검증자, 작업대상 입력 및 관리 조건
- [ ] **최초 실행 시 작업자 이름 지정 및 영구 기억:** `config.json`에 작업자 이름이 없으면 첫 화면에서 입력받아 영구 저장하고, 재실행 시 유지되며 상시 변경 버튼을 통해 즉시 수정·반영할 수 있어야 한다.
- [ ] **검증자 및 작업대상 입력 텍스트 상자 제공:** 메인 화면 내에 `검증자`와 `작업대상`을 기입할 수 있는 텍스트 입력 상자가 존재해야 한다.
- [ ] **작업자/검증자/작업대상 엑셀 자동 기입:** 생성되는 엑셀의 `사전작업`, `본작업`, `사후작업` 각 섹션 내 `작업자`, `검증자`, `작업대상` 열의 데이터 병합 셀에 입력된 값이 정확히 기입되어야 한다.

## 4. 3개 작업 섹션(`사전작업`, `본작업`, `사후작업`) 유동적 탐색 및 `Step` 고정 기입 조건
- [ ] **고정 좌표 배제 및 3개 섹션 자동 탐색:** 셀 주소를 고정값으로 지정하지 않고, 시트 내에서 `사전작업`, `본작업`, `사후작업` 섹션의 위치와 각 섹션 하단의 8개 컬럼(`Step`, `작업내용`, `작업자에 의한 사전 작업 내용`, `작업대상`, `검증방법`, `작업자`, `검증자`, `작업결과`) 및 그 바로 아래 위치한 데이터 병합 셀 블록을 유동적으로 찾아내야 한다.
- [ ] **`Step` 번호 자동 기입 (`1, 2, 3` 고정):** 결과 엑셀의 `사전작업`의 `Step` 칸에는 `1`, `본작업`의 `Step` 칸에는 `2`, `사후작업`의 `Step` 칸에는 `3`이 자동으로 생성·기입되어야 한다.

## 5. 시트 선택 순서 유지 및 섹션별 병합 셀 내 적재 조건
- [ ] **시트 선택 및 순서 지정 기능 유지:** `target` 엑셀의 시트들을 작업 항목으로 불러오고, 사용자가 체크한 순서(예: 3번 시트 → 1번 시트 → 2번 시트)를 정확히 유지해야 한다.
- [ ] **섹션별(`사전작업` / `본작업` / `사후작업`) 고정 3개 열 순서대로 통합 복사:**
  - 각 시트 안에는 `사전작업`, `본작업`, `사후작업` 3개 섹션이 모두 존재하며, 각 섹션의 `작업내용`, `작업자에 의한 사전 작업 내용`, `검증방법`에는 이미 내용이 작성되어 있다.
  - 2개 이상의 시트를 선택할 경우, 결과 파일의 **`사전작업` 데이터 병합 셀 하나** 안에 선택한 시트 순서대로 각 시트 `사전작업`의 `작업내용`, `작업자에 의한 사전 작업 내용`, `검증방법` 내용이 순서대로 들어가야 한다.
  - **`본작업`** 및 **`사후작업`** 역시 동일하게 각각의 단일 데이터 병합 셀 안에 선택한 시트 순서대로 내용이 들어가야 한다.
- [ ] **번호 및 시트 이름(`1. [시트이름]`) 자동 표기:** 병합 셀 안에 여러 시트의 내용이 순서대로 적재될 때, 각 열(`작업내용`, `작업자에 의한 사전 작업 내용`, `검증방법`)마다 기존 방식(방식 A)대로 체크한 순서에 맞춰 `1. [시트이름]`, `2. [시트이름]` 헤더가 자동 기입되고 그 아래에 원본 내용(텍스트, 서식, 글꼴 크기, 이미지/도형)이 겹침이나 누락 없이 배치되어야 한다.
