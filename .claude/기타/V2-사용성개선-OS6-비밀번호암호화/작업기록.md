## 작업 중 찾은 버그

- `vm_create`: 여유공간 -1 을 "못 찾음" 표시로 겸해 써서 음수 여유공간(vcsim 과할당)이면 재실행도 전 호스트 실패 → 찾음 여부 따로 기록. V1 `VM_setup`, `vm-setting-go-lang` 복사본에도 적용.
- `vm_setup.sh` `run()` 의 종료코드가 0 으로 찍힘(이번 변경 중 생김) → 수정.
- vcsim 은 `datastore.remove` 미지원, `object.destroy` 로 지우면 다른 호스트 조회까지 깨짐 → 실패 테스트는 처음부터 데이터스토어 없는 호스트로.
- 스펙에 ev01 `numa` 가 없으면 VM 생성은 되지만 vm-param-check 체크 불가(필수값) → 계획 단계 경고 + 체크 건너뜀. 시험 스펙에는 numa 추가.
