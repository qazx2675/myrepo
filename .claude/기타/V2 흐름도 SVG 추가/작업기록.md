- 렌더링: `npx @mermaid-js/mermaid-cli -c cfg(htmlLabels:false) -b white` — foreignObject 없는 순수 SVG, 흰 배경 (기존 SVG와 같은 방식).
- 각 README 상단에 SVG 링크 한 줄 추가.

## 2026-09-25 — 미리보기에서 너무 작게 보이는 문제 수정

- 기존 렌더링은 svg width="100%"라 GitHub 미리보기/다운로드 후 HTML에서 실제 크기가 작게 표시됨.
- `useMaxWidth:false` + 폰트 28px + `-s 2`(2배 스케일)로 재렌더링 → svg 루트에 고정 px width/height 부여, 글자도 커져 미리보기에서 확대 없이 바로 보임.

# 내용 보완 (2026-09-26, 다른 세션)

- 요청: `VMsetup/workflow.svg`(vm_setup.sh 흐름)에 이 저장소의 최신 실행 순서가 빠져 있어 보완 — VM_create 다음 MAC 수집(mac_info) 다음 전원정책 적용(power_setting), lpage_setting 다음 라이선스 할당(license_assign, 신규 호스트만).
- `VMsetup/workflow.mmd` 소스에 두 지점만 순수 추가(J→J1 mac_info→J2 power_setting→K, M 아니오→M2 license_assign→N). 기존 노드·문구·간선은 전혀 건드리지 않음.
- 렌더링: 네트워크로 mermaid-cli(mmdc)를 받을 수 없어(오프라인), 인수인계 핸드북에 이미 오프라인용으로 내려받아 둔 `mermaid.min.js`(v10.9.1)를 로컬 HTTP로 서빙해 브라우저에서 직접 렌더링 → 결과 SVG를 추출해 저장. 배경 흰색, 기존과 같은 기본(연보라) 테마 유지. 정확히 같은 mermaid 버전/설정(neo 룩, Recursive 폰트)은 아니라 픽셀 단위로는 다르지만 시각 스타일(색·모양)은 동일 계열로 맞춤.
- 확인: 생성된 SVG가 올바른 XML인지 확인, 브라우저로 vm_create→mac_info→power_setting→affinity_setting→lpage_setting→(단계 실패 판정)→license_assign→스펙 체크 순서로 렌더되는 것을 스크린샷으로 확인.
