# ARCHITECTURE.md

## 시스템 개요 및 구성도

휴대폰(ntfy 앱)을 통해 외부에서 질문을 입력하면, 집 PC에서 구동 중인 로컬 LLM(Ollama `qwen3:8b`)이 단일 근거 문서(`업무프로세스.md`)만을 기반으로 응답하고 👍/👎 피드백을 기록하는 경량 챗봇 시스템입니다.

```
[휴대폰 (Android / iPhone)]
   │  ① 질문 발행 (질문 토픽: proc-q-...)
   ▼
[ntfy.sh] ◀────────────────────────────────────────┐
   │  ② 구독 스트림                                   │ ④ 답변 발행 (답변 토픽: proc-a-...)
   ▼                                                │    + [👍 좋음] [👎 나쁨] 액션 버튼
[집 PC: bot.py] ──③ 문서 전체 + 질문──▶ [Ollama] ──┘
   │
   ├─ ⑤ 피드백 버튼 클릭 → 피드백 토픽 → bot.py → D:\업무프로세스\logs\feedback.jsonl
   └─ ⑥ 모든 질문/답변 → logs\qa.jsonl / 거절·미답변 → logs\unanswered.jsonl
```

## 폴더 및 파일별 역할

| 폴더/파일 | 역할 | 비고 |
|---|---|---|
| `bot.py` | ntfy 양방향 스트리밍 구독, Ollama API 통신, 답변 분할 및 피드백 액션 버튼 발행, JSONL 로깅 | 핵심 실행 프로그램 (Python 표준 라이브러리만 사용) |
| `run_tests.py` | 7절 60개 자연어 테스트케이스 일괄 실행, Ollama 직접 검증, 결과 CSV 및 통계 산출 | 자동 검증 도구 |
| `run.bat` | UTF-8 코드페이지(`chcp 65001`) 설정 및 `py bot.py` 실행 런처 | Windows 원클릭 실행 |
| `test_bot_mock.py` | 모의 환경 기반 컴포넌트(문서 읽기, 프롬프트, 분할 전송, 피드백 연결) 단위 테스트 | CI/로컬 검증용 |
| `.env.example` | 설정 템플릿 (토픽명, Ollama URL, 모델명, num_ctx, 문서 경로 등) | 비밀값 및 환경변수 템플릿 |
| `계획서.md` | 프로젝트 설계 원칙, VRAM/토큰 계산, 거절 규칙, 테스트케이스 원본 정의서 | 전체 기획 문서 |
| `README.md` | 프로젝트 설치, 실행, 옵션, 면책 조항, 전역 등록 가이드 | 표준 문서 |
| `PR_CHECKLIST.md` | 배포 및 코드 수정 전 체크리스트 | 표준 유지보수 산출물 |
| `CHANGELOG.md` | 버전별 변경 이력 및 Git 태그 연결 규칙 | 버전 관리 산출물 |

## 데이터 저장소 구성 (`D:\업무프로세스`)

| 디렉터리/파일 | 역할 |
|---|---|
| `업무프로세스.md` | 로컬 LLM의 유일한 근거 문서 (모든 질문에 시스템 프롬프트로 기본 첨부) |
| `백업/` | 보조툴이 문서를 수정하기 전 원본을 자동 보관하는 백업 디렉터리 |
| `logs/qa.jsonl` | 전체 질문/답변 기록 (질문 ID, 타임스탬프, 질문, 답변, 토큰 수, 소요시간) |
| `logs/unanswered.jsonl` | 미답변(문서 밖 거절 등) 질문 전용 로그 |
| `logs/feedback.jsonl` | 사용자가 누른 👍/👎 피드백 기록 (질문 ID로 원본 Q&A 연결) |
| `logs/errors.jsonl` | LLM 호출 및 네트워크 예외 발생 로그 |
| `tests/테스트케이스.txt` | 60개 자연어 테스트 질문 목록 |
| `tests/결과_YYYYMMDD.csv` | 일괄 테스트 실행 결과 및 판정표 |
| `state.json` | 봇 재시작 시 마지막 처리 메시지 ID 저장소 (이어받기용) |
| `.env` | 토픽명(비밀번호 역할) 및 로컬 환경변수 |

> **수정 팁**:
> 1. 프롬프트 규칙이나 거절 문구를 변경하려면 `bot.py` 및 `run_tests.py`의 `build_system_prompt()` 함수를 수정합니다.
> 2. 참조 문서를 변경하거나 추가하려면 `.env`의 `DOC_PATH` 항목을 수정합니다.
> 3. 피드백 버튼 형식이나 메시지 분할 기준(1,200자)을 조정하려면 `bot.py`의 `publish_ntfy()` 함수를 수정합니다.
