# CHANGELOG

## 2026-11-19 — v0.3.0
- 정비소 메인 화면 (CARLA): 카메라가 내 차 둘레를 돌고, 출발·엔진 튜닝·차량 선택·코스 선택·설정·종료 메뉴, 오른쪽 성능 표(출력·토크·최고속도·0-100·0-200 예상)
- 엔진 튜닝 파츠 9종 × 4단계(순정/스트리트/스포츠/레이스): 흡기·배기·연료·캠샤프트·터보·ECU, 전기 모터·인버터·배터리. 장착 전 미리보기, 차종별 자동 저장(config/garage.json)
- 운전 중 Esc = 정비소, Tab = 설정 메뉴
- 정비소에서는 차를 갓길에 세우고 주변 가로등·표지판·가드레일·나무를 잠시 숨김(카메라 가림 방지), 빛 번짐 끔, 카메라 거리는 차 크기에 맞춤
- 파츠에 따른 외관(단계별 도색)과 소리(배기·흡기·터보 휘슬/블로오프·모터)

## 2026-11-18 — v0.2.0
- 시뮬레이터 안 설정 메뉴(Tab/Esc): 코스·난이도·트래픽·차로·차종·파워트레인·차량 제원(최고속도를 정하는 레드라인·종감속비·EV 감속비 포함)·화면/소리, 파일 저장/다시 읽기
- OpenGL 3D 렌더러(ModernGL, 조명·그림자·안개·하늘), OpenGL 불가 시 기존 렌더러로 자동 대체
- CARLA 버전 `carla_sim/`: 사실적 그래픽, 차종·파워트레인·제원→CARLA 물리, 난이도별 Traffic Manager, 경로 탐색·안내, 30 km 직선(OpenDRIVE), 평행 주차, 제로백, 설정 메뉴, CUDA용 env API
- `install_carla.bat`: CARLA 자동 설치(기본 D:\CARLA_0.9.16, 공간 확인·이어받기), `run_carla.bat`: 서버 시작 + 실행
- 실행 개선: 바탕화면 바로가기, CARLA 서버를 창 없이 실행(게임 창 하나만 보임, 끄기 `stop_carla.bat`), 게임 창 중복 실행 방지, 로딩 중 '응답 없음' 방지
- 한국어 화면: 설정 메뉴·CARLA 주행 화면·로딩/오류 화면·내비/주차 안내 한글화 (기본 한국어, 메뉴 '언어'에서 English 전환, 맑은 고딕)
- 직선 코스 8 km → 30 km (300 km/h 로 5분 = 25 km + 가속·감속 여유)
