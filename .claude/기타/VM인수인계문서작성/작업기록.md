## 4. 검증 중 발견한 소스–README 불일치 (문서에 반영함)

옵션표를 `main.go`의 `flag` 정의와 대조하다 원본 README의 오류를 3건 찾았습니다.
문서는 **소스 기준으로 바로잡아** 적었고, 각 문서에 "원본 README와 다른 점" 절을 두어 명시했습니다.

| 도구 | README | 실제 소스 | 반영 위치 |
|---|---|---|---|
| `esxi-log-check` | `-server <주소:포트>`로 웹 대시보드 제공 | **`-server` 플래그 없음.** 소스에 `net/http`/`ListenAndServe` 자체가 없음. 그런데 `start_server.sh`/`run_test_server.sh`/`run_analyzer.sh`(메뉴 4)가 이 옵션을 넘김 → `flag provided but not defined`로 실패할 가능성 | 15번 5절 |
| `vm_lpage_bulk` | `-concurrency` 기본 20 | **해당 플래그 없음.** ev03 그룹 옵션도 없음(ev01/ev02만) | 17번 10절 |
| `vm_create` (vm-setting-go-lang) | 예시에 `-folderName`, Share에 `nomal` 허용 | **`-folderName` 없음**(`vm_connect` 전용), Share는 `flag.Int`라 문자열 불가 | 17번 10절 |

`esxi-log-check`의 대안으로 `-format html -out report.html` + `python3 -m http.server` 방식을 문서에 안내했습니다.
원본 README까지 고치려면 변경요청서 양식(B-6 문서 수정)을 쓰도록 연결해 두었습니다.
