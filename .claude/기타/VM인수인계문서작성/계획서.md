# 인수인계 기술문서 작성 계획서

- 작성일: 2026-09-02
- 대상: `myrepo/.claude/VM/` 아래 전체 도구(12개 폴더 + 공용 스크립트)

## 1. 결정 사항 (요청자 확인 완료)

| 항목 | 결정 | 이유 |
|---|---|---|
| 산출물 형식 | **Markdown 원본 + 단일 HTML 핸드북** | .md는 git diff·AI 수정에 최적. HTML은 파일 1개만 더블클릭하면 목차·검색·링크가 되는 오프라인 문서라 폐쇄망 반출과 비전문가 열람에 적합 |
| 문서 위치 | `.claude/VM/인수인계/` 통합 세트 | "이 폴더만 보세요"가 성립. 기존 각 폴더 README는 그대로 두고 상호 링크만 검 |
| 독자 수준 | 리눅스/SSH는 알지만 **vSphere는 모름** | 가상화 개념(vCenter/ESXi/NUMA/lpage/affinity/포트그룹)은 용어집과 본문에서 처음부터 설명. `ssh`, `vi`, `tar` 사용법은 설명하지 않음 |
| 범위 | **VM 폴더 전체** | 인수자가 폴더를 열었을 때 모르는 폴더가 남지 않도록 12개 폴더 전부 문서화 |

### 왜 마크다운인가 (형식 검토 결과)

| 후보 | 장점 | 단점 | 판정 |
|---|---|---|---|
| **Markdown** | git에서 변경 이력·리뷰 가능, AI가 그대로 수정 가능, GitHub에서 바로 렌더링, 코드블록/표에 강함 | 문서가 20개쯤 되면 파일 사이 이동이 번거로움 | **원본으로 채택** |
| **단일 HTML** | 파일 1개, 서버·인터넷 불필요, 목차/검색/앵커 이동 지원, 폐쇄망 반출 쉬움 | 손으로 고치기 어려움 | **배포본으로 채택** (md에서 자동 생성) |
| MkDocs / Docusaurus | 검색·네비게이션 우수 | Node/Python 빌드 툴체인 필요 → 폐쇄망에서 유지 곤란 | 제외 |
| Word / PDF | 결재 문서로 익숙 | 재생성 부담, 코드블록 깨짐, 버전 관리 안 됨 | 제외 (필요 시 HTML 인쇄로 대체) |
| Confluence / Notion | 협업 편집 | 사내 도입 여부 불명, 폐쇄망 접근 불가 | 제외 |

> 결론: **한 곳(.md)만 고치고, HTML은 스크립트로 다시 뽑는다.** 문서가 두 벌로 갈라지지 않게 하는 것이 핵심.

```

├── 00_시작하기.md               ← 인수자가 첫날 할 일, 전체 그림
```

### 도구 문서 공통 템플릿

모든 도구 문서는 같은 순서를 따른다. 인수자가 한 문서를 익히면 나머지도 같은 자리에서 같은 정보를 찾을 수 있게 하기 위함이다.

1. 한눈에 보기 (위험도 / 무엇을 / 어디서 / 대표 명령)
2. 이 도구는 무엇인가
3. 언제 쓰나
4. 준비물
5. 사용 방법 (단계별)
6. **옵션 상세표** (플래그 / 기본값 / 필수 / 설명 / 실수하기 쉬운 점)
7. 결과 해석
8. 자주 나는 오류와 해결
9. 주의사항과 한계
10. 파일 구조

### 위험도 표기

| 표기 | 의미 |
|---|---|
| 🟢 읽기전용 | 조회/계산만 함. 잘못 실행해도 인프라에 영향 없음 |
| 🟡 테스트용 | 시뮬레이터(vcsim)나 로컬 파일만 건드림 |
| 🔴 설정변경 | **실제 vCenter/ESXi 설정을 바꿈.** 실행 전 확인 필수 |

## 3. 작업 순서

1. 12개 폴더의 README/PLAN/CHANGELOG/`main.go` 플래그 정의를 전수 조사 → 옵션표 근거 확보 (완료)
2. 공통 문서(00/01/02/40/90/91/99) 작성
3. 도구별 문서 12종 작성
4. 유지보수 AI 가이드 + 변경요청 양식 작성
5. `build_handbook.py`로 단일 HTML 생성
6. 옵션표를 소스와 대조 검증 후 커밋

## 4. 유지 규칙 (인수 후)

- 도구 코드를 고치면 **그 도구의 `CHANGELOG.md`와 이 폴더의 해당 도구 문서를 같이 고친다.**
- 문서를 고쳤으면 `python3 build_handbook.py`를 다시 돌려 HTML을 갱신한다.
- 수정은 `31_변경요청서_양식.md`를 채워 AI에게 주는 방식을 표준으로 한다.
