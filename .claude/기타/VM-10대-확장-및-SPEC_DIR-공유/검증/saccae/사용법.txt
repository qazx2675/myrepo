saccae 검증 환경 사용법 (192.168.0.58 에 root 로 접속해서 실행)
=====================================================================

환경 요약
  - 가상 vCenter : vcsim.saccae.com  (BM hostname0000 ~ hostname0099.saccae.com 100대)
                   계정 lscsystems@vsphere.local / 비밀번호 Saccae1!  (암호 파일로 이미 등록돼 있음 — 환경변수 필요 없음)
  - 실제 vCenter : vcenter.saccae.com (192.168.0.50)  / ESXi esxi01.saccae.com (192.168.0.59)
  - 코드         : /home/saccae  (V2 브랜치, 빌드 완료)
  - 스펙(SPEC_DIR): /home/saccae/SPEC_DIR
      SAC-CAE101-VM06-HPC   : hostname0000~0039 (40대) x VM 6대  = 240대   (user lsh)
      SAC-CAE102-VM08-GPU   : hostname0040~0069 (30대) x VM 8대  = 240대   (user ljh)
      SAC-CAE103-VM20-BATCH : hostname0070~0094 (25대) x VM 20대 = 500대   (user dhk)
      SAC-CAE001-VM99-MAX   : hostname0095~0099 ( 5대) x VM 99대 = 495대   (user vm99, 포트그룹은 SAC-CAE100 — CAE 번호를 빼고 매칭)
      user saccae = BM 100대 전체 (VM 1475대)
  - fail_* user 와 SAC-CAE105~107 스펙은 실패 테스트용 (실패테스트사용법.txt)
  - TST-CAE002-GROUPCHECK-DEMO 스펙: ev01(Cpu16/Mem64/Disk500/Share8000)만 다르고 ev02~06(Cpu8/Mem32/Disk200/Share normal)은
    같게 만든 예시 — vm_create/lpage_setting 실행 계획에 ev 값이 정확히 반영되는지 눈으로 확인용. -u 목록엔 없어서
    "적용할 스펙을 고르세요"에서 번호로 직접 골라야 한다(아래 사용법 예시).
  - 가상 vCenter 는 메모리에만 있다 — restart 하면 만든 VM·포트그룹이 모두 지워지고 빈 BM 으로 돌아간다.
  - vm_setup.sh 는 시작할 때 "설치 정보"(OS 버전 / 인프라)를 묻고, 스펙마다 vm_create 다음에 mac_info(MAC 조사) →
    power_setting(BM 전원 고성능)을 실행한다(둘 다 환경변수 MAC_ARGSTR/MAC_ARG1 로 미리 채우면 묻지 않는다).

3. VM 만들기 (vm_setup.sh)
---------------------------------------------------------------------
cd /home/saccae/VMsetup

# user 를 번호로 고르기 (0 = 직접 선택: user 이름 직접 입력, 1~3 = lsh/ljh/dhk)
./vm_setup.sh

# user 지정 / 계획만 보기 (-n 은 vCenter 를 묻지 않는다)
./vm_setup.sh -u dhk -n

# 실제 실행: VM 표 y → CAE 번호 변경 Enter(=아니오) → OS 버전 8.10 → 인프라 입력 <값> → vCenter 번호 1 → 실행 확인 y
#            두 번째부터는 vCenter 번호에서 Enter = 이 user 가 지난번에 쓴 vCenter
#            MAC_ARGSTR/MAC_ARG1 환경변수를 미리 주면 이 두 질문은 건너뛴다 (아래 6번 참고)
./vm_setup.sh -u lsh
./vm_setup.sh -u ljh
./vm_setup.sh -u dhk
./vm_setup.sh -u vm99          # ev01~ev99, BM 5대 x 99대 (번호 메뉴엔 없음 — -u 로 지정)

# 100대 전체를 한 번에 (VM 1475대)
./vm_setup.sh -u saccae

# CAE 번호 바꿔 보기: CAE 질문에 y → 새 번호 입력 (포트그룹 이름만 바뀌고 스펙은 그대로)
./vm_setup.sh -u vm99 -n

# 계정 지정
./vm_setup.sh -u dhk -id lscsystems@vsphere.local

# 같은 명령을 다시 실행하면 이미 있는 포트그룹/VM 은 건너뛰고 정상 종료한다
./vm_setup.sh -u dhk

# 색을 끄고 싶으면
NO_COLOR=1 ./vm_setup.sh -u dhk -n

# TST-CAE002-GROUPCHECK-DEMO 로 vm_create/lpage_setting 실행 계획 확인 (BM 이름은 아무거나 — -n 이라 vCenter 는 안 건드림)
printf 'demo-bm\n' > demo.txt; printf 'demo-bm  DEMO-PG-1  999\n' > vswitch_demo.txt
./vm_setup.sh -u demo -n   # "적용할 스펙을 고르세요"에서 TST-CAE002-GROUPCHECK-DEMO 번호 선택 → y
rm -f demo.txt vswitch_demo.txt; rm -rf run_demo   # 확인 끝나면 정리

실행 확인 y 뒤에는 진행 모니터 화면이 뜬다 (터미널에서 실행했을 때만):
  ↑/↓ 단계 이동, Enter = 그 단계 실행 결과(로그) 보기 → ↑↓/PgUp/PgDn 스크롤, Enter = 목록으로
  라이선스 할당 단계에서는 모니터가 잠시 꺼지고 라이선스 번호를 묻는다 (vcsim 은 Evaluation Mode 뿐이라 q 로 취소)
  → 끝나면 모니터로 돌아옴. 다 끝나면 커서가 [종료] 에 있으니 Enter 두 번 → 원래 화면에 최종 요약
  Ctrl+C 는 5초 안에 3번 눌러야 종료(실행 중인 도구도 끝냄, 종료코드 130)
  로그: run_<user>/logs/ (단계별), run_<user>/run.log (전체), run_<user>/plan.txt (실행 계획)

# 모니터 없이 예전처럼 줄줄이 보고 싶으면
VMSETUP_MONITOR=0 ./vm_setup.sh -u lsh

실행이 끝나면 마지막에 "스펙 체크" 가 나온다 ([일치] / [차이] + 항목별 개수, 자세한 내용은 run_<user>/check_<번호>.log).
가상 vCenter 에서는 아래 항목이 [차이] 로 나오는 것이 정상이다:
  cpuid.coresPerSocket / config.numaInfo.coresPerNumaNode 설정없음  : vcsim 이 채우지 않는 값 (실제 vCenter 에서는 채워짐)
  numa.vcpu.preferHT FAIL (lsh)                                      : 스펙의 preferHT 는 vm_setup.sh 가 설정하지 않는다 → -fix
  sched.mem.lpage.enable1GPage 설정없음 (ljh ev06~ev08)              : 스펙에서 cores 를 비워 lpage 단계를 건너뜀 → -fix

power_setting 단계에서 "스킵: 이미 고성능(static)" 이 나오는 것도 정상이다 — vcsim 의 호스트는 기본값이 고성능이라
다시 실행해도 항상 스킵일 뿐, 실패가 아니다(실제 ESXi 에서 처음 적용될 때만 "성공"으로 나온다).

govc vm.info -e hostname0099ev99

6. MAC 조사(mac_info) / 전원 고성능(power_setting)
---------------------------------------------------------------------
cd /home/saccae/VMsetup

# vm_setup.sh 안에서: 스펙마다 vm_create 다음 mac_info → power_setting → affinity_setting 순으로 자동 실행된다.
# "설치 정보" 질문(OS 버전/인프라)을 건너뛰려면 미리 환경변수로 채운다:
export MAC_ARGSTR=8.10 MAC_ARG1=<인프라 값>
./vm_setup.sh -u lsh

# MAC 목록 복사 위치(awx_route, 기본은 비어 있어 run_<user>/mac_all.txt 에만 남음). 테스트는 임의 경로로:
export awx_route=/tmp/awx_test
./vm_setup.sh -u lsh
cat /tmp/awx_test/lsh.txt   # "VM VM <인프라> <VM이름> <IP> <MAC> eth0 sda sda5 <디스크> <OS버전> uefi"

# sda5 다음 디스크 값은 스펙의 disk-evNN 을 고정 용량 480/600/960/1200/1900/7600 중 가장 가까운 값으로 자동 변환한다
# (거리가 같으면 큰 값. 예: disk=500 → 480, disk=800 → 960)

# power_setting 만 따로 실행하려면(호스트 전원 정책만, VM 은 안 건드림):
export VC_PASSWORD='Saccae1!'
./power_setting-source/power_setting -vcTargetIP=vcsim.saccae.com -worklistFile=lsh.txt
