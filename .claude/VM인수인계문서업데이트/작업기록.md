## 4. 소스 기준으로 바로잡은 것

- **affinity 파일 형식**: 기존 문서의 `0=0,1`은 틀림. 실제는 `sched.vcpuN.affinity=0,1` (키가 그대로 ExtraConfig 로 들어감, `affinity_setting-source/main.go loadAffinitySpec`, `SPEC_DIR/.../affinity_ev01.txt`).
- **동질성 게이트**: V2 는 "같은 스펙·같은 그룹"끼리만 비교, 그룹 간 VM 대수 차이는 경고만(`fixer/gates.go`). 기존 문서는 대수 불일치도 게이트라고 적혀 있었음.
- **power_setting 옵션**: 문서에 없던 옵션을 .58 에서 바이너리 `-h`로 확인 — `-vcTargetIP`, `-id`(기본 `lscsystems@vsphere.local`), `-worklistFile`(기본 `worklist_bm.txt`). 비밀번호 환경변수 `VC_PASSWORD`는 바이너리 문자열로 확인.
- **vm_verifier 빌드**: `vendor/`가 아니라 `../../공통/govendor/govmomi-0.39.0` 링크 → 반출 시 `.claude/공통/govendor` 동반 필요.

  - `◇ 예/아니오` — `{"..."}` 마름모가 있을 때만
  - `▭ 처리` — 항상 (모든 흐름도가 사각 노드를 씀)
  - `⇢ 참고/생략 가능` — 점선 화살표(`-.->`)가 있을 때만 (14·15번)
  - `⇒ 단계 전환` — 굵은 화살표(`==>`)가 있을 때만 (README), 없으면 `→ 다음 단계`
  - `⬚ 단계 묶음` — `subgraph`가 있을 때만 (README)
  - 시작/종료를 나타내는 타원형·연결점 원형은 현재 어느 흐름도에도 쓰이지 않아 범례에도 넣지 않음(사용자 확인 없이 도형을 새로 추가하지 않음)
- CSS: `.mermaid`에 `position:relative`, `.hb-legend`는 절대위치 좌상단(11시 방향), 10px 작은 글씨, `var(--muted)` 색, 인쇄 시 숨김.
