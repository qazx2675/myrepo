# V2 흐름도 SVG 추가 (2026-09-25)

## 요청
`.claude/VM/V2` 안의 `VMsetup`, `vm-param-check-usability-improvement`에 누락된 흐름도 SVG 추가.

## 작업
- V1 폴더의 SVG는 V1 흐름(vm-param-fix 등)이라 그대로 쓰지 않고, V2 코드/README 기준으로 mermaid를 새로 작성해 렌더링.
  - `VMsetup/workflow.svg` — vm_setup.sh 흐름 (`vmsetup.mmd`)
  - `vm-param-check-usability-improvement/workflow.svg` — 체크·교정 흐름, V2의 `-specFolder`/암호 파일 반영 (`check.mmd`)
  - `vm-param-check-usability-improvement/workflow-deploy.svg` — 배포·갱신 흐름 (`deploy.mmd`, V1과 동일)
- 렌더링: `npx @mermaid-js/mermaid-cli -c cfg(htmlLabels:false) -b white` — foreignObject 없는 순수 SVG, 흰 배경 (기존 SVG와 같은 방식).
- 각 README 상단에 SVG 링크 한 줄 추가.

## 2026-09-25 — 미리보기에서 너무 작게 보이는 문제 수정

- 기존 렌더링은 svg width="100%"라 GitHub 미리보기/다운로드 후 HTML에서 실제 크기가 작게 표시됨.
- `useMaxWidth:false` + 폰트 28px + `-s 2`(2배 스케일)로 재렌더링 → svg 루트에 고정 px width/height 부여, 글자도 커져 미리보기에서 확대 없이 바로 보임.
