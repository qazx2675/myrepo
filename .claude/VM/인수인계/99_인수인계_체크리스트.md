# 99. 인수인계 체크리스트

체크가 안 되는 항목이 있으면 그 부분이 인수인계에서 빠진 것입니다.

## 4단계 — 읽기 전용으로 실행 (설정을 바꾸지 않음)

- [ ] `vm-param-check`를 `-fix` 없이, 대상 2대로 실행했다
- [ ] 결과 CSV의 컬럼 의미를 이해했고, **vSphere Client 화면과 직접 대조**했다
- [ ] `-onlyFail`을 써봤다
- [ ] `vm_setup.sh -u <작업이름> -n`으로 스펙·포트그룹 할당과 실행 계획을 확인했다
- [ ] `vm-param-check -specExport=<CAE폴더명>`으로 스펙 변환 결과를 봤다
- [ ] `lpage_search`로 실제 호스트 값을 넣어 계산했다
- [ ] `vm_verifier`를 실행했다
- [ ] `change.sh --dry-run`으로 망변경 예정을 확인했다
- [ ] `change.sh --debug-inventory`로 vCenter 이름 표기를 확인했다

## 완료 판정

1~7단계가 전부 체크되고 8단계의 빈칸이 채워지면 **인수인계 완료**입니다. 특히 아래 세 가지를 스스로 할 수 있어야 합니다.

1. **점검**: 실 vCenter 대상으로 `vm-param-check`를 돌리고 결과를 해석할 수 있다
2. **변경**: 예정을 확인한 뒤 `-fix`·`vm_setup.sh`·`change.sh`를 안전하게 실행하고 결과를 직접 검증할 수 있다
3. **수정**: 변경 요청 양식을 채워 AI에게 코드 수정을 시키고, 결과를 검증하고 기록할 수 있다
