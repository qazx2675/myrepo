## VMware / 가상화 기본

| 용어 | 뜻 |
|---|---|
| **ESXi** | 물리 서버에 설치하는 VMware의 하이퍼바이저 OS. ESXi가 깔린 물리 서버 한 대 = "호스트" |
| **호스트 (Host)** | ESXi가 설치된 물리 서버 한 대 |
| **BM (Bare Metal)** | 물리 서버. 이 저장소에서는 호스트와 같은 뜻으로 씀 |
| **VM (가상 머신)** | ESXi 위에서 돌아가는 가상 컴퓨터 |
| **vCenter** | 여러 ESXi 호스트를 한꺼번에 관리하는 중앙 관리 서버. 도구들은 여기 API에 접속 |
| **vSphere** | ESXi + vCenter를 아우르는 VMware 가상화 제품군의 이름 |
| **vSphere Client** | vCenter의 웹 UI. `https://<vCenter IP>` |
| **인벤토리 (Inventory)** | vCenter 안의 트리 구조 (데이터센터 > 폴더 > 클러스터 > 호스트/VM) |
| **데이터센터 (Datacenter)** | vCenter 인벤토리의 논리적 최상위 묶음 |
| **클러스터 (Cluster)** | 여러 ESXi 호스트를 묶은 단위 (HA/DRS 기능 단위) |
| **데이터스토어 (Datastore)** | VM 파일이 저장되는 스토리지 |
| **폴더 (Folder)** | 인벤토리 안에서 VM을 묶는 단위. **이 저장소에서는 폴더 이름이 스펙 식별자 역할**을 함 |
| **리소스풀 (Resource Pool)** | CPU/메모리 자원을 나눠 배분하는 논리 단위 |

## VM 성능 설정

| 용어 | 뜻 |
|---|---|
| **vCPU** | VM이 보는 논리 CPU 개수 |
| **소켓당 코어 수 (coresPerSocket)** | vCPU를 몇 개의 가상 소켓으로 나눠 보여줄지. **vCPU 수는 이 값으로 나누어떨어져야 함** |
| **NUMA** | CPU 소켓과 거기 붙은 메모리의 묶음. 같은 노드 안이면 빠르고, 넘나들면 느림 |
| **NUMA 노드** | CPU + 메모리 묶음 하나 |
| **`numa.vcpu.maxPerVirtualNode`** | 가상 NUMA 노드 하나에 넣을 최대 vCPU 수 (`-numa` 옵션) |
| **`config.numaInfo.coresPerNumaNode`** | NUMA 노드당 코어 수. vSphere UI: 설정 편집 > VM 옵션 > CPU 토폴로지. **API 8.0.0.1 이상 필요** |
| **`numa.vcpu.preferHT`** | NUMA 배치 시 하이퍼스레드를 우선 사용할지 (TRUE/FALSE). `-preferHT` 옵션 |
| **Auto 모드 (autoCoresPerNumaNode)** | "NUMA 노드 — 전원을 켤 때 할당됨" 상태. 이때 `coresPerNumaNode` 값은 **의미 없음**(지난 전원 켜짐 시점의 잔재) |
| **HT (하이퍼스레딩)** | 물리 코어 1개를 논리 CPU 2개로 보이게 하는 기술. `-ht on\|off` |
| **CPU Affinity** | 특정 vCPU를 특정 물리 CPU에만 돌게 고정하는 설정 |
| **`sched.vcpuN.affinity`** | vCPU N번의 affinity를 담는 ExtraConfig 키. 이 저장소가 주로 쓰는 방식 |
| **`Config.CpuAffinity.AffinitySet`** | affinity를 담는 또 다른(구조화된) 위치. 위와 **다른 곳**이라 한쪽만 값이 있을 수 있음 |
| **Large Page / lpage** | 메모리를 4KB가 아닌 **2MB 단위**로 관리하는 방식. 큰 메모리 워크로드에서 빠름 |
| **HugePage** | Large Page와 같은 개념 (리눅스 쪽 용어) |
| **minFree** | ESXi가 확보하려는 최소 여유 메모리. 보통 총 메모리의 약 2% |
| **High 상태 (High-State)** | 여유 메모리가 `minFree`의 3배 이상인 상태. **이때만 Large Page가 유지됨** |
| **`sched.mem.prealloc`** | VM 메모리를 미리 통째로 확보 |
| **`sched.mem.prealloc.pinnedMainMem`** | 확보한 메모리를 물리 메모리에 고정 (스왑 방지) |
| **`sched.mem.lpage.enable1GPage`** | 1GB 페이지 사용 여부 |
| **`sched.swap.vmxSwapEnabled`** | vmx 프로세스 스왑 사용 여부 |
| **Shares (공유값)** | 자원 부족 시 우선권을 정하는 상대적 가중치. `Normal`(자동) 또는 `Custom` + ratio 숫자 |
| **ratio** | Custom Shares의 숫자값 (예: 4000) |
| **메모리 예약 (Reservation)** | VM에 물리 메모리를 확정 할당. "모든 게스트 메모리 예약" = `config.memoryReservationLockedToMax` |
| **전원 정책 (Power Policy)** | ESXi 호스트 수준 설정. 고성능 워크로드는 **High Performance** 필요 |
| **ExtraConfig** | VM의 `key=value` 형태 고급 설정 모음 (vSphere UI: 설정 편집 > VM 옵션 > 고급 > 구성 매개변수 편집) |
| **CPU 토폴로지** | 소켓 수 / 소켓당 코어 수 / NUMA 노드 구성. **VM이 켜져 있으면 변경 불가** |

## 네트워크

| 용어 | 뜻 |
|---|---|
| **vNIC** | VM의 가상 네트워크 어댑터 |
| **vmnic** | ESXi 호스트의 물리 NIC |
| **vSwitch (VSS)** | ESXi 안의 표준 가상 스위치. 기본 이름 `vSwitch0`. **호스트마다 개별 설정** |
| **DVS / VDS** | 분산 가상 스위치. vCenter가 여러 호스트에 걸쳐 관리. **이 저장소 도구로는 포트그룹 생성 불가** |
| **nmcli / NetworkManager** | RHEL 8의 네트워크 설정 도구. vm-ip-change가 게스트 안에서 실행 |
| **Guest Operations** | vCenter → ESXi → VMware Tools 경로로 게스트 OS 안에서 명령을 실행하는 API. 네트워크가 끊긴 VM에도 동작 |
| **포트그룹 (Port Group)** | vSwitch 위의 논리적 포트 묶음. VLAN ID 지정 가능. **VM은 포트그룹에 연결됨** |
| **백킹 (Backing)** | vNIC이 어느 포트그룹에 붙어 있는지를 가리키는 설정 |
| **VLAN** | 네트워크를 논리적으로 분리하는 태그 번호 |
| **DHCP 예약** | 특정 MAC에 특정 IP를 고정 배정하는 설정 |
| **Kickstart** | 리눅스 자동 설치 방식. DHCP에 등록된 MAC을 보고 OS 이미지를 배포 |
| **교차 설치 / 역설치** | DHCP MAC 오기입 등으로 **A 서버에 깔려야 할 OS가 B 서버에 깔리는 사고** |

## 이 저장소 고유 용어

| 용어 | 뜻 |
|---|---|
| **ev01 ~ ev99** | VM 이름 접미사이자 **그룹 이름**. `<물리서버명>ev01` 형태. 그룹마다 기대 스펙이 다름. ev01 필수, 번호 연속 |
| **미분류 VM** | 이름에 `ev01`~`ev99`가 없는 VM. `-cores`/`-cpu` 등 **ev01 기대값이 적용**됨 |
| **worklist / `<user>.txt`** | 대상 물리 호스트(BM) 이름 목록 파일. 도구가 여기에 `ev01`~`ev99`를 붙여 VM 이름을 만듦 |
| **targets** | 대상 VM 이름(또는 BM 접두어) 목록 파일. `-f`로 지정 |
| **hostgroup.txt** | `"BM호스트 포트그룹이름"` 매핑 파일 |
| **SPEC_DIR / `-specRoot`** | 폴더명별 스펙(`_spec.txt` + affinity 파일)을 모아둔 **로컬** 디렉터리. V2 `vm_setup.sh`와 `vm-param-check`가 공유 |
| **`_spec.txt`** | 한 스펙의 기대값을 담은 파일. 형식은 CLI 플래그와 동일 (`cores=20` 등) |
| **CAE 폴더 규칙** | `TST-CAE001-SAMP48c-QRST` 형태. 하이픈 4조각, 2번째가 `CAE<숫자>`/`LSI<숫자>` |
| **차수** | CAE 폴더명 2번째 조각의 숫자(`CAE001`의 `001`). **매칭 시 무시됨** |
| **인시던트 (incident)** | 망변경 실행 1회의 결과·백업 위치 기록 (`incidents/incident_<시각>/`). `port`·`rollback`의 단위 |
| **gossh** | 여러 노드에 SSH 명령을 병렬 실행하는 사내 도구 (`.claude/공통/gossh`). 망변경 IP·LDAP 엔진이 사용 |
| **C / D / E 단계** | 망변경의 IP 변경 / LDAP 설정 / 포트그룹 이관 |
| **Task 폴더** | CAE 규칙을 안 따르는 임시 작업 폴더. 포트그룹명으로 스펙을 유추하거나 사람에게 물어봄 |
| **게이트 (Gate)** | `-fix` 실행 전 안전장치. **그룹 동질성 + 전원 OFF** 두 가지 |
| **그룹 동질성** | 같은 스펙·같은 그룹(ev01끼리, ev02끼리 …)의 교정 대상 스펙이 전부 같아야 한다는 조건. 그룹 간 대수 차이는 경고만 |
| **dry-run** | 실제로 바꾸지 않고 **바꿀 내용만 출력**하는 모드 |
| **자동교정 (fixable)** | 도구가 자동으로 고칠 수 있는 항목 |
| **수동조치 (manual)** | 사람이 vSphere Client에서 고쳐야 하는 항목 (메모리/디스크/Shares/전원정책 등) |
| **재검증 (recheck)** | 교정 적용 후 다시 조회해 같은 로직으로 판정하는 단계 |
| **판정값** | `OK` / `FAIL` / `설정없음` / `미지원`(조회 불가 필드) / `정보` 5가지 |

## 기술 용어

| 용어 | 뜻 |
|---|---|
| **govmomi** | VMware의 Go용 vSphere API 라이브러리. `v0.39.0`(vm-param-check·vm_verifier), `v0.55.1`(V2 VMsetup·망변경 포트그룹) |
| **Reconfigure Task** | vCenter에서 VM 설정을 바꾸는 비동기 API 호출(`ReconfigVM_Task`) |
| **워커풀 (Worker Pool)** | 동시 실행 개수를 제한하며 병렬 처리하는 구조. `-concurrency`로 조절 |
| **goroutine** | Go의 경량 스레드 |
| **멱등 (Idempotent)** | 여러 번 실행해도 결과가 같은 성질. 중복 실행해도 안전 |
| **ContainerView** | vCenter 인벤토리를 한 번에 배치 조회하는 API |
| **`property.Collector.Retrieve`** | 지정한 객체들의 속성만 골라 배치 조회하는 API |
| **moref (Managed Object Reference)** | vCenter 객체의 내부 ID |
| **vendor/** | Go 의존성 소스를 프로젝트 안에 통째로 넣어둔 폴더. **폐쇄망 빌드의 핵심** |
| **`-mod=vendor`** | `vendor/` 안의 소스만 쓰고 인터넷을 보지 않게 하는 Go 빌드 플래그 |
| **폐쇄망 (Air-gapped)** | 인터넷이 완전히 차단된 네트워크 |
| **SSL Thumbprint** | SSL 인증서의 지문. 미신뢰 호스트 등록 시 필요 |
| **SSLVerifyFault** | SSL 인증서를 신뢰할 수 없을 때 vCenter가 반환하는 오류 |
