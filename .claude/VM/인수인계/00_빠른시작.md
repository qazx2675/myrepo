## 1. 저장소 받기 (인터넷 되는 곳에서 1회)

```bash
git clone https://github.com/qazx2675/myrepo.git
cd myrepo/.claude/VM
```

폐쇄망으로 옮길 때는 폴더를 **통째로** 압축합니다 (`vendor`/`govendor` 포함).

```bash
cd myrepo
tar czf vm-tools.tar.gz .claude/VM/V2 .claude/VM/vm_verifier .claude/VM/lpage_search \
  .claude/VM/Network_Change_Integration_Script ".claude/VM/vCenter API IP 자동변경" \
  .claude/VM/VM_setup/vm-param-fix/power_setting .claude/공통/govendor
```

## 2. Go 확인

```bash
go version        # V2 전체 빌드는 1.26.5 이상 필요
```

Go가 없으면 [02번 1절](./02_공통_실행환경.md)의 오프라인 설치를 따릅니다.

## 3. 빌드

```bash
# V2 (VMsetup 10종 + vm-param-check) — V2 폴더를 통째로 배치 (OS6 서버면 bin_os6/ 실행파일을 자동 설치)
cp -r V2 /home/V2 && cd /home/V2 && bash setup.sh
./passwd_update.sh          # vCenter 비밀번호를 암호 파일로 등록 (vm_setup.sh, vm_setting_check_insert.sh 가 사용)

# vm_verifier (.claude/공통/govendor 가 두 단계 위에 있어야 함)
cd <저장소>/.claude/VM/vm_verifier && bash setup.sh

# lpage_search (의존성 없음)
cd <저장소>/.claude/VM/lpage_search && bash setup.sh

# 망변경 통합 스크립트
cd <저장소>/.claude/VM/Network_Change_Integration_Script && ./setup.sh

# vm-ip-change (폴더명에 공백 — 따옴표 필수)
cd "<저장소>/.claude/VM/vCenter API IP 자동변경/project" && ./setup.sh
```

## 4. 인증 (세션마다 1회)

도구마다 변수 이름이 다르므로 한 번에 다 넣어 둡니다.

```bash
export VC_USER='<vCenter 계정>'
read -rsp 'vCenter 비밀번호: ' P; echo
export VC_PASS="$P" VC_PASSWORD="$P"; unset P
```

| 변수 | 쓰는 도구 |
|---|---|
| `VC_USER` / `VC_PASS` | vm-param-check, vm_verifier |
| V2 암호 파일 (`passwd_update.sh`) | V2 `vm_setup.sh`, `vm_setting_check_insert.sh` — 셸의 비밀번호 변수는 지우고 시작 |
| `VC_PASSWORD` (+ 계정은 `-id`) | V2 개별 도구(`*-source`), power_setting, 망변경 포트그룹 단계 |
| `VC_USER` / `VC_PASSWORD` | vm-ip-change |
| `GOSSH_PW` | 망변경 IP·LDAP 단계 |
| `GUEST_USER` / `GUEST_PASSWORD` | vm-ip-change (게스트 OS 로그인) |

## 5. 첫 실행 — 읽기 전용 명령부터

```bash
# 메모리 계산 (접속 없음)
cd <저장소>/.claude/VM/lpage_search
./lpage_search -h <호스트명> -v1 <ev01 메모리GB> -hm <호스트 총메모리GB>

# VM 설정 점검 (대상 2~3대만 적어서 시작)
cd /home/V2/vm-param-check-usability-improvement/vm-param-check
echo '<vCenter IP>' > vcenter.txt
printf '<VM이름1>\n<VM이름2>\n' > targets.txt
./vm-param-check -vcenterList=vcenter.txt -f=targets.txt -specRoot=../../SPEC_DIR -out=result.csv

# VM 생성 계획만 보기 (vCenter 변경 없음)
cd /home/V2/VMsetup
./vm_setup.sh -u <작업이름> -n
```

결과 CSV를 vSphere Client 화면과 대조해 보고, 도구가 맞는 값을 읽는지 확인한 뒤에 🔴 명령으로 넘어갑니다.
