## 보안 점검 반영 (Q29)

읽기 전용 보안 점검에서 나온 지적을 반영했다: 가짜 확인자 이름으로 자기 승인(→ `users=` 목록 제한), `admin` 선점(→ 등록 금지, install.sh 가 기본 패스워드 abc135!! 로 생성), 잠금 DoS(→ 지연 방식), 연결/작업 수 상한, 시작 토큰 일회성, 중단 작업 부활 금지. 의도적으로 남긴 것: `run`/`list` 무인증, 평문 패스워드, root 공유 환경의 우회 가능성.
