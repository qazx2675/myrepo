# PR_CHECKLIST.md

배포/수정 전에 확인합니다. 항목을 지우지 말고 체크만 하세요.

## 빌드 · 검증

- [ ] 폐쇄망 기준 빌드 성공 — `bash setup.sh` (내부적으로 `-mod=vendor`, `GOPROXY=off`)
- [ ] 정적 분석 통과 — `go vet -mod=vendor ./...`
- [ ] 테스트 통과 — `go test -mod=vendor ./...`
- [ ] 의존성을 추가했다면 `go mod vendor` 를 다시 돌리고 `vendor/` 를 커밋했는가
- [ ] Windows 가 아니라 실제 대상 OS(Rocky/RHEL) 에서 빌드·실행을 확인했는가

## 동작 시나리오 (최소 1개는 실환경 또는 테스트 vCenter 로)

- [ ] `-dry-run` 결과가 실제 인벤토리와 일치하는가
- [ ] 실제 이관 1대 → 리포트/롤백 CSV 가 정상 생성되는가
- [ ] 같은 명령을 다시 실행했을 때 `SKIPPED` 로 넘어가는가 (멱등성)
- [ ] `-rollback` 으로 원래 포트그룹까지 되돌아오는가
- [ ] vCenter 를 2대 이상 적었을 때 동시에 조회되고, 한 대가 죽었을 때 VM 무손상으로 중단하는가
- [ ] 없는 VM / 없는 포트그룹을 넣었을 때 VM 을 건드리지 않고 중단하는가
- [ ] 실패가 있을 때 종료 코드가 `1` 인가

## 안전장치

- [ ] 목표 포트그룹 확인이 여전히 **고루틴 시작 전**에 이루어지는가
- [ ] NIC 를 끊었다 붙이는 코드가 다시 들어가지 않았는가 (백킹 교체 1회 유지)
- [ ] `find.Finder` 를 고루틴 안에서 공유하고 있지 않은가
- [ ] `-concurrency` 기본값이 과도하게 높아지지 않았는가
- [ ] vCenter 조사 실패 시 중단하는 분기를 없애지 않았는가

## 문서

- [ ] `CHANGELOG.md` 에 날짜순으로 항목을 추가했는가
- [ ] `README.md` 의 옵션 표를 갱신했는가 (플래그를 추가/변경한 경우)
- [ ] `ARCHITECTURE.md` 의 파일별 역할 표를 갱신했는가 (파일을 추가/삭제한 경우)
- [ ] 주의사항(Disclaimer) 문구가 그대로 남아 있는가

## 자격증명 · 자산 정보

- [ ] `vcenter.txt`, `vmlist.txt`, `report_*.csv`, `rollback_*.csv` 가 커밋에 포함되지 않았는가
      (`git status` 로 확인, `.gitignore` 등록 여부 확인)
- [ ] 커밋 메시지/문서에 실제 IP·비밀번호·호스트명이 들어가지 않았는가
- [ ] 비밀번호를 코드/문서/예시에 하드코딩하지 않고 `VC_USER`/`VC_PASS` 환경 변수 경로를 유지했는가
