vcenter 통합 관리 포털 - 명령 모음
====================================
※ 회사(Windows, PowerShell 만 있음)에서는 "W. 회사 Windows 빌드" 와 "D. Windows 측 절차" 만 사용합니다. bash 불필요.
※ 0, A, B, C 는 랩 리눅스(192.168.0.58, bash)에서의 개발/검증용입니다.
※ 각 명령 바로 위 줄이 설명입니다.


W. 회사 Windows 빌드 (PowerShell, 폐쇄망 가능, bash 불필요)
------------------------------------------------------------
# Go 버전 확인 (go1.26.5 권장. 1.26 미만이면 build.ps1 이 설치 안내 후 멈춤)
go version

# git 에서 내려받은(또는 복사해 온) 폴더로 이동
cd <내려받은 폴더>\.claude\VM\vcenter-통합관리

# 빌드 + dist\vc-portal 조립 (vendor 사용, 네트워크 접근 없음)
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 결과 확인: 이 폴더를 공유폴더에 통째로 복사한다 (이후는 D 절차)
dir dist\vc-portal -Recurse


0. [랩] 코드 가져오기 (랩 검증 시 먼저)
------------------------------
# [Windows] 변경 사항을 저장소에 올린다 (commit 후)
git push

# [랩 .58] 최신 코드를 받는다. .58 저장소는 cone 모드 sparse-checkout 이라 새 경로는 add 가 필요하다
cd /root/saccae-src && git fetch && git reset --hard origin/master && git sparse-checkout add ".claude/VM/vcenter-통합관리"

# [랩 .58] 프로젝트 폴더로 이동
cd /root/saccae-src/.claude/VM/vcenter-통합관리


A. 빌드 / 정적 검사 (랩 .58)
----------------------------
# 빌드 + dist/vc-portal 조립 (vendor 사용, 인터넷 불필요)
./build.sh

# 배포 패키지 구성 확인
find dist/vc-portal | sort

# 정적 분석
go vet -mod=vendor ./...

# 단위 테스트
go test -mod=vendor ./...

# 웹 UI JS 문법 검사 (node 가 있을 때)
for f in web/assets/*.js; do node --check "$f"; done


B. 랩 수집기 실행 (랩 .58, Linux 빌드 사용)
-------------------------------------------
# 랩용 conf 를 리포지토리 밖에 만든다 (계정/비밀번호는 절대 커밋하지 않는다)
cat > /root/vcportal-lab.conf <<'EOF'
[paths]
output_dir = /root/vcportal-out
work_dir   = /root/vcportal-work
log_dir    = /root/vcportal-logs
[account]
user     = lscsystems@vsphere.local
password = <랩 비밀번호>
[vcenters]
lab01 = https://192.168.0.50
EOF

# 출력 폴더 준비
mkdir -p /root/vcportal-out

# 설정 해석 + 경로 + vCenter 로그인 점검만 (종료 코드 0 이면 정상)
./scripts/run-collector.sh --conf /root/vcportal-lab.conf --check ; echo "exit=$?"

# 실제 수집 실행 (종료 코드: 0 성공, 1 설정오류, 2 일부실패, 3 전부실패)
./scripts/run-collector.sh --conf /root/vcportal-lab.conf ; echo "exit=$?"

# 생성된 데이터 파일 확인 (manifest.js, index.js, lab01.js)
ls -l /root/vcportal-out/data


C. 가짜 데이터 생성 (UI 대규모 테스트, node 필요)
-------------------------------------------------
# vCenter 15대 / VM 13,000대 / 호스트 700대 가짜 데이터를 testdata/fake/data 에 생성
node testdata/gen-fake.js --vcs 15 --vms 13000 --hosts 700 --out testdata/fake

# 수집 실패 vCenter 2대 + 수집 시각을 30시간 전으로 (실패 표시/경고 배너 확인)
node testdata/gen-fake.js --fails 2 --stale-hours 30 --out testdata/fake

# 웹 UI 를 가짜 데이터 옆에 복사하면 testdata/fake/index.html 을 바로 열 수 있다
cp -r web/index.html web/assets testdata/fake/


D. Windows 측 절차 (실제 공유폴더/수집 서버/사용자 PC)
------------------------------------------------------
# [빌드 PC] W 에서 만든 dist\vc-portal 폴더를 공유폴더로 통째로 복사한다
# 예: \\fileserver\share\vc-portal 로 dist/vc-portal 의 내용을 복사

# [공유폴더] 설정 파일 만들기 (복사 후 메모장으로 경로/계정/vCenter 목록 수정)
copy \\fileserver\share\vc-portal\config\vcportal.conf.example \\fileserver\share\vc-portal\config\vcportal.conf

# [수집 서버] 점검만: conf 해석, 공유폴더 쓰기 권한, 각 vCenter 로그인 (종료 코드 0 이면 정상)
powershell -ExecutionPolicy Bypass -File \\fileserver\share\vc-portal\collector\run-collector.ps1 -Check

# [수집 서버] 수집을 한 번 직접 실행 (data\ 에 manifest.js, index.js, <id>.js 생성)
powershell -ExecutionPolicy Bypass -File \\fileserver\share\vc-portal\collector\run-collector.ps1

# [수집 서버] 작업 스케줄러에 매일 12:00 등록 (등록 계정에 공유폴더 쓰기 권한 필요)
powershell -ExecutionPolicy Bypass -File \\fileserver\share\vc-portal\collector\run-collector.ps1 -RegisterTask

# [수집 서버] 등록된 작업 확인
schtasks /Query /TN vcportal-collector /V /FO LIST

# [수집 서버] 등록된 작업 즉시 1회 실행 (테스트용)
schtasks /Run /TN vcportal-collector

# [수집 서버] 등록 작업 삭제 (테스트 후 정리)
schtasks /Delete /TN vcportal-collector /F

# [사용자 PC] 바탕화면 "vCenter 포털" 바로가기 생성 + vcportal:// 프로토콜 등록 (사용자당 1회, 관리자 권한 불필요)
powershell -ExecutionPolicy Bypass -File \\fileserver\share\vc-portal\launcher\install-launcher.ps1

# [사용자 PC] 바로가기 삭제 + 프로토콜 등록 해제
powershell -ExecutionPolicy Bypass -File \\fileserver\share\vc-portal\launcher\install-launcher.ps1 -Uninstall

# [사용자 PC] 포털 열기 (권장, 바탕화면 "vCenter 포털" 과 같음): 전용 Edge 에 포털 → [vCenter에서 열기] 확인 창 없음
\\fileserver\share\vc-portal\launcher\vcportal.exe

# [사용자 PC] index.html 직접 열기 (이 경우 [vCenter에서 열기] 마다 Edge 확인 창에서 [열기] 필요)
start msedge "file://fileserver/share/vc-portal/index.html"

# [사용자 PC] 런처 단독 테스트 (conf 에 등록된 vCenter 의 /ui/ 주소여야 함)
\\fileserver\share\vc-portal\launcher\vcportal.exe --url "https://vc01.corp.local/ui/"

# [사용자 PC] 런처 로그 확인
type %LOCALAPPDATA%\vcportal\launcher.log
