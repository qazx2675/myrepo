argument-hint: [노력:낮음|중간|높음] 작업내용

$ARGUMENTS

위 입력에서 "노력:" 표기를 찾아 수준을 정하라. 표기가 없으면 중간으로 본다.
- 낮음: 핵심만 빠르게 처리 (effort: low)
- 중간: 표준 수준으로 검토 (effort: medium)
- 높음: 대안 비교와 교차 검증까지 수행 (effort: high)
노력 표기는 작업에서 제외하고 실제 작업 내용만 맡겨라.

현재 세션의 모델은 바꾸지 말고, Agent 도구로 서브에이전트를 호출해 작업을 맡겨라.
- model: "haiku" (버전 없는 별칭이라 항상 최신 모델로 연결된다)
- effort: 위에서 정한 수준
- prompt: 서브에이전트는 이 대화를 볼 수 없다. 작업 내용과 필요한 맥락(파일 경로, 제약, 원하는 결과 형태)을 스스로 완결되게 적어라.
서브에이전트가 돌려준 결과를 사용자에게 전달하고, 필요하면 그 결과로 이어서 작업하라.
