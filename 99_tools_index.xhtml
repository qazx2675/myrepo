Confluence Intelligence 사용 권장 (작업 툴 찾기)

어떤 도구를 써야 할지 모르겠다면, Confluence Intelligence에게 먼저 "내가 하려는 작업"을 물어보세요!

  • 예시: "서버 50대에 같은 명령어를 한 번에 실행하고 싶어. 어떤 툴을 써야 해?"
  • 예시: "서버 IP를 변경해야 하는데 어떤 문서를 봐야 해?"

Intelligence가 아래 목차에서 알맞은 툴을 안내해 주면, 해당 툴 페이지로 이동한 뒤 다시 질문하여 구체적인 사용법을 확인하세요.

99. 툴 (운영·점검 도구 목차)

  • 이 목차에는 서버 운영 및 점검용 툴(01~15)만 등록되어 있습니다.
  • VM 생성·설정 관련 스크립트(VM_setup_docs, vCenter_API_IP_자동변경_docs)는 본 목차에서 제외됩니다.
  • 모든 툴 문서는 이미 준비된 툴을 바로 실행하는 방법만 안내합니다.
번호 툴 이름 (문서 폴더) 한 줄 목적 (언제 쓰는가) Intelligence 질문 예시 주의사항
01 OS_환경설정_체크_docs 서버의 기본 OS 환경설정이 기준에 맞게 되어 있는지 점검할 때 "OS 환경설정 체크 툴은 어떻게 실행해?" -
02 V2_docs V2 버전 운영·점검 스크립트/도구를 사용할 때 "V2 툴은 언제, 어떻게 사용하는 거야?" -
03 auto_setup_docs 서버 초기 자동 설정 작업을 일괄 수행할 때 "서버 초기 자동 설정(auto_setup) 방법 알려줘." -
04 awx_script_docs 표준 자동화 플랫폼(AWX) 연동 스크립트를 실행할 때 "AWX 스크립트 실행 방법이 궁금해." -
05 config_check_docs 서버 주요 설정 파일 상태를 점검하고 확인할 때 "서버 설정 파일 점검(config_check) 어떻게 해?" -
06 dirmap_docs 디렉토리 구조 및 경로 매핑 상태를 확인/정리할 때 "dirmap 툴은 어떤 용도이고 어떻게 써?" -
07 gossh_docs 수백 대 서버에 SSH 명령을 동시에 실행하고 결과를 비교할 때 "여러 서버에 명령어를 한 번에 실행하려면?" 파일 전송(SCP) 미지원, 위험 명령 기본 차단
08 ip_change_docs 서버의 IP 주소를 변경해야 할 때 "서버 IP 변경 툴 사용법 알려줘." 표준 프로세스(AWX) 우선 권장. 너무 바쁘거나 AWX로 실행이 불가한 서버에 대해서만 사용
09 ldap_check_docs 서버의 LDAP 연동 상태를 점검할 때 "서버 LDAP 연동 상태 확인하는 방법 알려줘." 표준 프로세스(AWX) 우선 권장. 너무 바쁘거나 AWX로 실행이 불가한 서버에 대해서만 사용
10 ldap_setting_docs 서버에 LDAP 인증 설정을 적용할 때 "서버에 LDAP 설정하는 툴 사용법 알려줘." 표준 프로세스(AWX) 우선 권장. 너무 바쁘거나 AWX로 실행이 불가한 서버에 대해서만 사용
11 pm_monitor_docs 물리 서버(PM) 상태 및 이상 여부를 모니터링할 때 "물리 서버 모니터링(pm_monitor) 어떻게 해?" -
12 redfish_docs 서버 BMC/iDRAC 등 원격 관리(Redfish API)를 제어할 때 "Redfish로 서버 원격 상태 확인하는 법 알려줘." -
13 setup_check_docs 서버 셋업 완료 후 정상 구성 여부를 최종 점검할 때 "셋업 완료 후 점검(setup_check) 방법 알려줘." -
14 stress-test_docs 서버 CPU/메모리 등 부하(스트레스) 테스트를 수행할 때 "서버 부하 테스트(stress-test) 어떻게 실행해?" 운영 중인 서비스 서버에서는 실행 주의
15 조사_docs 여러 서버에서 필요한 현황 정보를 일괄 조사·수집할 때 "서버 현황 조사 툴은 어떻게 사용해?" -
