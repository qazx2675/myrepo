Confluence Intelligence 사용 권장 (도구 찾기): 이 페이지는 Confluence Intelligence(질문형 AI)가 "어떤 도구를 써야 하는지" 안내하도록 작성했습니다. 하려는 일을 Confluence Intelligence 에게 질문하십시오.

질문 예: "서버 50대에 같은 명령을 한 번에 실행하고 싶어. 어떤 도구를 써?" / "서버 IP 를 바꾸려면 어떤 도구를 써?" / "OS 설치가 끝났는지 확인하는 도구는?"

Confluence Intelligence 가 도구 이름을 알려 주면, 그 도구의 문서 페이지로 이동해서 사용 방법을 다시 질문하십시오.

이 페이지의 규칙: 이 페이지는 도구를 이름으로 안내합니다. 각 도구의 이름, 실행 명령, 문서 이름을 함께 적었습니다. 이 페이지에는 사용 방법의 상세 내용이 없습니다. 상세 내용은 각 도구의 문서에 있습니다.

2. 비슷한 도구는 어떻게 고르나?

헷갈리는 도구고르는 기준
ip_change 와 vm-ip-change서버에 SSH 로 접속되면 ip_change. VM 에 SSH 로 접속되지 않으면 vm-ip-change.
ldap_setting 과 ldap_check설정을 바꾸면 ldap_setting. 설정을 확인만 하면 ldap_check.
config_check 와 OS 환경설정 체크auto_setup·setup_check 와 연계하거나 벤더 코멘트가 필요하면 config_check. 연계 없이 단독으로 쓰면 OS 환경설정 체크.
auto_setup 과 pm_monitor 와 setup_checkAWX 작업을 받아 자동으로 끝까지 진행하면 auto_setup. 설치 진행을 화면으로 감시만 하면 pm_monitor. 사용자가 원할 때 한 번 판정하고 설정수정·부하테스트로 이어가면 setup_check.
V2 와 VM_setup새 작업은 V2(ev01 ~ ev99). 예전 V1 작업을 유지할 때만 VM_setup(ev01 ~ ev03).
gossh 와 다른 도구정해진 도구가 없는 일반 명령은 gossh. 대부분의 도구가 내부에서 gossh 를 사용합니다.

3. 작업 순서로 도구 찾기 (서버 OS 설치부터 인계까지)

  1. awx_script: AWX 에 노드정보·DHCP·PXE 를 등록해 OS 설치를 시작합니다.
  2. auto_setup 또는 pm_monitor: 설치 진행을 감시합니다. auto_setup 은 READY 뒤 LDAP 복원과 config_check 를 자동으로 실행합니다.
  3. setup_check: 설치 결과를 판정하고, 필요하면 config_check(설정수정)와 stress-test(부하테스트)를 이어서 실행합니다.
  4. ldap_check: LDAP·DNS·NTP·autofs 설정을 확인합니다.
  5. survey: 자산 정보를 조사해 엑셀로 정리합니다.

5. 자주 묻는 질문 (FAQ)

Q. 어떤 도구를 써야 할지 모르겠습니다.
A. 1절 "하려는 일로 도구 찾기" 표에서 하려는 일을 찾으십시오. 도구 이름의 문서로 이동해 사용 방법을 확인하십시오.

Q. 여러 서버에 명령을 한 번에 실행하려면 어떤 도구를 쓰나요?
A. gossh 를 쓰십시오. 처음이면 "gossh 사용 가이드(초보자용)" 문서를 먼저 보십시오.

Q. 서버 IP 를 바꾸려면 어떤 도구를 쓰나요?
A. SSH 로 접속되는 서버는 ip_change 를 쓰십시오 (AWX 표준 절차를 먼저 쓰십시오). SSH 로 접속되지 않는 RHEL 8.10 VM 은 vm-ip-change 를 쓰십시오.

Q. LDAP 설정을 확인하거나 바꾸려면?
A. 확인만 하면 ldap_check, 바꾸면 ldap_setting 을 쓰십시오. 두 도구 모두 AWX 표준 절차를 먼저 쓰십시오.

Q. OS 설치가 끝났는지 확인하려면?
A. AWX(awx_script)로 등록한 작업은 auto_setup 화면에서 확인하십시오. 호스트파일로 직접 감시하려면 pm_monitor 를 쓰십시오. 한 번에 판정하려면 setup_check 를 쓰십시오.

Q. 서버 OS 설정이 기준과 맞는지 확인하고 수정하려면?
A. config_check 를 쓰십시오. 연계 없이 단독으로 쓰려면 OS 환경설정 체크 를 쓰십시오.

Q. 부하테스트를 하려면?
A. stress-test 를 쓰십시오. setup_check -run 으로 이어서 실행할 수도 있습니다.

Q. BIOS 설정을 확인하거나 바꾸려면?
A. redfish 를 쓰십시오. 실행 명령은 bash bios.sh 입니다.

Q. 서버 자산 정보를 엑셀로 정리하려면?
A. survey(조사)를 쓰십시오. 실행 명령은 ./run_survey.sh 입니다.

Q. VM 을 만들려면?
A. V2 의 vm_setup.sh 를 쓰십시오. 예전 V1 도구 VM_setup 은 새 작업에 쓰지 마십시오.
