2.1 설치 폴더 구조

2.2 표1 입력 파일 (asset_list.txt)

  1. 표1(자산양식)을 탭 구분 텍스트로 저장합니다.
  2. 첫 줄이 헤더이면 자동으로 건너뜁니다.

  4. conf/conf.toml 의 [input].asset_file 에 경로를 씁니다.

2.3 A 서버 재조사를 쓰려면 (run_survey.sh 전용)

B 서버(전용)가 전체를 조사합니다. 타임아웃·접속불가 서버만 A 서버(공용)가 1번 다시 조사합니다. DNS 미등록 서버는 다시 조사하지 않습니다. 아래 조건이 모두 필요합니다.

  1. [server_a].enabled = true 로 설정합니다.
  2. A 서버와 B 서버가 [server_a].dir 경로를 같은 절대경로로 공유합니다(autofs 등).
  3. 공유 폴더에 A 서버용 바이너리([server_a].bin, 예: survey-rhel6)와 conf/conf.toml 이 있습니다.
  4. B 서버에서 A 서버로 [server_a].user(기본 root) 계정의 비밀번호 없는 SSH 가 됩니다.
  5. A 서버에 gossh 가 설치되어 있습니다. 경로가 다르면 [server_a].gossh_bin 에 씁니다.

3. survey 는 어떤 순서로 조사하나?

  1. (run_survey.sh) [asset_filter] 가 있으면 표1 을 걸러 asset_file 을 만듭니다.
  2. B 서버에서 survey 가 모든 서버를 gossh 로 조사합니다. 설정값(/etc/auto.appl 의 /appl)과 인프라망(infra_survey.sh, 실패하면 ldap.conf 의 binddn)을 봅니다.
  3. 설정값이 없음 인 서버에 uname 을 실행합니다. VMkernel 이면 ESXi 로 판정합니다.
  4. ESXi 마다 <esxi>ev01, ev02, ev03 이름을 DNS 로 찾습니다. 찾은 VM 만 2차로 조사합니다.
  5. (run_survey.sh) A 서버 재조사가 켜져 있고 타임아웃/접속불가 서버가 있으면, 공유 폴더에 .resurvey.XXXXXX 를 만들고 A 서버에서 1번 다시 조사합니다. 결과를 hostname 기준으로 합칩니다.
  6. TSV 파일을 만듭니다. 서버는 파일 사이에서 중복되지 않습니다.

접속에 실패한 서버도 1행씩 기록합니다. 실패 이유는 특이사항 열에 적습니다.

4. 결과 파일은 어떻게 읽나?

4.1 결과 파일 3종

파일만드는 때
result_YYYYMMDD_HHMM.tsv항상. 표1 전체 서버 (SDC 서버 제외)
result_vm_YYYYMMDD_HHMM.tsvESXi 가 1대 이상이고 VM 행이 있을 때
result_sdc_YYYYMMDD_HHMM.tsv인프라망 값이 정확히 SDC 인 서버가 있을 때. 그 서버는 다른 파일에서 빠집니다.

TSV 내용을 복사해 엑셀에 붙여 넣으면 탭으로 셀이 나뉩니다.

4.2 7개 열

열값
1. hostname표1 의 hostname. VM 은 <esxi>ev01~03
2. 위치표1 의 위치. VM 은 ESXi 의 위치
3. 상태표1 의 상태. VM 은 ESXi 의 상태
4. 설정값auto.appl 의 /appl 줄 마지막 값(이름:/경로). 출력이 없으면 없음. 접속 실패면 빈칸
5. 인프라망인프라망 값. 값이 VIP 이면 SLSI_VIP 로 바꿉니다. ESXi 는 없음. 실패면 빈칸
6. appl설정유무O: 설정값의 위치가 표1 위치와 같음. X: 다르거나 mountpoint 미정의. 없음: 설정값 없음 또는 ESXi. 빈칸: 접속 실패
7. 특이사항접속불가, 타임아웃, DNS 미등록, gossh 실행 실패, mountpoint 미정의, 인프라 스크립트 없음, 인프라 확인필요(...), esxi

4.3 ESXi 와 VM 은 어떻게 기록하나?

  • ESXi 행: 설정값/인프라망/appl설정유무 는 없음, 특이사항 은 esxi 입니다.
  • DNS 에서 찾지 못한 VM(예: 없는 ev03)은 행을 만들지 않습니다.
  • DNS 에서 찾았지만 SSH 가 안 되는 VM 은 접속불가 로 기록합니다.
  • 조사할 수 있는 VM 이 하나도 없으면 ESXi 이름으로 접속불가 1행을 남깁니다.
  • 타임아웃 VM 은 1번 다시 조사합니다.

5. 설정 파일(conf/conf.toml)의 키는 무엇인가?

키샘플 값뜻
[input].asset_file/root/HPC/조사/asset_list.txt표1 텍스트 경로
[gossh].bin/usr/local/bin/gosshgossh 경로
[gossh].concurrency4000동시 실행 수. 설정값 조사에만 씁니다.
[gossh].timeout10시간 제한(초). 모든 조사에 씁니다.
[gossh].retry_timeout30일반 서버의 DNS 미등록/타임아웃 재조사 시간 제한(초). VM 은 제외
[gossh].extra_args비움gossh 에 넘길 추가 옵션
[scripts].config_valuecat /etc/auto.appl | grep -v '#' | grep -w '/appl'설정값 조사 명령
[scripts].infra_net/usr/local/bin/infra_survey.sh인프라망 조사 스크립트. 비우면 인프라망 열이 빈칸입니다.
[scripts].infra_regex^INFO\s+\S+\s+(\S+)인프라망 출력에서 값을 뽑는 정규식
[scripts].infra_fallback_cmdcat /etc/openldap/ldap.conf | grep -i binddn정규식이 맞지 않거나 스크립트가 없을 때 쓰는 명령
[scripts].infra_fallback_regexuid=([^,\s]+)대체 명령 출력에서 값을 뽑는 정규식
[[mountpoint]].name / .locationnas-a / A센터설정값의 스토리지 이름과 그 정상 위치. 표1 위치와 비교합니다.
[asset_filter].source / .include / .exclude원본 표1 / 비움(run_survey.sh 전용) 표1 을 egrep -E 로 걸러 asset_file 을 만듭니다.
[server_a].enabled / .host / .userfalse / a-server / root(run_survey.sh 전용) A 서버 재조사 사용 여부와 접속 정보
[server_a].dir / .bin / .gossh_bin/user/autofs1/조사 / survey-rhel6 / 비움공유 폴더, A 서버용 바이너리, A 서버의 gossh 경로

6. 문제가 생기면?

  • 원인을 자세히 보고 싶다: ./run_survey.sh --debug 를 실행합니다. 설정을 출력하고, A 서버의 gossh 를 점검하고, 임시 폴더 .resurvey.XXXXXX/ 를 지우지 않습니다.
  • 인프라망 열이 비거나 이상하다: infra_regex 가 infra_survey.sh 의 실제 출력과 맞는지 먼저 확인하십시오. 원격 셸(csh)은 원인이 아닙니다. infra_net 은 bash 로 실행합니다.
  • 인프라 스크립트 없음 이 나온다: 그 서버에 infra_survey.sh 가 없습니다. 이 경우 binddn 대체 명령의 값을 씁니다.
  • mountpoint 미정의 가 나온다: 설정값의 스토리지 이름이 [[mountpoint]] 에 없습니다. conf/conf.toml 에 추가하십시오.
  • /usr/local/bin/survey 로 복사했더니 설정을 못 읽는다: survey 는 실행 파일 옆의 conf/conf.toml 만 읽습니다. 설치 폴더에서 ./run_survey.sh 로 실행하십시오.
  • 결과 파싱이 깨졌다: survey 는 gossh 출력 형식(hostname: 결과)을 전제로 합니다. gossh 출력 옵션을 바꾸지 마십시오.

참고용 보조 도구입니다. 결과를 100% 믿지 마십시오. 중요한 값은 서버 몇 대에 직접 접속해서 확인하십시오.

7. 자주 묻는 질문 (FAQ)

Q. survey(조사) 는 무엇을 하는 도구인가요?
A. 표1 자산 목록의 모든 서버를 gossh 로 조사하고, 엑셀에 붙여 넣을 수 있는 TSV 파일로 저장하는 자산 조사 도구입니다.

Q. 어떻게 실행하나요?
A. 설치 폴더에서 ./run_survey.sh 를 실행합니다. 매월 01일 00시에는 크론탭으로 자동 실행합니다.

Q. 자동 실행 날짜를 놓쳤어요.
A. 설치 폴더에서 ./run_survey.sh 를 직접 실행하십시오.

Q. 결과를 엑셀에 넣으려면?
A. result_*.tsv 내용을 복사해 엑셀에 붙여 넣습니다. 탭으로 셀이 나뉩니다.

Q. appl설정유무 가 X 이면 무슨 뜻인가요?
A. 서버의 /appl 스토리지 위치가 표1 의 위치와 다르거나, 그 스토리지가 [[mountpoint]] 에 정의되지 않았다는 뜻입니다.

Q. VM 도 조사되나요?
A. 예. ESXi 를 찾으면 <esxi>ev01~ev03 중 DNS 에 있는 VM 을 조사하고 result_vm_*.tsv 에 저장합니다.

Q. 내가 정한 명령 결과를 표로 만들고 싶어요.
A. survey 는 정해진 항목만 조사합니다. 원하는 명령을 조사하려면 gossh -sv -w hosts.txt 를 쓰십시오.
