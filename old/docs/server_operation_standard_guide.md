# 서버 운영 및 관리 표준 지침서

## 1. 주요 용어 사전
- ITOM: 자산관리시스템. 모든 장비의 등록 및 현황 관리 표준.
- CF (Compute Farm): 컴퓨트 서버 작업의 최종 승인 및 Job 상태 확인 담당자.
- VWP (Virtual Workstation): 시각화 장비. 물리 장비 여부 확인 필수.
- SSI (Server Security Index): 서버 보안 지표.

상세 경로 확인 가이드를 공통 원칙에 추가한 최종 통합본)
