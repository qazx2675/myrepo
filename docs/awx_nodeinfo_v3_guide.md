# AWX_nodeinfo_V3 실무 운영 가이드

## 1. 도입 배경 (Why)
기존 AWX를 이용한 VM 설치 과정에는 다음과 같은 비효율이 존재했습니다.
- 과도한 수작업: 엑셀 기입, 데이터 가공을 사람이 직접 수행
- 반복적인 실수 발생 가능성

AWX_nodeinfo_V3는 ESXi 서버 구축 및 VM 생성 과정에서 발생하는 번거로운 수작업(엑셀 기입, 데이터 가공)을
최소화하고, AWX 템플릿 실행을 효율적으로 보조하기 위해 설계된 운영 보조 도구입니다.

## 2. 표준 작업 절차 (실제 작업 순서, How to use)
1. AWX_nodeinfo_V3 스크립트 실행
2. 대상 노드 정보(호스트명/IP/사양) 입력 또는 파일 로드
3. 가공된 데이터를 AWX 템플릿의 Extra Variables 형식으로 자동 변환
4. AWX Job 실행 및 결과 확인
