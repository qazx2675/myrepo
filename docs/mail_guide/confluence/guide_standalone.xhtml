작업대상 호스트 교차 검증기 (host-cross-checker.exe) 설정 및 사용 가이드

Confluence 게시용 / 로컬 미리보기 겸용 XHTML 1.0 Strict 문서

안녕하세요.

작업 전 AWX 호스트 대상 오류를 사전에 방지하고, 작업자와 확인자가 서로 교차 검증(Cross-Check)을 진행할 수 있도록 개선된 작업대상 호스트 교차 검증기(host-cross-checker.exe)의 초기 설정 방법과 실제 실행 화면 기준 항목별 사용법을 안내드립니다.

한눈에 보는 전체 사용 흐름
  1. 초기 1회 설정: 상단 ⚙ 패널의 AWX 연동 설정에서 주소·인벤토리·계정/비밀번호/Token을 입력 후 [연결 테스트 & 저장] (Windows DPAPI 암호화 저장)
  2. 1. 작업 전 자체확인 탭에서 선택 인벤토리 기준 AWX 호스트 수집 및 상세/인시던트/작업대상 대조로 1차 검증
  3. 2. 작업자 요청/승인대기 탭에서 동료 확인자를 지정해 크로스체크 요청 발송
  4. 3. 확인자 검증/승인 탭에서 확인자가 블라인드 요약(대표 1대 제외 숨김) 대조 후 최종 확인 완료(승인) 또는 반려
  5. 어느 탭에서나 하단 6시 상태 바에서 승인 대기·완료·반려 여부를 상시 확인하고, 상단 [📋 로그]에서 승인 이력 감사·내보내기 가능

0. 설치·실행 및 초기 설정 (config.json · DPAPI · 공유폴더)

구성 항목설정 및 동작 설명
host-cross-checker.exe팀원 각자 로컬 PC에서 더블클릭으로 실행하는 단일 독립 앱 실행 파일입니다. (Edge/Chrome --app 창 자동 실행, 창 닫기 시 안전 종료)
config.json (sharedDir)실행 파일 옆에 위치합니다. 원격 교차 검증 시 sharedDir에 사내 공유폴더 경로를 지정하면 PC 간 포트 방화벽 설정 없이도 sessions/ 폴더(500ms 폴링)를 통해 승인 상태가 실시간 동기화되며, 승인 감사 로그도 sharedDir/logs/YYYY-MM-DD.log에 자동 저장됩니다.
users.json공유폴더(또는 실행 폴더) 내 사용자 IP 명부(name, ip, role)입니다. 접속 시 로컬 IP를 자동 매칭해 상단 사용자 배지 및 확인자 선택 목록을 구성합니다.
AWX 자격증명 유지 (Windows DPAPI)⚙ 환경설정 → AWX 연동 설정에서 [연결 테스트 & 저장]을 1회 성공하면 비밀번호와 API Token이 Windows DPAPI(현재 PC/사용자 전용 암호화)로 config.json에 안전하게 저장(awxPasswordEnc, awxTokenEnc)되어 재실행 후에도 재입력 없이 바로 수집할 수 있습니다.
열린 AWX 탭 브리지 (선택)SSO 로그인만 가능하거나 AWX 웹 화면에 적용된 검색·필터 상태 그대로 수집하려면 북마크 바에 [AWX 탭 연결] 버튼을 드래그하거나 dist/bookmarklet.txt 코드를 1회 실행해 실시간 브리지로 연결할 수 있습니다.
자격증명 보안 유지 (Windows DPAPI)

AWX 비밀번호와 API Token은 평문으로 저장되지 않고 현재 PC/사용자 전용 Windows DPAPI로 암호화(awxPasswordEnc, awxTokenEnc)되어 config.json에 저장됩니다.

1. 공통 상단 헤더 및 환경설정 (⚙)

▲ 상단 공통 제어 영역(접속 사용자·로그·설정·상단 고정) 및 ⚙ 환경설정 패널 주요 항목
번호항목설명
①현재 접속 사용자 표시현재 실행 중인 본인 이름과 에이전트 연결 상태(초록색 점)가 상단 헤더에 표시됩니다.
②[📋 로그] · 환경설정(⚙) · 상단 고정 버튼[📋 로그]로 일별 승인 이력을 조회·저장하고, ⚙으로 알림·자동 숨김 지연·AWX 연동을 설정하며, [상단 고정]으로 다른 작업 창(터미널·브라우저·메신저 등) 위에 앱 창을 항상 띄워 둘 수 있습니다.
③승인요청 / 승인완료 알림창을 최소화하거나 내려두더라도 새 요청 또는 승인/반려 완료 시 Windows 우측 하단 알림과 작업표시줄 깜빡임으로 즉시 알립니다. (동일 PC 셀프 테스트 시에는 'skipped'로 구분 표시)
④마우스 이탈 시 자동 숨김 & 지연(초) 설정상단 고정과 함께 켜 두면 마우스가 창 밖으로 벗어난 뒤 지정한 지연 시간(기본 5초, 0초부터 설정 가능)이 지나면 지정 비율(기본 30%)만 남기고 자동 축소됩니다. 대기 중 마우스나 포커스가 돌아오면 타이머가 취소되고 즉시 원래 크기로 복원됩니다.
⑤1인 셀프 크로스체크 테스트타인에게 잘못 발송되지 않도록 일반 확인자 목록에는 본인이 숨겨져 있으며, 혼자 동작을 검증하고 싶을 때 이 버튼으로 본인에게 테스트 요청을 보낼 수 있습니다.
⑥알림 테스트 버튼현재 PC에서 Windows 토스트 및 작업표시줄 깜빡임 알림이 정상 동작하는지 즉시 시험해 볼 수 있습니다.

2. AWX 연동 설정 (직접 API 우선 · DPAPI 암호화 · 열린 탭 브리지)

▲ ⚙ 환경설정 내 AWX 연동 설정 — 직접 API 자격증명 저장 및 열린 AWX 탭 브리지 연동
번호항목설명
①AWX 열린 탭 브리지 연동직접 API 대신 Edge/Chrome의 열린 AWX 탭(SSO 세션·검색/필터 적용 화면)과 WebSocket으로 실시간 연결합니다. 상단 상태에 연결된 탭 수(예: '연결됨 1개' 또는 현재 인벤토리·호스트 수)가 표시되며, 여러 탭이 열려 있어도 로그인된 정상 탭의 응답을 우선 채택합니다. [AWX 창 열기]·[AWX 탭 연결]·[연결 코드 복사]를 지원합니다.
②AWX 서버 URL · 인벤토리 선택 · 목록 출처접속할 AWX 주소(예: http://awx.example.com:30080)를 입력하고 [목록 갱신]을 누르면 인벤토리 목록(이름·ID·호스트 수)을 불러옵니다. 목록 아래에는 출처가 '목록: 직접 API' 또는 '목록: AWX 탭(직접 API 실패: …)' 형태로 표시됩니다.
③수집 범위 & 기본 페이지인벤토리 드롭다운을 바꾸면 범위가 자동 반영되며(예: inventory:3), [현재 화면 수집] 버튼 클릭 시 조회할 페이지 번호(기본 1)도 지정할 수 있습니다. 범위나 인벤토리만 변경할 때는 기존 인증 세션을 불필요하게 초기화하지 않습니다.
④계정 · 비밀번호 · Token 입력 (DPAPI 암호화 유지)AWX 계정·비밀번호·API Token을 입력해 둡니다. 저장 성공 시 비밀번호와 Token은 실행 파일 옆 config.json에 Windows DPAPI(현재 PC/사용자 전용 암호화)로 암호화(awxPasswordEnc, awxTokenEnc)되어 기록되므로, 프로그램을 껐다 다시 켜도 재입력 없이 유지됩니다. (타 PC로 config.json 복사 시 복호화가 차단되어 '다시 입력 필요' 표시)
⑤HTTPS 인증서 무시 & AWX 탭 우선 옵션 (기본 꺼짐)사내 사설/자체 서명 HTTPS 인증서를 사용할 때는 '사내 HTTPS 인증서 무시'를 체크합니다. AWX 탭 우선은 기본적으로 체크 해제되어 있어 직접 API로 먼저 수집하며, AWX 웹 화면의 검색/필터 상태 그대로 수집하고 싶을 때만 체크하세요.
⑥[초기화] 및 [연결 테스트 & 저장][연결 테스트 & 저장]을 누르면 입력한 URL·자격증명으로 실제 호스트 조회 시험과 성공 인증 방식(세션/Token/Basic) 기억, config.json DPAPI 저장을 한 번에 수행합니다. [초기화]는 에이전트 및 config.json의 AWX 설정·암호화 자격증명까지 함께 지웁니다.

3. [1번 탭] 작업 전 자체확인 (AWX 수집 및 4중 교차 비교)

▲ AWX 호스트 수집(직접 API / 탭 브리지)과 3개 입력 소스의 교차 비교 및 [MATCH] 판정 화면
번호항목설명
①제외 호스트 설정 (| 구분)AWX 인벤토리에는 포함되지만 실제 작업 대상에서 빼야 하는 서버(예: prd-db-0295|prd-db-0296|...)를 입력하면 수집 단계에서 자동 차감됩니다.
②[현재 화면 수집] / [현재 인벤토리 전체 수집]직접 API 자격증명이 설정된 경우 에이전트가 직접 API(/api/awx/hosts)로 먼저 수집하고, 실패 시 열린 AWX 탭(브리지)으로 자동 폴백합니다. [현재 화면 수집]은 선택한 인벤토리의 지정 페이지(기본 1페이지)만, [현재 인벤토리 전체 수집]은 선택 인벤토리 전체 호스트를 페이지네이션으로 수집합니다. 양쪽 모두 실패하면 직접 API·AWX 탭 오류 원인을 모두 표시합니다.
③[수집 초기화] 및 수집 톱니바퀴(⚙)수집된 AWX 호스트 결과만 비우거나, 톱니바퀴 옵션으로 입력란 연동 초기화를 설정합니다.
④수집 결과 요약 · 실제 사용 경로 · [AWX 연동 설정]총 수집 대수, 제외 대수, 인벤토리 정보를 표시하며 실제 사용된 수집 경로('경로: 직접 API(토큰/세션/Basic)' 또는 '경로: AWX 탭')를 명확히 구분해 보여줍니다. 우측 [AWX 연동 설정] 버튼을 누르면 즉시 상단 ⚙ AWX 설정 영역으로 이동합니다.
⑤비교 대상 호스트 입력 (상세목록현황 · 인시던트 · 작업대상)작업 전에 확인한 상세목록현황[필수], 인시던트[필수], 작업대상[선택] 호스트 목록을 각각 붙여넣습니다. (호스트명 / 시리얼 형태도 자동 정제)
⑥[교차 비교 실행] 버튼입력된 2~3개 소스 및 수집된 AWX 호스트(1대 이상 수집 시 자동 포함)를 양방향 대칭 비교합니다.
⑦비교 결과 리포트 및 vim 작업 권장 안내모든 소스가 일치하면 [MATCH] 배너와 함께 'vim [작업대상 파일] -> esc -> :set paste 입력 -> 붙여넣기' 권장 안내가 표시되며, 1대라도 다르면 [MISMATCH] 및 누락·불일치 명단을 적발합니다.

4. [2번 탭] 작업자 요청/승인대기 및 하단 6시 상태 바

▲ 확인자 지정·요청 발송(상단) → 실시간 APPROVED 상태 카드(중단) → 하단 6시 상태 바(최하단)
번호항목설명
①[?] 워크플로우 가이드 버튼마우스 커서를 올리면 작업자/확인자 기준의 전체 절차 흐름도 팝업이 표시됩니다.
②인시던트 번호 [권장] & 특이사항 전달 메모 [선택]관련 인시던트 티켓 번호와 확인자에게 전달할 특이사항(예: DB 6대 제외 반영 완료 등)을 입력합니다.
③크로스체크 확인자 지정 [필수] & 요청 발송사내 명부(users.json)에서 동료 확인자를 선택하고 [크로스체크 확인 요청 발송]을 클릭합니다. 1번 탭에서 입력/수집한 호스트가 자동 연동됩니다.
④요청 진행 상태 (PENDING / APPROVED / REJECTED)발송 후 실시간 상태를 표시하며, 지정 확인자 부재 시 쿨타임 없이 다른 확인자로 즉시 변경할 수 있습니다. 승인 완료 시 [CROSS-CHECK APPROVED] 배너와 코멘트가 표시됩니다.
⑤하단 6시 실시간 상태 바1번·2번·3번 어느 탭에 있더라도 창 맨 아래 녹색/빨간색/노란색 바로 승인 대기·승인 완료·반려 상태를 항상 확인할 수 있습니다.

5. [3번 탭] 확인자 검증/승인 (블라인드 대조 및 승인/반려)

▲ 동료 요청 선택 → 복사 방지 블라인드 요약 → 확인자 직접 입력·대조 → [확인 완료 (승인)]
번호항목설명
①3번 탭 & 미확인 요청 배지동료에게서 검증 요청이 도착하면 탭 제목 오른쪽에 빨간색 건수 배지(예: 1)가 표시되며 Windows 알림이 뜹니다.
②확인할 요청 선택 & [새로고침]도착한 요청(예: [INC-2026-1113] 김철수님의 요청)을 선택해 검증 화면을 엽니다.
③요청 상세 · 특이사항 & 작업자 입력 요약(블라인드)작업자·인시던트 번호·특이사항·AWX 참여 대수가 표시되며, 확인자가 작업자 데이터를 그대로 복사해 승인하는 어뷰징을 막기 위해 대표 1대만 노출(예: svr01 등 5대)되고 나머지는 [블라인드] 처리됩니다.
④확인자 호스트 직접 입력 & [교차 비교 실행]확인자가 본인 화면(상세목록현황·인시던트·작업대상)에서 직접 복사한 호스트를 붙여넣고 [교차 비교 실행 (전체 소스 통합 대조)] 버튼을 클릭합니다.

  • AWX 수집 경로 우선순위 & 폴백: 자격증명이 저장되어 있으면 직접 API로 먼저 수집하고 실패 시 열린 AWX 탭(브리지)으로 자동 폴백합니다. 양쪽 모두 실패하면 두 원인을 함께 표시합니다.
  • AWX 화면의 검색·필터 상태 그대로 수집하려면: ⚙ AWX 연동 설정에서 AWX 탭 우선 체크박스(기본 꺼짐)를 필요한 순간에만 켜고 열린 AWX 탭과 함께 수집하세요.
  • 혼자 동작을 테스트해 보고 싶을 때: 일반 확인자 선택 목록에서는 오발송 방지를 위해 본인 계정이 숨겨져 있으므로, 상단 ⚙ 환경설정 → [셀프 테스트] 버튼을 이용해 주세요.
  • 작업 화면을 가리지 않고 띄워 두고 싶을 때: 상단 [상단 고정]을 켜 두고, 환경설정에서 마우스 이탈 시 자동 숨김(기본 30%)과 이탈 지연 시간(기본 5초, 0초~ 설정 가능)을 조정하면 마우스를 치운 뒤 지정 초 후에 창 높이만 줄어들어 편리합니다.
