1. 어떤 일을 하려면 어떤 도구를 실행하나? (명령 찾기)

모든 도구는 먼저 export VC_PASSWORD='<vCenter 암호>' 가 필요합니다.

하고 싶은 일명령
ESXi 호스트를 vCenter 에 등록한다./main_conn-source/main_conn (옵션 없음, 대상이 바이너리에 고정)
ESXi 라이선스를 할당한다./license_assign-source/license_assign -vcTargetIP <vCenter> -worklistFile worklist.txt
vSwitch 를 설정한다./vswitch_setting-source/vswitch_setting -vcTargetIP <vCenter> -worklistFile worklist.txt -targetVSwitch vSwitch0
VM 을 만든다 (ev01 ~ ev03)./vm_create-source/vm_create -vcTargetIP <vCenter> -worklistFile worklist.txt -mapFile hostgroup.txt -vmCount 2
vCPU affinity 를 설정한다./affinity_setting-source/affinity_setting -vcTargetIP <vCenter> -worklistFile worklist.txt -vm_cnt 2 -ht ON
HugePage 와 CPU 토폴로지를 설정한다./lpage_setting-source/lpage_setting -vcTargetIP <vCenter> -worklistFile worklist.txt
numa.vcpu.preferHT=TRUE 를 넣는다./numa_preferht_setting-source/numa_preferht_setting -vc <vCenter> -f targets.txt
VM 에 태그(DEPT_NAME, PURPOSE, VM_TYPE)를 쓴다./tag_setting-source/tag_setting -vcTargetIP <vCenter> -hostListFile hostlist.txt -vmCount 2 -deptNames <값> -purposes <값> -vmTypes <값>
VM MAC 목록(Kickstart 용)을 만든다./mac_info-source/mac_info -vcTargetIP <vCenter> -worklistFile worklist.txt -arg1 <값> -argStr <값>
체크 CSV 를 읽어 설정을 보정한다cd vm-param-fix && ./vm-param-fix -checkResult <상세 CSV> -vcTargetIP <vCenter> -out ./fix_result.csv

2. 처음 사용하기 전에 무엇을 준비하나?

  1. 하위 도구 바이너리와 vm-param-fix/ 폴더(power_setting 바이너리 포함)를 서버에 둡니다. 실행 권한을 확인합니다.
  2. 대상 ESXi 호스트 목록 worklist.txt 를 만듭니다.
  3. VM 생성에 쓰는 호스트 그룹 매핑 hostgroup.txt 를 만듭니다.
  4. 태그를 쓰려면 vCenter 에 사용자 지정 특성 DEPT_NAME, PURPOSE, VM_TYPE 을 먼저 만듭니다.
  5. export VC_PASSWORD='<vCenter 암호>' 를 실행합니다. 기본 계정은 lscsystems@vsphere.local 입니다 (-id 로 바꿉니다).

3. 어떤 순서로 실행하나?

단계도구하는 일
1main_connESXi 호스트를 vCenter 클러스터에 등록합니다 (동시 5대, 제한 10분, SSL thumbprint 자동 재시도).
2license_assign평가판(00000-…, eval) 호스트를 찾아 라이선스를 대화형으로 할당합니다. q 로 중단합니다.
3vswitch_settingvSwitch(기본 vSwitch0)를 순차로 설정합니다.
4vm_create호스트마다 VM ev01 ~ ev03 을 만듭니다.
5affinity_settingvCPU affinity 를 설정합니다. 파일이 없거나 파일 내용이 AUTO 이면 -ht 값으로 1:1 자동 계산합니다.
6lpage_settingHugePage 와 CPU 토폴로지를 설정합니다.
7numa_preferht_setting전원이 꺼진 VM 에 numa.vcpu.preferHT=TRUE 를 넣고 다시 확인합니다.
8tag_setting사용자 지정 특성을 씁니다.
9mac_infoVM MAC·IP 를 조회해 Provisioning_List_<vCenterIP>.txt 를 만듭니다 (읽기 전용).
10 (보정)vm-param-fixvm-param-check 상세 CSV 를 읽어 다른 설정을 보정하고 다시 체크합니다.

4. vm-param-fix 는 어떻게 보정하나?

  1. -checkResult 로 vm-param-check 상세 CSV 를 줍니다.
  2. 안전 검사를 합니다: 호스트 구성이 같은지, 호스트마다 ev01/ev02/ev03 수가 같은지, 대상 VM 전원이 꺼져 있는지.
  3. 다른 항목을 아래처럼 나누어 외부 도구로 보정합니다.
  4. 보정 뒤 vm-param-check 로 다시 체크하고 결과를 -out 파일에 씁니다.
다른 항목보정 방법
sched.vcpuN.affinityaffinity_setting 호출 (-affinityTool)
HugePage·CPU 토폴로지 8개 키lpage_setting 호출 (-lpageTool)
호스트 전원 정책power_setting 바이너리 호출 (-powerTool)
그 밖의 항목보정하지 않습니다 (manual). 직접 조치합니다.
bash \ -id lscsystems@vsphere.local \ -workDir . \ -affinityTool ./affinity_setting \ -lpageTool ./lpage_setting \ -powerTool ./power_setting \ -recheckTool ./vm-param-check \ -out ./fix_result.csv]]>

항목VM_setup (V1)V2
실행 방법도구를 하나씩 수동 실행vm_setup.sh 한 번으로 전체 실행 + 진행 화면
VM 수ev01 ~ ev03 (최대 3대)ev01 ~ ev99 (최대 99대)
체크·보정vm-param-fix 가 외부 도구 4개를 호출vm-param-check -fix 단일 바이너리

추가 도구없음nic_assign, pci_passthrough, power_setting

7. 문제가 생기면?

  • vCenter 로그인에 실패한다: VC_PASSWORD 와 -id 계정을 확인하십시오.
  • 4대 이상의 VM 을 만들어야 한다: VM_setup 은 3대까지만 지원합니다. V2 를 쓰십시오.
  • tag_setting 이 실패한다: vCenter 에 DEPT_NAME, PURPOSE, VM_TYPE 특성이 있는지 확인하십시오.
  • numa_preferht_setting 이 종료코드 2 를 낸다: 전원이 켜진 VM 이 있거나 재확인 값이 다릅니다. VM 전원을 끄고 다시 실행하십시오.
  • mac_info 결과에 _DNS_AND_TOOLS_NOT_FOUND 가 있다: VMware Tools 또는 DNS 정보가 없습니다. 다음 작업 전에 IP 를 직접 채우십시오.
  • vm-param-fix 가 ev03 을 보정하지 못한다: 알려진 한계입니다. vm-param-check -fix(V2)를 쓰십시오.

8. 자주 묻는 질문 (FAQ)

Q. VM_setup 은 무엇을 하는 도구인가요?
A. ESXi 호스트 등록, 라이선스, vSwitch, VM(ev01 ~ ev03) 생성, affinity·HugePage·NUMA·태그 설정, MAC 목록 생성을 하는 V1(레거시) VM 자동화 도구 모음입니다. 도구를 하나씩 실행합니다.

Q. 새로 VM 을 구축할 때 VM_setup 을 써도 되나요?
A. 새 작업에는 V2 를 쓰십시오. V2 는 99대까지 지원하고 한 번에 실행하며 체크·교정이 통합되어 있습니다.

Q. 실행 순서는 무엇인가요?
A. main_conn → license_assign → vswitch_setting → vm_create → affinity_setting → lpage_setting → numa_preferht_setting → tag_setting → mac_info 입니다. 보정은 vm-param-fix 입니다.

Q. 잘못 설정한 것을 되돌릴 수 있나요?
A. 자동 롤백은 없습니다. 실행 전에 기존 설정을 백업하고, 대상을 적게 해서 먼저 확인하십시오.

Q. VM 의 IP 를 바꾸려면?
A. VM_setup 은 IP 를 바꾸지 않습니다. vm-ip-change(vCenter API IP 자동변경) 도구를 쓰십시오.
