양식 유형: T2 (점검형 · 빌드 불필요 순수 Bash 스크립트)

원본 경로 (origin/master): .claude/HPC/GPU 체크스크립트/ (check-gpu-power-limit.sh, README.md)

동작 환경 및 의존성: Linux / systemd + NVIDIA GPU 서버 (bash, systemctl, nvidia-smi, grep, xargs)

연계 도구: gossh (다수 GPU 서버 일괄 실행 및 grep FAIL 필터링)

한 줄 요약: nvidia-persistenced와 gpu-power-limit.service 기반 GPU 전력 상한(최대 전력의 75%)이 재부팅 유지 설정과 실제 GPU 하드웨어 모두에 적용되었는지 6개 항목으로 일회성 점검하고 OK\t/FAIL\t으로 출력하는 스크립트입니다.

1. 개요 및 전체 점검 흐름

check-gpu-power-limit.sh는 GPU 서버에 적용한 전력 상한(Power Capping, GPU 최대 전력의 75%)이 systemd 서비스 구성과 실제 nvidia-smi 전력 제한 값 모두에 정상 반영되어 있는지 일괄 점검하기 위한 읽기 전용 Bash 스크립트입니다.

gossh 등으로 수십~수백 대의 GPU 노드에 배포해 한 번에 실행하는 용도로 설계되어, 사람이 읽는 장문 대신 파싱하기 쉬운 OK<TAB>설명 / FAIL<TAB>설명 형식으로 한 줄에 한 항목씩 결과를 출력합니다.

전제 서비스 구성 (gpu-power-limit.service)

대상 GPU 서버에는 nvidia-smi -pl <목표W>를 실행하는 set-gpu-power-limit.sh와 이를 부팅 시 실행하는 systemd 유닛이 사전에 구성되어 있다고 가정합니다.

2. 사전 준비 및 스크립트 배치 (빌드 불필요)

check-gpu-power-limit.sh는 순수 Bash 스크립트이므로 빌드가 필요 없습니다(빌드 불필요). 스크립트 상단 변수를 실제 GPU 장비 사양에 맞게 수정하고 실행 권한을 부여한 뒤, 공유 NFS 경로 등에 올려 두고 실행합니다.

  1. 스크립트 상단 변수 수정 — GPU 최대 전력 × 0.75 값을 정수(W)로 계산해 TARGET_POWER_LIMIT_W에 입력합니다(예: 최대 1100W GPU → 825). bash
  2. 실행 권한 부여 및 공유 경로 배치 bash

3. 설정 변수 규격

이 스크립트는 별도 외부 conf 파일이나 CLI 옵션을 받지 않으며, check-gpu-power-limit.sh 상단 설정 블록(11~21행)의 4개 변수를 직접 수정해 사용합니다.

변수명 기본값 설명
TARGET_POWER_LIMIT_W 825 목표 power limit (W 단위 정수). GPU 최대 전력 × 0.75 값을 직접 계산해 입력 (예: 1100W × 0.75 = 825)
SERVICE_NAME "gpu-power-limit" 점검할 systemd 서비스 이름 (.service 확장자 제외)
SERVICE_FILE "/etc/systemd/system/${SERVICE_NAME}.service" systemd 서비스 유닛 파일 전체 경로
SET_SCRIPT_PATH "" (빈 값) set-gpu-power-limit.sh 절대경로. 값이 비어 있지 않으면 SERVICE_FILE 내 해당 경로(ExecStart=) 포함 여부를 추가 점검, 비우면 건너뜀

5. 점검 항목 · 출력 형식 및 종료 코드

5.1 6개 점검 항목

순서 점검 항목 판정 방식
1 서비스 유닛 파일 존재 여부 [[ -f "$SERVICE_FILE" ]]
2 (선택) ExecStart 설정 스크립트 경로 참조 여부 SET_SCRIPT_PATH가 비어 있지 않을 때 grep -qF "$SET_SCRIPT_PATH" "$SERVICE_FILE"
3 서비스 active 상태 systemctl is-active --quiet "$SERVICE_NAME"
4 서비스 enabled 상태 (재부팅 유지) systemctl is-enabled --quiet "$SERVICE_NAME"
5 nvidia-smi 및 GPU 인식 여부 command -v nvidia-smi 및 --query-gpu=count가 1 이상인지 확인 (미설치 또는 GPU 0개면 FAIL 출력 후 즉시 exit 1)
6 GPU별 실제 power limit 일치 여부 nvidia-smi --query-gpu=index,power.limit --format=csv,noheader,nounits로 모든 GPU를 순회하며 소수점 이하를 버린 정수부가 TARGET_POWER_LIMIT_W와 일치하는지 비교

종료 코드 주의: nvidia-smi가 없거나 감지된 GPU가 0개이면 즉시 exit 1로 종료되지만, 그 외 항목(1~4번, 6번)에서 FAIL이 출력되더라도 스크립트는 끝까지 모든 항목을 점검한 뒤 마지막 명령의 종료 코드로 종료됩니다. 따라서 일괄 점검 시에는 종료 코드 대신 출력 문자열에서 grep FAIL로 이상 여부를 판별하는 것이 정확합니다.

6. 해석상 한계 및 주의사항

  • 참고용 점검 도구: 본 스크립트는 참고용 보조 도구입니다.
  • 드라이버별 nvidia-smi 출력 형식 차이: nvidia-smi --query-gpu=index,power.limit --format=csv,noheader,nounits의 출력 형식이나 단위 표기는 드라이버 버전에 따라 달라질 수 있으며(예: [N/A] 등 비숫자 출력 시 정수 비교 -eq 오류 가능), 대규모 배포 전 일부 서버에서 직접 실행해 출력 결과를 확인하시기 바랍니다.
  • 소수점 절사 비교: 스크립트는 cut -d'.' -f1로 소수점을 버린 정수부만 비교합니다. GPU 모델 혼재 환경에서는 서버군별 목표 W 값을 맞춰 점검해야 합니다.
